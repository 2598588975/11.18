# 从观众感受到相机位置

适用于按情绪设计镜头、给短场景排镜、诊断已有提示词。先确定观众此刻跟谁站在一起、要看见哪一项变化，再决定观看距离、机位相对谁的高低，以及让观众在这一刻停多久。

## 三种输入

- 一段剧本：在观众获得新信息或人物关系改变处划节拍，为每拍选一个主要情绪。安排观众看见信息的时刻，也给人物消化它的时间。约 30 秒的短文戏可先试 2–3 个节拍、3–6 镜，再用实际台词、动作和反应校时。揭示可以先看察觉者、再看他发现的东西、最后回到反应。和解有时只需留在同一镜，看两个人的距离怎样改变。
- 一句情绪：给一个可拍选项，说明观众从哪里看、能看到什么、为什么在这里停住。要表现被审视，先指明谁是受压者；从上方拍受压者与从其眼位仰看逼近的人，是两种不同的观看立场。表现疏离可让人物占画面一小角，让空处可见。表现亲密可留在眼平近景等对方听完，克制的悲伤可留在固定机位等动作结束。情境和导演意图决定取舍。
- 一条旧提示词：先做下方四查，局部改稿交付「改前／改后／为什么」。改前保留原句，改后原样保留主体动作、外观、服装、台词及用户锁定的文字，只替换发生问题的摄影描述。为什么点明第几查、具体冲突及改后观众能读到的变化。

## 六个逐镜决定

| 决定 | 写到可以摆机或剪接的程度 |
|---|---|
| 距离 | 给主景别和人物占幅，说明环境与人的取舍。镜内变化另写起幅和落幅。 |
| 高度 | 以被摄对象的眼位、肩或地面为参照；说清高低与俯仰分别如何设置。 |
| 朝向 | 指明看谁的正面、侧面、背面或越过谁的肩；交代视线方向与主体在画面哪一侧。 |
| 焦段与焦点 | 选一种空间效果，交代观众应看清的平面、前后景的清晰关系。 |
| 运动 | 一个普通生成镜头选一个主运动。写种类、速度或实际用时、可见终点。例：四秒沿桌边向前推，从双人中景收到印章，章面清晰时停。选固定则写明机位锁定，让动作发生在画内。推轨会改变透视，原地变焦只改变取景范围。明确设计的推轨变焦需写反向配合、主体占幅及背景变化。 |
| 接点 | 指定切出的动作相位、遮挡物或尾帧状态，以及下一镜如何接。单张或孤立单镜只需写实际适用的落点；上下镜缺失时不要编造。 |

每维给相容的答案。把选择放进原有镜头表的对应栏，拍法理由留在规划稿。正式提示词沿用目标模型格式和已确认导演方案。

## 画幅与剪接

画幅已定为 9:16 时，在竖幅内安排人脸、手、前景与字幕。双人可用前后景或正反打，视线附近留出空间；推拉、升降、俯仰比长距离横移更容易留住主体。可把眼睛置于上三分线附近，有字幕时以画面高度约 15%–75% 为初始工作区，再按交付界面校对。若锁定横版母版另裁竖版，则在母版内检查竖裁安全区。

同一主体连续硬切时，用约 30° 的机位差检查意外跳切；对话先守互动轴线和视线。主动越轴或跳切时，以可见过渡或明确剪辑意图为准。动作中段切要对动作相位，遮挡切要对遮挡方向与覆盖范围，首尾帧桥要对位置和状态。30–40 秒短片可试把遮挡或帧桥留给 1–3 个重音，普通衔接用硬切。

## 改稿四查

1. 能否按原句摆出摄影机？找出缺失的观看距离、相对位置或朝向。
2. 这个角度把力量给了谁？检查景别、高度、负空间及停留时间是否服务这次情绪。
3. 运动怎样开始、多久能到、停在哪里？检查漂移、无动机叠加和不可能同时完成的运动。
4. 是否在同一时刻要求互斥的拍法，或仅用否定句、风格词代替可见构图？在可改的摄影句中把目的写成可见结果。保留模型要求的独立负向栏和用户锁定前缀。
