# 乱霞号日常 Skill

从构思到剧本再到分镜参与创作。先让点子具有铺垫、反差、人物选择和结果，再落实为可执行镜头；最终视频提示词需具体到画面、动作与声音，不以剧情摘要代替。

## 咒蓝篇下：图片与视频参考包

新增[咒蓝篇下项目索引](references/zhoulan-media-index.md)：2026-11-12只读归档163个图片节点、50个视频节点，其中图片提示词135条、视频提示词48条；空节点也保留。需要该项目原文，或当前任务涉及主资产/多角度分工、空间母版、特写尺寸还原、巨物与多肢、同身变形、同步救援、生活道具回报、绘画冲击帧时，按需读[图片与视频规则](references/zhoulan-image-video-rules.md)，再完整读取实际采用的原文。已有战斗保真、A/B、异种纪元和五项视觉前缀规则继续适用。

- **图片请求**：直接交付所需图片提示词；按主资产、结构卡、空场、道具、材质或冲击帧确定职责。原文在[图片库](references/zhoulan-image-prompts.md)，不强制续写视频、添加视频五项前缀或生成全部配套资产。
- **视频请求**：从[视频库](references/zhoulan-video-prompts.md)按场面与版本选完整底稿；用户要求贴合该项目格式时保留其输入说明/目标/基础设定/声画/时间段写法，否则将有效规则嵌入当前A/B，不另改默认格式。
- **版本与作用域**：不同终局版本的束缚、控制权、照明参考和多角度输入存在差异；先锁当前采用版本与起止状态，不把版本混写，也不以最大后缀判断最好。港式奇幻、重庆、墨青琥珀及2秒活动黑屏不成为所有乱霞号任务的默认设定。原文及配置不等于已验证成片效果。

## 视频提示词五项视觉前缀（2026-11-11）

新写或明确要求更新完整视频提示词时，读取 [五项视觉前缀](references/global-visual-prefix.md)。每个独立生成段开头写全【全局视觉风格】【画面规格】【光影色彩】【镜头与物理】【一致性与执行】，之后接本段资产与时间轴；特别写清光源位置/方向、软硬、补光、配色、对比度、高光、阴影与主体曝光。同场反打按固定世界光源换算受光方向。

统一的是信息结构，具体值按项目和当前分镜填写；古风暖日光、9:16、人像焦段与慢推只是限定范例。已有明确格式将五项合入开头总控，保持原有镜内写法；已确认最终提示词的原样投喂和局部修改任务不自动追加。当前分段内容与项目锁定值优先，不新增人物、动物、道具或特效。

## 调用别名：异种纪元

在提示词/创作语境中，用户说“异种纪元”“用异种纪元写”即可调用本技能的异种纪元模式，不必同时说“乱霞号”。先读 [异种纪元调用与原文保真格式](references/yizhong-format-and-source-workflow.md)，从 [完整原文索引](references/yizhong-ep4-original-prompts.md) 选贴近场景的案例，完整阅读后再适配；不要只读风格摘要就起稿。没有另定格式时，尽量保持所选原文的外层结构、逐镜字段、镜内句式与声画节拍。用户明确保留乱霞号A/B或只借某项风格/镜头时，保留指定骨架并尽可能贴合所选原文表达。该模式仍是额外选择，不自动作用于未点名的乱霞号任务；只说调用词且没有创作材料时确认已启用并询问要处理的内容，不凭空编一段。

## 场面分工（高优先级）

**战斗与强动作高光保留已有写法；对白与叙事调度按原库提炼的方法自主设计。** 按段落职责分别执行，不把战斗的原文优先规则扩成全片只能套底稿：

- **战斗、重点视觉高光**：沿用目前已有格式与原文优先流程，保留成熟参考的动作链、关键句式、视点、快慢节拍和声画衔接，再做必要适配；不得借自主创作随意润色高光。
- **对话、场景移动、关系展开、故事展开**：可按已分析的导演思维链自行设计——场面目的与人物诉求 → 信息先后与关系变化 → 可见动作、走位及回应 → 有动机的运镜、焦点与声音交接 → 结果与下一段衔接。文戏新写先用对局、笑点、关系设计检查回应是否落成可见证据；有贴合桥段可以参考，不强制逐段找到底稿，也不以“原文没有对应段落”为自主设计的前提。
- **混合场面**：按实际节点切换方法；同段出现战斗或高光，不会使前后对白全部变成照搬任务。自主设计保留用户指定或当前稿的格式；新稿按场面职责选择A/B，遵守已确认的剧情、台词、能力和资产。前期可选创意重点放在没有直接参考的新段落；普通文戏调度可在任务范围内直接完成，改变已定关系、结果等关键选择才先讨论，未采用的备选不混入正文。

## 战斗底稿与分场装载

新写或重写战斗/强动作高光，先辨明场面职责，定位并完整阅读最接近的一份主原提示词，再起草；默认最小必要替换。保留动作链、关键句式、视点、快慢比例、转焦聚能、冲击帧、能量占幅/持续和声画衔接，不先自由重写再补原文词。用户的保留/排除、当前资产与结果优先；删除招式后只补必要接口。执行 [战斗原文保真工作流](references/combat-source-workflow.md) 的来源映射、混源与减法审计，并做三链预检。原稿中的计时、引用与状态错误要修，原故事材质/能力不默认继承。

### 使用深度与最小装载

遇到施法、控场、召唤剑阵或禁术收尾，按节点选读[高燃法术分镜 50 式](references/spell-storyboard-50.md)。点名编号时直接查该式，保留景别、视角、运镜或变速，以及作用后的可见反馈。单招是主战斗底稿的局部补充，仍按已定人物能力、空间和 A/B 或异种纪元格式接戏。

按影响范围选深度，不按修改字数选，也不规定固定阅读时长或装载字数：

| 深度 | 触发 | 实际加载与可观察检查 |
|---|---|---|
| D0 文案局部 | 只改措辞、命名，不改变事件/声画接口 | 本文件相关规则＋当前稿；逐字文本与范围核对 |
| D1 连续链局部 | 改动作、快慢、持器、受力；或对白时序、笑点揭示、关系落点、声桥 | 完整当前连续链＋对应方法章节；战斗另读完整主原文、保真流程与相关物理模块，执行三链/减法；文戏读对白设计及格式对应节，核对回应与接口 |
| D2 完整成稿 | 任意时长的独立完整提示词；或累计跨三个以上镜头/多种系统相互影响 | 统一格式＋质量表适用章节＋下列场面包；保留已选原句与格式字段，整段核对时间、空间、资产和接戏，不以“汇总”泛化高光 |

- **新写/增强创意**：读 [创意导演](references/creative-direction-design.md) 的对应设计部分，单纯校对不加创意。
- **战斗包**：读保真工作流、[战斗编排](references/combat-creative-design.md)、[物理拆解](references/combat-weapon-breakdown.md)相关节；镜头与动作交接按[15项战斗运镜](references/combat-camera-methods.md)选读对应条目；[场面索引](references/029-directing-pattern-catalog.md)定位后完整读所有实际采用的原文；[场面机制](references/029-scene-mechanics.md)只读本场动作/视点/节奏相关节。
- **文戏包**：新写/增强或改关键节拍时读 [对局与关系场面](references/dialogue-scene-design.md)，对应场面机制第7—8节；实际借用桥段才完整读该原文，不强制每段套底稿。只改文本、身份绑定时不加载整套创意方法。
- **接口/版本包**：出现抛接、换手、回收、相近变体选择时读 [动作接口与版本](references/action-interfaces-and-versions.md)。
- **成片反馈包**：有成片、截图、失败反馈或要求记录实测时读 [生成后回填](references/generation-feedback.md)。
- **异种纪元画面与镜头包（额外可选）**：点名“异种纪元”按上面的调用别名进入原文保真模式；只借画风/镜头时，读 [可选规则](references/yizhong-visual-camera-options.md) 的对应部分并嵌入指定格式。提供5类画面风格、质感/美术锁定和12种镜头场景用法。实际借用案例时完整读 [31份原文](references/yizhong-ep4-original-prompts.md)，保留格式与有效写法，只作当前项目所需适配。已定摄影基底、媒介、画幅、剧情及成熟高光优先；此包不改变现有运镜库的主动选用机制。
- **运镜包（按需主动选用）**：新写或优化打斗、追逐、创意高光时，主动查看[24项运镜库](references/camera-movement-library.md)的索引与[场面调用规则](references/camera-movement-library.md#invocation-rules)；战斗另按[15项战斗用法索引](references/combat-camera-methods.md#快速索引)选读，在突进、反击、腾空、空间揭示、接触、转场和后果收尾等节点选用匹配方法，用户不必点名。其他镜头需要调整视点、焦点、路径或时间表现时再读相关条目。按信息、情绪和节奏收益选择，不设技巧配额；用户已定视点、速度、画风及成熟高光优先，保留有效表达。单纯改字不加载整库，不自动套慢放、全周环绕或8K超写实；变速、冻结与瞬移分别判断，人物翻滚、机位环绕与光轴滚转分别写明。

混合段按节点加载两类相关章节，不重复通读全部方法库。低深度触发更高条件就升级。所需案例无匹配时标明新编，不把索引摘要当作原文；用户要求全库复盘时才逐份通读。

### 原文检索不只依赖摘要

先按叙事任务查索引；摘要未命中时直接搜当前归档正文，用动作、对象、结果与同义词交叉定位，再完整读所选记录。可用零依赖 [read_case.py](scripts/read_case.py)：

~~~text
python <skill目录>/scripts/read_case.py --search 修复 握拳
python <skill目录>/scripts/read_case.py --source P2 --case v-iQqD2oqXL3
python <skill目录>/scripts/read_case.py --source YZ --search 转焦 阴影
python <skill目录>/scripts/read_case.py --source YZ --case YZ30
python <skill目录>/scripts/read_case.py --source ZLI --search 空间母版 多角度
python <skill目录>/scripts/read_case.py --source ZLV --search 扣腕 竖桥
~~~

脚本搜索P1/P2/P3/P4及YZ（异种纪元）视频全文，另支持ZLI（咒蓝图片）与ZLV（咒蓝视频），返回定位和短摘录；按精确标题/nodeKey读取完整原记录，YZ另支持YZ01—YZ31编号及同正文副本nodeKey，咒蓝库支持ZLI001—ZLI163、ZLV001—ZLV050，空记录明确返回为空。它不决定适配性，不修原文、不把搜索排名当质量排序；旧文本/资产按已有索引另查。无Python时用rg及文件读取完成同样步骤，不能因工具缺失改用摘要代替底稿。

## 默认交付目标

创作新故事时，按 [原文场面机制](references/029-scene-mechanics.md) 的对应章节理解动作、视点、焦点与声音为何这样接续，并按上述场面分工设计。战斗与重点视觉高光先读所选完整原文；对白和叙事调度可自主设计，选择具体桥段作参考时才须完整阅读该原文。故事目标、阻力和转折可在用户前提内新编；采用成熟参考的关键镜内表达仍执行原文保真规则。不同场面只在可承接的动作落点或信息交接处组合，不把“理解机制”当作自由润色高光原句的理由。单纯局部校对不要求加载整份机制库。

用户给构思或剧本通常是在提供创作起点，默认目标是可复制到 Seedance 2.5 的完整视频提示词：**构思丰富 → 剧本补足 → 高光与声画设计 → 适合本场的A/B完整正文**。中间过程可内部完成，不要求用户反复说“继续”，也不默认把剧本和提示词全文重复交付。

只有用户明确要求“先讨论构思”“只写剧本”“台词先检查”“先给建议”时，才停在相应阶段；仅评估、校对、记录设定或修改局部的请求不扩写全片。可能改变已定剧情的关键选择先确认，不以默认成品流程跳过用户审批。

**创意重点放在原提示词没有直接对应的新段落**，如新的情节、过渡或人物关系；已选作底稿的成熟参考段主要做保真和必要适配，不把重新设计它们当作常规创意任务。前期构思或讨论中给少量具体可选建议，说明位置、做法、预期效果及对时长／设定的影响，让用户选择后再落实。可借原文的组织方法，但无直接底稿的内容明确标为新编，不冒充原句，也不顺带改动相邻的成熟高光。执行阶段按已选方案稳定展开，未确认的可选设计不混进正文；这不限制任务范围内的对白、走位和叙事设计，也不要求逐个小点另获授权。直接要求成稿且尚未选择额外创意时，先交付保留已定要求的版本，备选放正文之外，不擅自视为获准采用。最终组织方式见 [统一成品格式](references/unified-format.md)，建议如何搭配案例见 [创意导演方法](references/creative-direction-design.md)。

## 按创作阶段介入

- **点子/构思输入**：把用户的小创意展开为场面目标、人物动机、阻力、转折与高光回报，主动利用性格、能力差和环境，补成可拍摄的剧本逻辑，再继续完成提示词；明确只讨论时才交付创意方案或节拍。
- **剧本/桥段输入**：保留故事骨架、已定结果和确认台词，适当补足铺垫、战术诱因、动作回应、人物反差与情绪落点，再转成提示词；不把“补亮点”等同于重写主线。明确只要剧本时不展开摄影参数表。
- **分镜/视频提示词**：在已定故事上设计观众先看到/听到什么、何时揭示，再写机位、焦点、动作、声音和接戏。
- **局部润色**：只补用户指定的创意或薄弱环节；已确认的剧情结果、台词、能力和资产不擅改。用户要求开放构思时可提出新情节，清楚区分建议与既定设定。

新写或增强创意时先读 [创意导演方法](references/creative-direction-design.md)；涉及打斗构思、剧本或分镜时，再读 [战斗创意编排](references/combat-creative-design.md)。单纯校对、格式转换不强行加入新创意。美感来自有理由的取舍，不靠规定每场必须有脚部开场、荷兰角、冲击环。

## 工作方式

通常完成下面整个流程；仅在用户明确限定中间阶段时，取所需步骤而不强制制作资产表与逐秒计时。

1. 识别输入起点、最终交付要求与不可改变项。已有成熟段落先识别并保留其期待、反差和回报，确有缺口或开放构思时再补，再确定时长、画幅、媒介、声音和资产。次要缺项合理暂定并简短说明；会改变已定叙事或资产身份的信息才询问。
2. 建立资产表：角色、场景、道具、声音、首尾帧或参考视频。每个角色绑定后主动附简短外观、服装和本段起始状态，不只写姓名或资产编号；缺失外观不凭空锁死。多参考分工、状态变体或引用冲突时读 [资产绑定逻辑](references/asset-binding-logic.md)，明确每项参考负责什么、不继承什么、在哪些镜头生效。保留当前平台已确认的绑定形式；操作LibTV画布时可用有效的 `{{Node "节点名"}}` 或唯一nodeKey，已有 `{{Mixed N}}` 不擅改。尚未提供的素材用【绑定：】留空，不猜编号或声线。涉及武器、打斗、战斗或攻击特效时，先读 [武器与战斗提示词拆解](references/combat-weapon-breakdown.md)，按本场需求选择适用模块。
3. 先按完整节拍分段，长场面通常20–30秒，短文戏按实际事件时长，优先在适合的换场处断开；再为每段写独立剧情、高光、资产、规格、坐标和规则。全片连续性底稿用于内部核对，提交正文只包含本段需要的设定和适用时刻，不把后段状态写成全片常驻。
4. 按镜头分配成片时间，只在必要的转折、快慢切换、爆点与快切处细标秒数或帧数，不把连贯突进拆成逐秒准备。战斗先编双方策略与反制，再写主体、动作、目标及必要的受力和环境反馈；日常场面先编人物诉求、信息/关系变化和笑点兑现，再用视线、遮挡、声音和人物交接承载；无冲突的关心不强加博弈。
5. 对白逐字写明说话人、已知声线、状态（处境）、语气、镜号与成片时间、画内/画外属性。B格式有对白时用独立对白模块；A可就地写全，复杂时独立成栏。尾音跨镜写续入镜/动作落点，物理接戏与起幅关系按需要单列。
6. 所有段落都验算总时长、镜头时长、资产数量、左右位置、持物手、出入画方向和上一镜落幅状态；只有战斗、追逐、攻防对抗或以强动作/VFX为主要高光的段落，再执行下述“三链预检”，未通过先回改再交付。混合段只检查其中的战斗/强动作节点。

## 战斗与强动作段的三链预检

这只是战斗、追逐、攻防对抗或强动作/VFX高光段的简要文本检查；普通文戏不强制执行，混合段只检查其中的战斗节点。它不负责观看或诊断生成视频，也不要求把内部推演写进可复制正文。

1. **空间—时间威胁链**：核对双方起始位置与距离、相对速度、动作耗时、同期位移和结束位置。对手不能无故停住等主角完成动作，角色距离也不能靠切镜凭空变化；摄影机后拉不等于角色后退。站桩、移动射击和后撤射击都可以成立，按事件时间验算动作窗口：匀速v(m/s)=v(km/h)÷3.6，位移=v×t；相向接近用速度之和，同向追逐用速度之差，变速分段计算。升格/同步回看另记成片时间，不当作额外行动时间；例如300km/h走800米约需9.6秒，500km/h走300米约需2.16秒。路程、对手同期移动与接触前剩余距离一起核对，**不把站桩射箭本身判为错误或列入负向禁项**。
2. **身体动作链**：核对前一动作尾态、重心与支点、双手和武器状态、发力轨迹、接触/释放及下一动作起幅。拉弓、蓄力或武器变化可以站定，也可以嵌入移动；按本镜需要选择，不强迫所有攻击边跑边做，只排除姿态、持物手或连接动作互相矛盾。
3. **命中后果链**：核对力量来源与方向、实际接触点、受击反应、位移/破坏传播和持续尾态。黑白帧、冲击环、闪光与爆炸只能强调命中，不能替代接触和受力过程；命中、爆发、击退与环境破坏应有可读先后。

三链只审查提示词基础逻辑。发现矛盾就修改对应距离、计时、动作或镜头；逻辑成立时不为追求“更动”擅自增加小碎步、后退或复杂连接动作。

## 输出要求

用户指定格式和已有稿格式优先；新稿按主导任务选择，不按镜数硬切。创意说明、来源、备选与校验留在可复制正文之外：

**异种纪元模式例外**：用户点名异种纪元且未指定其他骨架时，优先贴合所选源提示词格式，按 [原文保真格式](references/yizhong-format-and-source-workflow.md) 执行；不强制改写成下面的A/B。仅借异种纪元的局部规则时仍用当前指定格式。

- **A 六节＋镜内三栏**：战斗、突进、强动作/VFX主导；六节为剧情与高光、资产、成片要求、最高优先级、分镜、负向。
- **B 字段制＋对白模块**：对白、对局、日常、表演/关系主导；保留剧情、高光、资产、成片要求、最高优先级、场景箭头节拍、对白模块、必要的物理接戏与负向。不为套B删掉镜头内有效的摄影机/画面/音效三栏。
- **混合场面**：保留主稿骨架，在需要处补对白、起幅、速度硬锁和接口，不在一段里重复两套总设定。字段制也能承载打戏；WX1就是十镜混合段，不能据镜数拒绝B。统一格式见 [A/B模板与选择](references/unified-format.md)。

乱霞号真人电影风格在未另指定摄影基底时，默认采用 **ARRI ALEXA 65 数字电影摄影机拍摄质感**；已有项目的摄影机、媒介与画幅设定优先，不把该默认值强加给动画或其他明确风格。每个独立生成段在开头五项前缀的“全局视觉风格”写一次摄影基底（已有指定格式可合入开头“成片要求”），逐镜再写具体光学与运镜，不用机型代替镜头设计；细则见 [摄影基底与镜内写法](references/unified-format.md#11-摄影基底与镜内写法)。

每段均为独立可复制单元，镜内时间从0开始；全片时间范围标在正文外的段落标题。场景转换优先作为分段点，但不拆断关键接触与后果，不为凑20秒加无用镜头。统一身份在各段必要重述，伤势、能量、天体显露和出场角色按本段起始/变化/结束分别限定。其他方法文档所说的“全局规则/定义一次”，在多段生成时均指每段内部的恒定规则，不是让所有段落共用一份未分时的指令。交付视频提示词前读 [统一成品格式](references/unified-format.md)。

A镜内默认三栏，B按统一格式展开；起幅、表演、对白和接戏放在相应动作节点，无台词不机械重复空对白栏：

```text
镜1｜0s—4.5s｜中景低机位｜跟随→转焦
【摄影机参数】起幅机位、焦段；触发事件、路径与焦点交接；落幅。
【画面内容】起幅站位与持物。0s—1.2s动作A；1.2s—2s反馈B；2s—4.5s动作C及镜尾状态。视线、惯性与必要对白就地写明。
【音效层】与动作节点同步的环境声、拟音和远近方向。
```

镜头写法、资产格式和两类示例见 [references/unified-format.md](references/unified-format.md)。需要理解格式来源与画布资产特征时读 [references/source-patterns.md](references/source-patterns.md)。需要核对示例 LibTV 画布 `494bce207e004f878be78bedf74bda5a` 的完整视频提示词时读 [references/libtv-original-prompts.md](references/libtv-original-prompts.md)；需要核对《熵乱归序》四个当前项目（029之围 P1/P2/P3 与乱霞号日常 P4）的完整视频与图片资产提示词时，先读 [references/029-media-prompts-index.md](references/029-media-prompts-index.md)，再按 P1/P2/P3/P4 定向读取对应归档。需要查看资产与格式分析时读 [references/libtv-asset-format-analysis.md](references/libtv-asset-format-analysis.md)。完成前执行 [质量检查](references/quality-checklist.md) 的适用章节，不加载无关战斗检查。完整成稿可在正文外保留段名/版本、来源、新编和关键表现的小记录；用户只要正文时不展示。收到成片或失败反馈后进入 [生成后回填](references/generation-feedback.md)，将文本完成、待生成、用户反馈与已看片证据分开；不凭文字宣布还原率或稳定性。

## 关键写作规则

### 029案例与资产入口

战斗原文保真规则见前述工作流。按 [全库方法索引](references/029-directing-pattern-catalog.md) 定位视频，按 [当前媒体索引](references/029-media-prompts-index.md) 定向读P1/P2/P3/P4；旧版比较用 [来源索引](references/029-source-index.md)。原句摘录与已知疏漏见 [写法分析](references/029-writing-patterns.md)，图片提示词见 [资产生成](references/029-asset-prompts.md)，角色/武器版本见 [资产档案](references/029-assets.md)。跨项目不搬nodeKey，不混五链五刃/双链双斧、30米/50米墙宽；未读图片或成片不声称核验外观或效果。

### 武器与战斗场景的灵活拆解

沿用现有资产表、导演设定、摄影机/画面分栏和声音模块；把 [武器与战斗提示词拆解](references/combat-weapon-breakdown.md) 的方法填入相应位置，不另堆一套重复模板。

- **先定结果再编动作**：本段是命中、格挡、闪避、落空还是取消攻击；蓄力或拉弓不自动续写为发射。只展示武器时，重点锁定结构、比例与持有状态。
- **结构与变化分开**：刚性部件锁连接、数量、持物手和人物比例；链条、弓弦、尾坠按各自连接与运动规则处理。允许的弯曲、伸展、能量生成或消散明确列出。
- **写完整因果**：动作起点 → 轨迹与目标 → 接触/闪避/取消节点 → 双方反馈 → 分离与落幅；有破坏时补对象、破坏方式、产物及持续状态。
- **能量按需分层**：内芯、外沿、环境反馈、动态构件分别定义；形成、维持、释放或取消写成时间过程。普通武器不强加发光，已有实体不随能量消散而消失。
- **冲击手段按戏选**：量化尺度、强运镜、快慢对比、冲击帧、环境反馈都是可选方法。先保证动作可读，再按高光需要组合；不要求六种手段齐上，也不把参考案例的颜色、尺度、帧数写成固定规格。

### 通用规则

- **摄影机和画面分开写**：摄影机描述机位、焦段、运动和构图；画面描述可见事件，不把“震撼、电影感”当作动作。
- **动作必须有因果**：交代攻击起点、轨迹、目标与结果；命中或格挡写接触点、双方受力和分离，闪避或取消写轨迹如何错开或终止。破坏须来自明确接触或已设定的能量/冲击波作用，不凭空发生。
- **秒数必须可加**：镜头内动作时长之和应等于镜头时长；全片镜头之和应等于目标时长。快切子镜头也要占用时间。
- **同一时刻只保留一个主动作**：并行动作用“同时”明确绑定，避免模型把顺序事件叠成一帧。
- **空间关系可复述**：用“角色 A 在画面左/右、朝向、距角色 B 多远、出口在哪一侧”写坐标，不只写抽象氛围。
- **资产引用承担身份锁定**：每段角色引用后仍主动写简短发型/辨识特征、服装配色与结构、已知身高和当前状态；面部、造型、声线职责分开，不用编号替代描述，也不臆造未提供外貌。
- **连续性优先于炫技**：每镜起幅必须能由上一镜落幅到达；蒙太奇或跳时需要明确标注。
- **品牌式风格词不能替代画面设计**：除上述默认摄影基底与用户明确指定内容外，不额外堆砌品牌或片名；将风格落实为摄影、灯光、材质和特效的可观察特征。
- **负向提示词只写高风险错误**：避免堆砌与任务无关的通用垃圾词。
- **界面文字先分工再防错**：先检查用户、原文和参考资产已指定的图文；机构名、标题、等级等应保留内容按固定图文资产锁定，不丢失、不变形、不替换，并让镜头与指示动作对应其位置。只有未指定的辅助数据区才完全不可读；同屏可分区，“无字幕”不禁止场景内正确文字。材质、群体差异、局部入画和动态落幅等其他小约束按本场取用，见 [原文细节约束](references/029-scene-mechanics.md#10-不能在精简时丢掉的小约束)，不机械复制整套禁项。
- **精简不删因果**：每段内部只写一次恒定设定，镜内写当前动作和变化；跨独立生成段重复必要身份与规则不算冗余。不删接回武器、火球成形、关键接触、三层光效差异、破坏延展等决定效果的节点。输出长度服从镜头复杂度，不以归档最长版本为字数目标。

## 两种分镜模式

- **动作/VFX**：优先 2–6 秒一镜，镜内动作节拍常为 0.2–1.5 秒；强调屏幕方向、惯性、接触、受力、速度变化与破坏来源。
- **对白/表演**：可用 5–15 秒长镜；按焦段、调度、视线、微表情、口型、台词时间和声音透视拆分。必要时在一个镜头下使用 A/B/C 子镜，但每个子镜仍需时间范围。

当用户要求“导演设定板图片”时，先输出可供制图的设定板数据（项目栏、角色、场景、镜头、灯光、声音），再按需调用图片生成能力；不要把长段提示词直接塞进图片版面。
