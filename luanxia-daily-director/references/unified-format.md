# 统一提示词与秒级分镜格式

默认把构思或剧本推进到本格式的视频提示词；用户明确只讨论、只写剧本、先审台词或只修改局部时尊重范围。已有用户明确指定的格式优先。可复制正文与创意说明、备选建议、检查结果分开。

通常以20–30秒的完整剧情节拍为一段，优先在合适的换场处切开。每段独立自足：新战斗/强动作稿用A六节＋三栏，新对白/关系稿用B字段制＋对白模块；已有稿与用户指定格式优先，混合段保持同一总骨架。镜数与长短不是硬门槛；WX1字段制包含十镜混合打戏，WX5/6也用三栏，不能把工种与格式一一绑定。恒定设定在本段写一次；跨段保留必要重复以便独立生成。

## 0. 每段开头的五项视觉前缀

先按 [五项视觉前缀](global-visual-prefix.md)写完整的五项，然后接原有A六节或B字段正文。它们分别负责画风材质、画面规格、光影色彩、镜头物理和一致性；每段各写一次，逐镜补具体变化。用户明确保留其他骨架时将五项合入开头总控/成片要求，不改原有高光句式、镜头节拍或对白。原文提取与已确认提示词原样投喂不自动增补。

摄影基底、恒定光色和运镜/物理规则集中在前缀；后面的成片要求只补时长、声音及尚未覆盖的项目需求，最高优先级只补本段起态和分时变化，避免重复或冲突。已有锁定原文保留，补充只填缺项。光源按世界位置固定，反打不翻灯；古风范例不改变乱霞号现有画幅、媒介、配色或动作设计。

## 1. 模板A：每段六节正文

段号、全片时间范围和该段时长放在代码块外的标题中；每段一个独立text代码块，内部只放可复制内容。各段局部时间从0开始。以下尖括号表示写作位置，成品应填实；只有用户尚未提供的素材绑定可明确留空。

```text

【画面规格】<本项目画幅、适用焦段/景别、景深与焦点；具体构图服从当前分镜>
【光影色彩】<主光来源与固定方位、当前受光方向、色温/软硬/柔化、补光及轮廓光取舍、主辅色、对比度、高光、阴影与主体曝光>

一、短片剧情与高光
剧情：<用一句话交代本段人物、行动、阻力与落点>。

二、资产锁定

五、分镜内容
```

### 1.1 摄影基底与镜内写法

当前归档的《029之围》60份视频提示词均明确使用ARRI ALEXA 65；早期LibTV日常案例也有Super 35。提炼为“可覆盖的摄影基底＋逐镜设计”，不是所有题材只能使用一种摄影机。

- **选择与延续**：乱霞号真人电影风格未指定机型时默认ARRI ALEXA 65；项目已有摄影设定或用户另有要求时沿用，不因从战斗切到对白就随意换机型。动画、DV、纪实等明确风格按本次要求处理；不把画幅、帧率和分辨率当作机型自动附带的参数。
- **段内放置**：新稿机型和整体影像质感放在前缀“全局视觉风格”，画幅/景深放“画面规格”，灯光调色放“光影色彩”；每个独立段重述。已有指定格式可置于开头“成片要求”的五项子块，同一信息不写两次。时长与声音仍在原字段写明。
- **镜内执行**：“摄影机参数”写焦段、机位高度/朝向、景别与前中后景构图，再写事件触发的运动方向、路径、加减速、焦点交接和落幅。静止镜头无需硬加运动，只有确有作用时才加光圈、快门、升格或精确失焦时长。
- **光学与清晰度**：焦段、机位距离、拍摄画幅和目标景别相互匹配，不把某个毫米数机械等同于固定景别。交代谁清晰、谁虚化以及何时转焦；高速段允许方向性运动模糊，但关键接触要可辨。不能同时要求全景层层清晰与后景高度虚化，也不能用“全程锐利”否定有意失焦。
- **质感落地**：补本段需要的曝光、光比、明暗层次与材质表现，避免只写机型或“电影感”。机型名称是视觉提示，不代表实际由该相机拍摄，也不保证生成分辨率；不自动追加8K等未约定输出规格。

沿用本项目21:9与无配乐要求时，“成片要求”可写：

```text
真人实拍电影质感，21:9宽银幕，ARRI ALEXA 65数字电影摄影机拍摄质感；保留暗部层次与真实材质，高亮能量边缘不过度溢白，关键人物与接触点清晰。景深及高速运动模糊按各镜设计执行。无字幕、无BGM、无音乐、无配乐。
```

这是一种可调整的基底句，不把示例的夜景、能量或声音限制移植到不相干的项目。具体镜头仍需写出例如“50mm侧前近景，前景人物掠过时保持焦点在后景角色；遮挡离开后缓慢前推，落幅于其眼神”，不能只重复相机型号。


### 1.2 模板B：字段制（对白、对局、日常、关系主导的新稿）

与A承载相同的剧情、资产、规格、规则与风险信息，用原库既有字段直接处理表演、对白及接戏；不强制只有1—3镜或没有焦段。箭头链适合连贯表演，复杂摄影仍可保留独立三栏。已有稿只需补必要字段，不为切换模板全篇重写。

~~~text
【全局视觉风格】<本项目媒介、画风、人物表现与本段可见材质>
【画面规格】<本项目画幅、适用焦段/景别、景深与焦点；具体构图服从当前分镜>
【光影色彩】<主光来源与固定方位、当前受光方向、色温/软硬/柔化、补光及轮廓光取舍、主辅色、对比度、高光、阴影与主体曝光>
【镜头与物理】<本段运镜方式与速度边界、已定重力/惯性/接触及延迟>
【一致性与执行】<本段身份/造型/比例、空间/光源/调色锚点；当前分镜优先；未明确出现的人物/动物/道具/特效不得生成>

剧情：<本段人物、诉求、回应与落点>
高光：<信息翻转、关系证据或具体反差>
资产：<有效引用/待绑；人物已知外观服装和起始状态；道具、动物、场景与声线职责，锁数量>
成片要求：<本段时长、声音及前缀未覆盖的本段要求；特效按时间节点生效>
最高优先级锁定：<世界/屏幕关系、状态阶段、关键限制；同步多视点时写事件与镜号>
🎬 镜头1：0s—Xs
【起幅位置关系锁定】<只有易混的多人、逆观察侧或持物关系需要时单列>
场景：【<景别、机位与有动机的运动/焦点>】<事件A>（<x秒>）→ <回应B>（<y秒>）→ <变化与落幅>（<z秒>）
【对白模块】
台词：<角色>：“<逐字台词>”
配音指令：<角色>｜<有效声线绑定或已确认声线描述>｜状态（<身体与处境>）｜语气（<表达方式>）
对应镜头：镜头1，成片局部时间<起—止>；<画内/同地画外/通讯/内心等>
尾音续入落点：<仅跨镜时写下一镜/成片时间/承接动作；本镜可见发声口型区间也写清>
【音效层】<同步拟音、环境层、声源方向与远近；可与场景节点并写>
<继续下一镜；无台词镜不必重复空对白模块>
【物理接戏】<关键位置、持物手、道具归属、环境尾态、声音余韵及下一镜/段起态>
【负向提示词】<仅本场高风险错误，勿否定合法变化>
~~~

时间区间是段内成片时间，不用007等含糊编码；沿用“持续X秒”时在内部累计起止并核对对白位置，成品可写“持续X秒（起—止）”。不把两种时间表达当作未经换算即可互换。各箭头是顺序事件，其耗时相加等于镜长；并行动作写“同时”共用同一窗口，不重复累加。

### 1.3 A/B共用的对白与接口字段

| 原库术语 | 放在哪里及实际职责 |
|---|---|
| 对白模块、对话模块、台词对话模块锁死 | 同属对白组织；前者逐镜执行，最高优先级仅锁准确文本、角色和关键声画约束，不把全文再抄一次 |
| 配音指令 | 角色＋有效声线/已确认音色＋状态（处境）＋语气；状态与语气不是同一个字段。VoiceID仅在实际提供有效标识时用，原稿占位词不是可猜的音频资产 |
| 对应镜头 | 镜号＋段内成片起止秒＋声音属性，与画面口型及人物状态对应 |
| 尾音侵入下一镜 / 尾音续入落点 | 锁上一句如何在下一镜的哪个时刻/反应继续，声音可先切或后切；画外续音不要求下镜无关角色做口型 |
| 物理接戏 | 镜尾或段尾的持物、位置、持续环境与声音状态；简单镜就地写，复杂段单列，不取代镜间检查 |
| 起幅位置关系锁定 / 初始构图 | 镜头观察侧下的前中后景、人物左右与世界地标/持物；不把参考图的屏幕左右当全世界左右 |

这些是现有归档字段的整理，不是新增平台语法或必须逐镜堆齐的表。A只有一句简单对白时可在画面节点把相关信息写全；多说话人、声桥、声音属性切换时用同样的独立模块。台词跨镜时分别标发声区间、声尾区间与可见口型区间；回敬重叠只允许可听清的短尾，不把两句全叠。没有新声线资料时沿用已确认描述或标待绑，不以角色名杜撰VoiceID。

### 1.4 额外可选规则：异种纪元画面与镜头包

说“异种纪元”即可调用，完整创作先选案例、读完整提示词，并尽量贴合其原文格式、字段与写法，见 [原文保真格式](yizhong-format-and-source-workflow.md)。用户未指定别的骨架时，不强制转成A/B。未点名时不自动加载整包或改变原默认。

**以下映射仅用于用户明确保留A/B、已有指定格式或只借局部规则的情况。** 按 [可选规则](yizhong-visual-camera-options.md) 将所选画风、材质、美术及镜头方法补入当前格式，仍尽量保留源文有效表达。可用自然语言点名或V/T/G/K/E编号；本次选择在正文外简述，给模型的正文只写具体执行内容。

| 所选内容 | A格式位置 | B格式位置 |
|---|---|---|
| 主色、光线、影像质感 | 开头五项前缀中的全局视觉风格/光影色彩 | 开头五项前缀中的全局视觉风格/光影色彩 |
| 场景结构、材质、光源与背景活动 | 二、资产锁定的场景条目 | 资产的场景条目 |
| 方向、重力例外、阶段变化与接戏限制 | 四、最高优先级 | 最高优先级锁定／必要的物理接戏 |
| 起幅、前中后景、焦点、事件触发、运动与落幅 | 五、分镜中的摄影机参数 | 场景镜头说明；复杂时保留摄影机参数栏 |
| 材质反馈、背景分层、反应与道具接触 | 画面内容 | 场景箭头节拍／画面内容 |
| 声源距离、遮挡、混音起落与声桥 | 音效层 | 音效层／既有对白模块 |

同一信息只放一个主位置，逐镜补变化；每个独立生成段重述所需恒定条件。采用A/B时保留其字段，采用源格式时保留源格式；不并列重复两套总设定。只选镜头方法不连带换画风；细腻35mm颗粒不等于35mm焦段，变形镜头观感不决定输出画幅。已有摄影基底、媒介、画幅、时段和成熟高光优先；时长按实际完整节拍与用户要求安排，不为格式切换机械延长原文短场。

## 2. 每段资产：引用之后仍需描述

多图职责、素材与文字冲突、镜内状态调用，按 [资产绑定逻辑](asset-binding-logic.md) 处理。资产栏定义身份与初始状态，镜内写变化；参考图的机位、背景和打光是否继承逐项说明，不用一句“全参考”覆盖相互冲突的素材。

**先按资产类型选择描述字段，不能把“人物外观”套给场景、道具或声音。**

| 资产类型 | 简述内容 |
|---|---|
| 人物/造型 | 人物辨识特征、已知身高与体态、服装配色和结构、本段初始状态；面部参考与服装参考分别明确 |
| 场景/环境视图 | 空间结构、方位与层级、尺度、材质色调、光照、当前破坏状态及取景用途；不写人物五官或服装字段 |
| 道具/武器 | 形状、尺寸比例、材质、数量、刚性/可动结构、初始归属与使用状态；不套人物身高和服装字段 |
| 声线/音频 | 声线的音色、说话风格与所属角色，或环境音的声源和用途；不以视觉外观代替声音描述 |
| 首尾帧/视频参考 | 所锁定的构图、动作阶段或接戏状态及参考范围，不当作新增角色 |

每项同时说明“是什么”和“怎么用”。**每个入段角色，尤其女主的造型与服装，均主动给简短描述，无须等用户追问。** 通常一两句足够：已知身高与辨识特征、服装主色/主要结构、当前段初始状态；关键持物或特殊遮挡另补。保持与参考资料一致，未看图且文字未说明时标明待确认，不编造精确外貌。

面部身份与全身服装若是不同资产，分别标清参考职责；不从人物图继承其背景和打光。战损等动态状态写“起始为何、何时变化”，不要在资产栏先把整段人物锁成最终伤态。女主、男主、反派都适用，不只给女主添加描述。

```text
【角色】<有效绑定或【绑定：】>：姓名；已知身高、发型/辨识特征；服装主色和主要结构；本段起始状态。
【场景】<绑定>：入口、出口、层级、尺度、已有残骸与可破坏区域；仅供本段哪些镜头参考。
【道具】<绑定>：尺寸、材质、数量、初始持有者和允许的运动方式。
【声音】<绑定>：音色、情绪范围；只用于该角色，不把图片当声线。
【首尾帧/视频】<绑定>：锁定的构图或接戏状态；是否允许重构镜头。
```

### 适合作为资产的常见格式

沿用当前平台已有且确认的编号/引用。LibTV中的有效Node与用户给出的Mixed绑定不擅自互换；尚未提供资产时用【绑定：】，不猜编号。“可复制”不代表素材已自动上传、绑定或验证。

- 角色：全身/半身/三视图或四视图；背景干净、服装和比例一致。
- 场景：横向宽图，能读清入口、出口、层级、尺度和固定物件。
- 道具：单体、数量明确、轮廓完整；复杂武器补侧视或比例信息。
- 声音：每个角色单独的干净语音样本，避免混响和多人混声。
- 视频：作为首帧、尾帧、动作或连续性参考时明确用途，不要只写“参考视频”。

## 3. 分段与规则作用范围

先标场景边界和完整节拍，再尽量安排每段20–30秒，不能只在固定秒数处截断。换场前完成当前动作和反应，下一段从新场景可独立理解的状态开始；同场长战斗可在一次攻防后分离、威胁升级或救场交接处切段。不要在刀锋接触与受力结果之间断开。全片时长已定时不擅自拉长；尾段或短转场可以短于20秒，不靠无用镜头凑数。这里是创作分段惯例，不声明任何平台的固定时长上限。

每段独立写一句剧情和一句高光。高光概括本段，不沿用整片摘要；一句高光不限制镜内辅助亮点的数量。资产也按本段筛选，后段才出现的角色/场景不要提前混入当前绑定。

内部可维护全片身份、地理与状态连续性底稿；**交给模型的是各段自足的必要规则，不依赖“全片共用规则见上”。** 每段说明起始状态、发生变化的条件/时间及结束状态。动态限制不要写成全段绝对禁项：

- 肩伤在本段中途发生：起始未伤；接触之后才有对应衣料破损与伤势，禁止提前出现或伤侧跳变。
- 星球在末镜揭示：前面画外或虚化，指定镜头进入清晰构图；不能同时全段写“没有星球”和“后景始终巨大星球”。
- 武器在抱人时消失、之后重现：只在相应阶段限定，不同时锁死“全程在手”和“抱人无武器”。
- 环境残骸跨段持续：下一段资产和起幅简述已存在的破坏，不恢复完好，也不重放上一段爆炸。

下列字段按本段需要选取，融入最高优先级，非额外全片模板：

```text
【世界坐标】场景方向、地标和人物路线。
【屏幕方向】角色A始终由左向右；角色B初始位于高处/右侧。
【人物状态】伤势、服装湿度、情绪、可用肢体、持物手。
【数量锁定】角色、武器、动物和道具各自数量。
【物理规则】攻击、粒子、水、烟尘、破坏和受力怎样产生。
【特效规则】颜色、透明度、材质、速度、是否发光、消散方式。
【适用阶段】哪条规则整段有效、哪条仅在某镜/某事件后生效。
【连续性】上一段尾态如何成为本段起幅；镜内变化如何接到下一镜。
```

## 4. A镜内三栏模板与混合段补栏

战斗片段先执行 [战斗原文保真工作流](combat-source-workflow.md)：下列模板只保留字段边界，不取代相近原提示词的镜内句式和节奏。爆发动作允许按原文写“前情动态＋连续行动＋事件触发快切”，只在必要处标秒数；总镜长仍须配平，不把连续突进拆成逐秒停顿。配平不等于拉伸原文短冲刺或追加准备镜头；补写接口先融入现有动作，按[减法对照](029-scene-mechanics.md#91-审美保真与减法对照)核对新增内容的节奏代价与必要性。

区分“可适配的招式”和“需保留的关键表现”：前者按本次攻防与人物调整，动作干脆接续；后者依所选原文保留关键句式、触发节点及声画关系，按SKILL.md高优先级规则逐项核对。同步回看的不同机位在最高优先级和相关镜头明确标注同一次事件，帧数和延迟各归其原定事件，不能因统一格式而改成重复攻击或错误的先后顺序。

```text
镜头 <编号> | <起始–结束> | <持续秒数> | <景别/角度> | <切换方式>

【摄影机参数】
<焦段、机位高度与朝向、起幅构图>；<什么事件触发何种移动、焦点变化与速度>；<落幅>。

【画面内容】
<起始人物、重心、持物和景层>。①<时间范围>，<动作、目标、轨迹及受力结果>；②<时间范围>，<反动作、表演与环境反馈>；③<时间范围>，<后续动作及镜尾状态>。
有台词时在实际发生处写角色/有效声线、状态（处境）、语气、镜号与成片时间、画内/画外属性和准确台词；单句可就地写全，复杂时独立【对白模块】，尾音跨镜明确续入落点。

【音效层】
<动作拟音、环境底噪、声音远近与方向、与具体动作相对应的变化>。
```

## 5. 动作镜头示例

以下仅示范三栏写法，不是完整生成段。强度和破坏按本例的超常人物设定，不移植给普通人。

```text
镜头 03 | 00:06–00:10 | 4s | 中近景/贴地低机位 | 连续
【摄影机参数】35mm；贴地后拉跟拍；人物分居画面左右，保留进攻纵深；高速段使用方向性运动模糊，接触瞬间保留刀背与护臂轮廓。
【画面内容】A在左侧前冲，右手持刀，B在右侧后撤。6s—6.7s，A沿腰线横斩；6.7s—7.5s，B沉下重心，以硬质护臂斜顶刀背将刃线带向外侧，双方手臂震开；7.5s—8.4s，A借反震转髋回收，B跨步肘击；8.4s—9.2s，A侧身避开，B肘部撞上后方木栏，栏杆折裂；9.2s—10s，双方分离两米，视线重新锁定。A仍在左侧右手持刀；B喘息、右脚后撤，断栏不恢复。
【音效层】刀风、护臂与刀背的金属震鸣、鞋底摩擦、木栏折裂声。
```

## 6. 对白镜头示例

```text
镜头 02 | 00:05–00:13 | 8s | 双人近景 | 硬切
【摄影机参数】50mm、T2.8，与桌面齐高，缓慢前推二十厘米；起幅焦点在A，B停勺时转焦至B，说话时焦点回A，句尾再交给B的反应。
【画面内容】A在左侧靠窗，B在右侧靠外，杯子在两人之间。5s—6.5s，A垂眼、拇指轻压衣角；6.5s—7.5s，B停下搅拌抬眼；7.5s—11s，A抬头直视B，克制而略带歉意地说（画内）：“我只是还没想好怎么告诉你。”11s—13s，B眉峰轻抬后放松，点头。两人仍在原座位，杯子未被拿起，下一镜承接B的反应。
【对白模块】台词：A：“我只是还没想好怎么告诉你。”
配音指令：A｜沿用已确认声线（缺音频时待绑）｜状态（坐着，尚未说明原因）｜语气（克制、略带歉意）
对应镜头：镜头02，7.5s—11s，画内；口型同区间。无跨镜尾音。
【物理接戏】两人仍坐原位、杯子未动；下一镜接B点头后的目光与呼吸。
【音效层】杯勺轻碰、室内通风声、衣料摩擦，A的画内对白。
```

## 7. 负向约束模板

只保留和本段内容直接相关的风险，禁止项的时间范围不能否定本段之后的合法变化：

```text
【负向约束】人物身份互换、左右位置跳变、道具增殖、持物手改变、无接触破坏、动作无惯性、口型不同步、字幕、水印、BGM。
```

## 8. 篇幅与正文之外的记录

不设统一字数下限。篇幅由本段时长、事件数量、对白和必要约束决定，用户长度要求优先；短文戏通常比同长度复杂战斗轻。比较相近原文的密度以发现重复，不把评估报告的启发式分类中位数当硬指标。先删重复资产、泛化形容词和无用规则，不删原文关键动作／声画节点，也不靠拉慢动作填时长。新故事的场面衔接按 [原文场面机制第9节](029-scene-mechanics.md#9-如何产生新故事而不稀释原文) 检查。

可简述“本版已补入”的关键设计和少量“可选创意（未采用）”。建议写清插入位置、具体动作、预期效果、是否改变设定或增加素材，不把相斥备选同时塞入正文。来源案例、创作分析和检查结果不让用户一起复制。

没有重大待选项时直接交付完整本版，不因可选点子停下来等确认。缺素材时明确哪些【绑定：】需用户补齐；不要声称已经绑定或可无素材直接达到身份一致性。不自动上传、运行生成或消耗外部额度。

完整成稿可在正文外保留段落ID/版本、来源、关键表现与待验证项；收到成片后按 [生成后回填](generation-feedback.md)逐项核验。难度是结构推断，不是可靠性；只完成文字校验时不报告成片还原率。用户只要提示词时不展示记录和分析。
