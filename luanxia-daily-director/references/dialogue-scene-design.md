# 对局、日常与关系场面设计

用于新写或增强对白、对峙、喜剧和关系戏；仅改字词时不加载整套方法。以下是从归档提炼的设计工具，不是每场必填七步，也不是作者原意或成片实测。格式见 [统一成品格式](unified-format.md)；具体借用桥段时完整阅读对应原文。

## 1. 先编人物如何改变彼此，再编镜头

内部先写一条短线：**谁要什么 → 对方掌握什么条件 → 怎样试探、拒绝、加压或照顾 → 什么信息/行动令回应改变 → 选择落在哪个可见动作 → 结束后留下什么关系或任务状态。**

“对局”包含禁令与回敬、身份试探、误会解除；日常关心也可以只用“负担—察觉—帮助—接受”。没有冲突的喂药、同行不强加摊牌、翻脸或权力争夺。已定关系可只被揭示、确认或暂时悬置，不要求每场改变亲疏。

每次关键回应要改变一个东西：下一步行动、信息可得性、说话主动权、对物件的控制或对方判断。不能只轮流说设定；也不要求每句都有手势。先决定观众知道多少、听者何时知道，再安排看说话者还是反应者。

## 2. 权力关系由行为证明

可选用高低位、谁先进入/离开、谁让路、谁能中断对方、谁控制门槛或物件、谁主动缩短距离承载地位。镜头高度只是表现手段，不是“高处必然地位高”的公式；病者被俯拍也可以拥有决定权。

锁定空间关系后，让一次回应改变观看方式。例如桥上禁令先以声源和仰视建立控制，桥下人物不退、抬眼回敬并迈向边界，证明禁令未被接受；是否升级为投剑由当前剧情决定，不能从 WX1 自动续写一场战斗。

原库锚点：P4 WX1 的禁令/挑衅；P1 LX6 的上下层互看；LX14 的身份确认后递纸笔与谄媚请求。迁移社会动作，勿默认继承峰主、舰长或签名情节。

## 3. 笑点要有铺垫、揭示与承接

选择一条适合人物的短链：**建立正常预期 → 藏住一个有迹可循的信息 → 用动作/机位/台词揭示反差 → 留给另一人消化或回敬 → 结果承接下一行动。** 不把“逗笑”当作可见事件，不靠所有人同时夸张表情代替结构。

- WX5：先见得意神态和对手懊恼，后拉才揭示脚在操控手柄，台词兑现差距，听者以轻度吐舌回应。若提前全景展示手柄，笑点已变，不能仍写成延迟揭示。
- LX14：先有“你谁啊”的试探，介绍身份后恭敬递纸笔，最后贴近镜头说“签个名呗，偶像”。转变有信息触发，谄媚不是突然换人格。
- SC12-1：误会引发搭弓，身份信息使攻击取消，白猫再轻惩戒。借结构时保留“认出—取消—回应”，不自动增加窥视角度或把轻惩戒升级为灾难。
- WX4：更大威胁使原对峙失去意义，两人同时泄气形成共同反应。必须先让观众读到威胁；没有该前提的同时躺倒只是姿势。

节奏按台词长度、动作与反应时间配平。短停顿可以是手停、视线迟到或未说完的半句，不统一规定固定秒数，不为了凑笑点另插准备拍。

## 4. 关系变化用可见证据承载

选本场有关的一项：戒备/信任、疏远/接纳、依赖/自主、对立/暂时同向。内部核对 **起始证据 → 触发 → 反应 → 结束证据**；关系不变时说明本场揭示了什么即可，不在复制正文里写心理评分。

可见证据来自距离、是否接受触碰/帮助、视线停留、手部由攥紧到放松、物件归属或共同面向一个目标。情绪词须落在这些动作上，但不要为每种情绪叠加全部动作，也不凭一次微笑擅定恋爱或阵营变化。

WX6 中喂药、放勺、手攥紧、眼神亮起、转向同伴和名字确认各有作用；只借眼神弧线时不自动继承喂药、伤手或卡通小人。WX5 的痛声中断游戏练习、随后抚背，是注意力转向照顾的证据。SC3.5 -2 的闭眼接受局面是合法收束，不为增加动作继续开战。

## 5. 表演、调度与声音一起编

先确定谁此刻掌握信息、视线指向谁/什么、手或步伐被哪句改变，再选保焦、转焦、摇摄、让位或切反应。人物持续进行的任务不因说话消失；第三人要有原位置与进入动机。

说话条件与语气分开：**状态（处境）**写刚落地、湿透、疼痛、被打断等身体/情境条件；**语气**写克制、急切、轻快等表达方式。声线继承有效音频/已确认描述，不猜 VoiceID。对白时间、口型区间、画内/同地画外/通讯/内心属性见统一格式；尾音跨镜时写接到哪一镜、哪个反应节点，受话者可以在尾音未落时回敬，但双方完整台词仍要可辨。

## 7. 文戏交付前检查

能否指出一处信息、选择或关系被揭示/改变的可见证据？笑点的反差信息是否提前泄露？台词与动作是否互相触发？声音桥是否有来源和落点？已定关系、结果和台词是否保留？若没有这些证据，先修事件与表演，不靠更多焦段、冲击帧或形容词补足。
