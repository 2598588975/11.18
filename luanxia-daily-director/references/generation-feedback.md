# 成片证据与生成后回填

用于用户提交成片/截图/失败描述，或要求保存生成记录、复盘实测。文字成稿不能证明效果；本库没有随本次优化新增实测样本。不要从难度或原句强度推算还原百分比，也不把本文模板填成虚构测试数据。

## 1. 成稿留下可追踪的小记录

完整提示词在复制正文之外可给一个段落标识，例如 LX-日期-项目简称-S01-v01；未知日期或项目用用户已有段名加版本，不猜。内部/当前对话记录 **标识｜采用底稿（文件＋nodeKey）/新编｜关键表现｜必要适配与修正｜尚未验证项**。普通改一句不强加记录流程；用户只要正文时省略展示。

需要保存时写入当前项目的记录文件或用户指定位置，保存最终提示词并用内容SHA-256关联版本。不要自动改skill归档、原文或全局排行榜，不自动启动生成、上传或消耗额度。无项目保存位置时可交付可复制记录，不为建记录阻塞成稿。

## 2. 证据等级与观察单位

分别标记：**待生成；已生成未审看；用户反馈；已看片核验**。截图只能核验该瞬间的外观/构图，不能证明速度、接戏、整段声画与帧级时长；仅有描述时标明“用户反馈，未独立看片”。不可读视频或未提供媒体时，说明具体无法核验的表现项。

每个关键表现逐项记 **出现 / 部分出现 / 未出现 / 出现但错误 / 无法判断**，绑定成片时间区间和证据。文字中已经写了某效果不算“出现”。先看本场主事件与人物选择，再看视听机制、身份/物件连续性、关系与笑点兑现；没有台词的段落不填口型测试。

可复制的记录模板（仅保存记录时填写）：

~~~text
记录ID与版本：
提示词文件/内容哈希：
源案例：文件、标题、nodeKey；或新编
生成环境：平台/模型与版本（未知如实写未知）、入口、实际时长/画幅/帧率、资产版本、seed（入口有提供才记）
关键表现：镜/节点｜预期可见结果｜对应源机制或用户要求
证据：视频文件/可访问引用；观察区间；已看片/截图/用户反馈
观察：每项出现/部分/未出现/错误/无法判断；实际发生了什么
诊断：文本矛盾/资产冲突/时长容量/声画对齐/生成波动；证据与尚未排除原因
下一版：修改的单一主要变量；保持项；需要重看哪些节点
~~~

## 3. 从失败回到小改动

先定位具体镜/时间区间与实际偏差，再复核相关文本和资产。文本无接刀、时间重叠、声线引用错配等已有明确证据时先修它；文本逻辑成立但模型没执行时，才提出拆镜、降低同窗事件密度、调整可见参照或资产等实验。不要单凭一次失败宣称模型做不到。

一次优先改变一个主要变量，保留其他核心条件。对比新旧成片的同一表现项，同时检查有没有破坏原有高光或关系落点。不得在用户只要求诊断时自动替换已确认结果；必要的降级作为有代价的选择，不直接丢掉主高光。

## 4. 难度与实测可靠性分别记录

| 结构负担（推断） | 文本特征 | 写作时优先核对 |
|---|---|---|
| L1 单一事件 | 单次接触、一个主要可读结果、少量物件 | 接触与后果是否有观察空间 |
| L2 多条件联动 | 多视点同步、分层能量、多人/巨物局部、对白声桥 | 时间锚、身份、资产职责和主次是否明确 |
| L3 高密度或极端跨度 | 帧级突进、短窗多次转移、极端尺度同框、复杂空间与表演并行 | 容量是否自洽，关键节点是否可分开阅读 |

L1/L2/L3只评结构负担，均不能称“稳定/不稳定”；语速、资产、入口变化也会改变负担。主高光复杂时保留意图，先压缩冗余，需拆镜/降级再说明代价，不自动把L3全部改成普通攻击。

实测统计按相同模型/入口、资产、主要设置与表现目标分组，逐项报告“命中数/可判断样本数”，部分、错误与无法判断单列；一次生成内部的多个帧/机位不能算多次独立样本。未知环境、截图与用户口述不混入已看片命中率。样本不足时保留“仅该样本”，不建立假精确排序；重复命中也仅说明该组条件下的观察。

只有用户要求维护skill、且重复证据支持可迁移修正时，才把失败模式回补相应方法与索引，并保留原条件、反例及日期。原始提示词继续保持来源快照；不把某一模型的偶然错误升级为所有项目的禁令。
