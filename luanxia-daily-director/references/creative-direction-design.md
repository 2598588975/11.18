# 从小创意到导演设计

用于从小创意到构思、剧本、分镜的各阶段，不等成稿后才装饰镜头。这里只规定构思方法，不给所有场景套同一种结构。战斗另读 [战斗创意编排](combat-creative-design.md)；回查全库案例用 [逐段方法索引](029-directing-pattern-catalog.md)。

## 0. 在哪个阶段，补哪一层

构思阶段就能决定“她看似从容，其实正在把敌人引向一处陷阱”“观众以为攻击结束，破坏却还在远处延伸”。剧本阶段把这种期待与回报落实为可见行为，让环境提前出现、能力先有线索、对手作出有个性的判断。分镜阶段才精确安排先看脚还是脸、哪个声音先入、何时转焦与切镜。

同一小创意可贯穿三层。例如用户说“她手里的火很轻盈”：构思时可利用轻盈火焰与敌人沉重步伐作力量反差；剧本时让火球被气浪吹偏、她主动修正路线，表现灵巧并推动攻防；分镜时以浮焰细丝、手掌微调、火球整体脱手和远处命中兑现。是否能控向、是否失手仍服从角色设定，不凭审美新增能力。

无需每次交付三个阶段的全文。构思或剧本通常是输入起点，默认内部完成丰富与转译，交付适合场面职责的A/B完整视频提示词；仅在用户明确说“先讨论”“只写剧本”“先让我检查”等时停在该阶段。导演思维可以从画面反推事件，不限于按步骤单向往下填。

### 按段落职责选择设计方法

战斗与重点视觉高光沿用已有格式和原文优先流程，成熟表达以保真、适配和必要纠错为主。对话、场景移动、关系展开与故事展开则可直接按导演思维链设计：先确定本场人物想达成什么、观众何时获知什么，再让言语改变动作或关系，由动作、视线和声音触发机位与焦点，最终落到结果与接戏。有贴合原文桥段可以借鉴，但不是自主设计的前置条件，也不强制复刻其机位顺序。对白里的信息转折不因被称作“亮点”就必须套战斗高光。混合场面按节点分工，保留用户指定或当前稿格式；新稿按统一格式选择A/B，混合段不重复总设定。

### 主动补足与可选建议

创意的重点是原提示词没有直接对应的新段落，不是给已有成熟参考镜头再加花样。先区分已选用的直接参考段与待新编段，在后者前期给一至三条值得讨论的创意，不硬凑数量，也不等成稿后才提出。建议用“放在哪里／具体怎么做／为什么适合人物与当前场面／新编边界及可借的方法／对时长或设定的影响”说明；有方法借鉴不等于有直接原文底稿。相邻的成熟参考段主要保真和适配，只有用户要求或确有冲突才另行改变。未采用的选项保持为备选，不混入执行正文。任务范围内的普通对白、走位、信息揭示与关系推进无需逐个小点审批；关键改变已定内容的方案仍先讨论。直接要成稿时也不因可选点子停工，沿已定要求完成本版并把备选放外面。简短局部校对无需强塞创意提案。

先区分新写与修订：已有成熟原文高光以保留、资产适配和必要纠错为主，不把未新增技巧视为不够创意；新写对白和叙事段落可正常构建，无需先证明存在缺口。需要借鉴时，可从全库选择功能相近的案例：缺悬念，找声音先行与延迟揭示；缺人物味道，找小动作、反应与强弱反差；缺战术，找借力、反制与环境利用。需要具体借鉴时读对应原文，不能只凭案例标题编造原句或声称有效。

可以搭配不同案例的机制，但它们须服务同一目的。例如“腿部步频钩子＋画外脚步先行＋遮挡移开露出后景人物”可以共同表达被跟踪感；若主角已经看清追兵，再用同一套延迟身份揭示就可能重复。搭配后检查空间、能力、道具和时长，不把来源人物的专属动作、颜色或战力一并移植。先用本skill已有方法；其他当前可用skill确有补益时才按其适用范围调用，不为一次小创意默认加载一串技能。

分清两类补充：

- **本版已融入**：确实解决已识别缺口、不改变既定剧情与成熟镜头表达的过渡、表演、战术细节、铺垫回收和声画节奏，可写入本版，必要时在正文外简述改了哪里。“没有改胜负”不自动证明新增动作或光效值得保留。仅有构思时，可在既定前提内补人物动机和事件因果；重要暂定项明示。
- **可选创意，未采用**：改变能力、关系、胜负、伤势、已确认台词，或明显增加新角色/场景/资产的方案，不混入正式正文。用“放在哪里＋具体怎么做＋预期效果＋是否改变设定/增加素材”简述，并推荐最合适者。若是完成当前版本不可绕开的关键选择，先询问；若只是锦上添花，可先交付不含它的完整版本。

值得提出时通常给一至三条有区别的建议，不硬凑数量；用户要求只给正文时省去解释和备选。建议可以来自构思、剧情或镜头层，不限于增加特效。不要为每项小补充都等待审批，也不要把尚未采用的点子写成“也可以A或B”塞给视频模型。

对白、对峙、笑点或关系主导的新写/增强任务，同时使用 [对局与关系场面](dialogue-scene-design.md)，把自主设计落成回应、信息变化与可见关系证据；安静关心不强加对抗。

## 1. 先设计观众的发现过程

用户只说“帅气、压迫、灵巧、可爱”时，不止换形容词。先决定观众先看见什么、暂时不知道什么、哪个动作或声音让信息翻转、揭示后留什么反应。

把创意展开为：**用户的具体点子 → 希望观众产生的感受 → 可见铺垫 → 揭示/反差 → 角色回应 → 后续结果**。链条可短可长，不要求每镜六步齐全。例如“站在巨物头上”的精髓并非站姿本身，而是先从巨物的反应建立尺寸和疑问，再揭示危险位置上人物异常平静的姿态。

已有定稿时保留剧情结果、对白和资产规则，再补相应层次。改变已定胜负、人物关系、伤势或新增关键能力不是单纯表现优化，应先说明并取得选择。开放构思时可在用户给定前提内发展情节，不必为每个正常创作细节提问；影响世界观的新设定标为建议。仅改一句或一镜时局部补足，不自动重写全片。

## 2. 选择手法的理由

| 想实现的效果 | 可以选择的设计 | 不要误用成 |
|---|---|---|
| 有辨识度的登场 | 鞋底接触、腿部步态、刀尖、手上小动作先入画；停步/声响触发上摇或转焦揭脸 | 每个女性都从腿向上扫描 |
| 暂隐身份、先立性格 | 主人公尚未露面，已从脚步速度、稳重落脚、旁人反应或画外一句话知道其态度 | 无目的延迟露人 |
| 地位与尺度反差 | 巨物眼部/局部作尺度参照，循视线揭示小人物占据反常高位；动作松、环境紧 | 每场复制踩头、发光瞳孔 |
| 活的空间层次 | 前景短暂经过者，中景主行动，后景独立任务；声源或视线决定是否交接焦点 | 所有人同时做同一动作、抢同一句台词 |
| 惊讶、威胁进入 | 先听到画外声/看到局部反光，再看人物反应，最后揭示来源 | 摄影机无端提前知道危险在哪里 |
| 用动作换场或藏剪口 | 人、衣摆、兽鬃、碎屑贴近镜头短时遮挡，出遮挡后交付新信息 | 每过一个人就切镜、遮掉关键接触 |
| 轻松转紧张 | 让闲置者继续小动作；报警/一句话令动作中断，视线与机位一起稳定下来 | 用无关大爆炸代替表演 |
| 余味与关系 | 人物出画后继续听短对白，画面落在共同关心的物件或环境 | 结尾黑屏、对白仍无来由拖长 |

这是候选库，不是打勾配额。只在当前表达确有缺口时选择适合的设计；已有有效表达不再强加一层装饰，用户也不必先声明“克制”才能获得有取舍的镜头。用户明确要无人物、固定机位等时服从该限制。无人场景可用现有门框、断板或烟尘做前景，不能为层次擅自添加路人。

### 脚部、腿部开场如何不空泛

给局部镜头一个事件：靴底擦停留下细痕、悬空脚尖停住晃动、步频被画外声打断、刀尖擦过脚边而脚未退。交代支撑面和身体重心；再由停步、抬眼、走近或声音触发揭示人物。低机位不等于贴地，也不自动等于仰拍裙底。未要求时不添加暴露或窥视角度；人物魅力由姿态、材质、光线和从容程度表达。

可参考 P1 LX14（下半身作前景、转焦来人）、P2 SC1-1（腿部上摇与环绕）、P3 SC10-1/2（悬脚和纸偶小动作配画外音）、WX5（足部起幅接行走对白）。它们的叙事任务不同，不能只学“先拍腿”。

### 前景遮挡的四种不同任务

- **遮挡但不交焦**：前景人快速走过，焦点始终锁在后景主角；看的是主角如何等候或反应。
- **遮挡后交焦**：来人脚步/声音引起主角抬眼，前景移开时焦点交给来人；不是无动机自动追焦。
- **遮挡藏切**：按[C01动态前景遮挡转场](camera-movement-library.md#c01)，可在段落中途借斗篷／衣摆、翼膜或马身等贴镜扫满画面藏切，再移出露下一镜；保持来向、节奏、持物和动作相位，遮挡物服从本场设定。用于动作或视角接续，不默认做30秒段落的片尾盖黑；注明这是剪辑，不伪称连续穿越实体。
- **揭示式遮挡**：前景衣摆移开露出后景一直存在的人或物；新的是观众的信息，不是角色凭空生成。

每次选清楚一种主用途；短暂遮挡后观众必须更明白场面，而不是更迷路。

## 3. 镜头运动要改变信息

新写或优化打斗、追逐、创意高光时，主动查[24项运镜库](camera-movement-library.md)的索引与[场面调用规则](camera-movement-library.md#invocation-rules)，按关键节拍选镜头；其他段落需要具体路径、视点或光学方案时再查匹配条目。运镜可用于情绪与节奏增强，已有成熟参考有效时保留，用户已定动作与高光优先；不设技巧配额，也不为凑方法重复信息。

战斗的起手、换位、时间强调与后果交接，另按[15项战斗用法](combat-camera-methods.md#快速索引)选读；与原24项通过映射衔接，既可细化已有跟拍／环绕，也可选攻击物跟随、接触短停和结果拉远，不把所有技巧叠进同一镜。

| 运镜/光学手法 | 用途与执行要点 |
|---|---|
| 上摇/下摇 | 沿视线或身体动作连接两个信息，不用“上移”混称机位升降；必要时保留接触面显示角色站在哪里 |
| 景深切换 | 前后对象都已在同一空间内；写谁先清楚、谁的动作/声音触发、何时交焦；并非把所有景层同时拉清 |
| 斜前跟随→推进正脸 | 跟住躯干转向后逐步靠近正面，脸上已有决心变化再推近；若继续正面突进，机位在人物前方后撤，不能切成背后追拍 |
| 环绕 | 随关系改变揭示第三人、出口或新威胁；预先给出沿哪侧弧线及落幅方向，越轴需可读的过渡 |
| 荷兰角 | 用倾斜地平线强化失衡、压迫或攻击斜线；保持一个有意义的倾斜方向，局面恢复控制时可回正，不每镜随机左右歪 |
| 极速跟摇/爆发推拉 | 起势到接触之间追踪主轨迹；交手节点短暂读清受力，随结果急停或减速，不全程均匀乱晃 |
| 短时失焦后拉实 | 可表现突发揭示时摄影机追不上；如源例0.4s，只用于需要的揭示瞬间，回焦后留出眼神/姿态阅读时间，不把失焦覆盖决定性接触 |
| 希区柯克变焦（Dolly Zoom） | 推拉机位与反向变焦配合，主体画面尺寸近似不变、背景透视改变，用于认知突变；不等于普通推近或拉焦 |
| 滚转/FPV | 沿一条可追踪轨迹呈现穿越与空间翻转；先立路径，落幅重新建立方向；不是每次挥刀转一圈 |
| 镜头继续走、人物停下 | 摄影机运动惯性延续，逐步露出人物身后一直存在的景物；适合延迟揭示，不能把天体或武器直接变出来 |

“摄影机过量摆动”只放在需要失衡的段落；人物、兵刃、碰撞轮廓仍需间歇可辨。一次短动作选一个主导运动即可；不在同一半秒要求环绕、滚转、变焦、拉焦全部完成。

## 4. 声音在画面之外继续导演

区分：**空间内画外对白**（人存在但不入画）、**内心独白**（嘴不动、主观听感）、**跨镜声音桥**（前镜尾音延续或下镜声音先行）、**客观旁白**。不可统称画外音后随意混用。

- 声音先行：先听高处一声，再拍抬头反应，再上摇见说话者；镜头依据声源转向。
- 画面先行：镜头暂留受话者的反应，说话者仍在画外，随后再切回；避免句句正反打。
- 台词与小动作互相改变：漫不经心地把玩→听到关键词手停→视线抬起，比同时写三种情绪更明确。
- 环境声桥：远处爆炸尾响接下一地点时降低高频与响度、改变混响，不把远爆写成贴耳轰鸣。
- 收声再爆发：短暂收风声/能量声后释放，写清收去的是哪层；不是每招全片绝对静音。无BGM时不添加鼓点、弦乐铺底或把道具声写成持续配乐。

有用户已定台词时逐字保留；对话不能为了运镜被改成内心独白，也不能塞在屏息、吐息或失去意识的动作中。

## 5. 节奏与审美取舍

一段可有一个主高光和数个辅助亮点，强弱要分级：细节钩子让人看进去，转折令局势变化，主高光兑现，余波让人相信刚才发生过。高潮前的平静不是让角色站桩等攻击，而可以是稳住手、看清破绽、收风、落脚等有效动作。

开放构思或确需重设计时可比较不同呈现机制，再选最贴人物的一种；成熟原文适配不强制另造替代高光，不必把内部候选全列给用户。若去掉荷兰角、光效和响声后，这段仍只是“你打一下我挡一下”，须先补策略或信息变化。反之，安静对白已有表演支点，就不要硬加战斗式冲击帧。

新增表演、光效或运镜须同时通过两个判断：在本场是否合理，是否真的改善当前表达。光源合理不等于扫脸光有必要；人物冷静、背景猛烈的反差已经成立时，不为强化表情额外加光带、挑眉或停顿。按[审美保真与减法对照](029-scene-mechanics.md#91-审美保真与减法对照)撤掉无收益的增加，不把某种光效本身列为全局禁项。

## 6. 小创意补足示例（新写示范，不是归档原文）

用户种子：“她走来，后面还有一个人，有点不安，但不要增加对白。”

可写为6秒一镜：50mm低位中近景，焦点在前景女主靴子；0–1.5s，她走过一道地面灯带，鞋跟略顿，镜头随步向上摇至侧脸。1.5–3s，她没有回头，先停下捻动手套边缘的拇指；后方第二组脚步仍多响一步。3–4.5s，她从镜头近侧走出，衣袖短暂遮住右半画面，焦点由她转到走廊中景原本被挡住的同行者。4.5–6s，同行者在同一灯带前停住，目光越过她追向画外；机位缓停，保留两人之间的空距离。光照、衣摆余动与脚步远近维持，无新增人物和台词。

核心不是照搬这六秒，而是把“后景有人”变成两组步频、一次停顿和一次揭示，让现有信息产生情绪。
