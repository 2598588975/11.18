# AI视频提示词拆解与加固规则

本参考用于拆解现有提示词、提炼可迁移规则，或在乱霞号提示词中加固震撼场面、镜头节奏、武器/能量特效和否定式约束。它吸收的是方法，不继承案例中的人物名、资产槽位、尺寸、摄影机型号或项目专属设定。

## 1. 先分清六层

把一条复杂提示词拆为“五个约束层 + 一个执行层”，不要把所有内容混成一段。

1. **剧情与高光**：一句话说明谁要做什么，以及观众应记住的视觉事件。
2. **资产锁定**：角色、声线、场景、道具、武器、首尾帧及不可变项。槽位/Node 是绑定标识，不是可跨项目复用的编号。
3. **成片规格**：时长、画幅、媒介、摄影基底、声音、字幕、水印和禁用项。
4. **特效与物理方案**：能量构成、形成顺序、受力、环境反馈、残留与消散。
5. **最高优先级约束**：只收录会造成身份、结构、空间、数量、动作意图或连续性崩坏的硬约束。
6. **分镜执行**：镜号、时间码、景别、机位运动、可见动作、表演、对白、音效和落幅。

约束强度应逐层上升。先给叙事目标，再锁资产和全局规则，最后才用最高优先级堵模型默认行为。拆解别人提示词时，先把原句归层，再判断缺项；不要把原句顺序直接当成合理结构。

## 2. 拆解流程

### 第一步：建立不变量与变量

- 不变量：身份、脸、服装状态、声线、武器结构、持物手、数量、空间轴线、时间/天气、画幅和明确禁项。
- 变量：镜头路径、动作节拍、光效细节、声音质感、环境反馈和落幅方式。
- 同一角色/道具跨段落时核对引用是否一致；不同项目、不同状态或不同资产表不能沿用槽位号或 nodeKey。

### 第二步：把形容词改成证据

对“震撼、快速、巨大、电影感、能量很强”等词逐一追问：画面里凭什么看得出来？

- 快：入画帧数、移动距离、前景掠过、抽帧、音爆、衣料拖尾、急停与落幅微震。
- 大：人物/建筑/地标参照、前中远景分层、距离、占画比例和镜头高度。
- 强：接触点、环境介质失真、尘屑/水面/地面响应、摄影机震颤、光照变化。
- 电影感：焦段与机位、景深、构图层次、动态范围、暗部细节、高光层次、散景和运动方式。

数字必须服务空间、时间或比例，不能只为显得专业。未锁帧率时，可保留“显示 3 帧”等成片意图，不擅自换算秒数。

### 第三步：补齐因果链

普通动作最小链：

```text
意图/触发 → 发力与起点 → 轨迹 → 接触或闪避 → 双方反馈 → 环境反馈 → 分离状态 → 落幅
```

破坏动作必须写成：

```text
动作 → 破坏对象 → 破坏方式 → 破坏后产物 → 残留/消散时长
```

例：不要只写“斩出雷电”。应说明雷电从何处产生、沿什么路径击中何物、目标如何碎裂、形成何种碎屑，烟尘/碎屑在冲击后持续多久。只有吹飞就写吹飞；需要碎裂时明确“不是被吹散，而是碎裂成……”。

一次击打至少检查两端：受击方的位移/重心/表情，施击方的反作用力/收势；柔性物按惯性延迟摆动，方向通常与加速方向相反。

### 第四步：检查时间与节奏

- 升格必须写起点、终点、持续时间以及恢复常速节点。
- 抽帧/跳帧用于超常速度错觉；不与升格在同一动作时刻含混叠加。
- 冲击帧标明帧数、触发点和影响范围，例如画幅级黑白反转或从画外突入。
- 全程高速会稀释速度感；优先使用“快 → 慢 → 快 → 停”的速度包络。
- 高速爆发后留 0.3–1 秒左右的稳定落幅只是一种常见选择，实际时长以剧情、总时长和用户要求为准。

### 第五步：检查机位是否承担叙事

运镜写成：

```text
基础动作 + 速度/加速度 + 幅度或路径 + 触发点 + 焦点交接 + 终点机位 + 落幅
```

- 景深切换用于在同一镜头内交替强调两个信息源，不只是装饰。
- 环绕用于不切镜地改变人物关系和空间信息。
- 前推/跟拍用于代入冲刺；若要求镜头与主体完全同步，明确“严格绑定轨迹、无相对漂移”。
- 景别越小越适合情绪，越大越适合规模；动作需要身体空间时不要一直困在脸部特写。
- 长镜与快切可混合：长镜负责空间和蓄势，快切负责爆发与信息压缩。

## 3. 震撼场面的六个维度

不是每场都必须全部使用，但大型动作/VFX场面应逐项判断。

1. **实质化破坏**：世界留下可见、可持续的物理结果。
2. **量化参数**：距离、尺寸、时长、帧数、数量或占画比例形成尺度证据。
3. **极端但可执行的机位**：快速、幅度和路径明确，避免只写“震撼环绕”。
4. **快慢对位**：抽帧/闪入与升格形成速度反差。
5. **冲击帧与画外突入**：用瞬时构图/色彩反差制造打击点。
6. **环境辐射**：特效影响空气、光、地面、碎屑、衣料、声音或摄影机。

## 4. 光效、武器与生成过程

### 通用能量四层

```text
内芯 + 外沿 + 环境反馈 + 动态构件
```

- 内芯：亮度、颜色、密度与材质感。
- 外沿：边缘颜色、厚度、锐度、辉光或电弧等结构。
- 环境反馈：空气折射/扭曲、局部照明、尘屑受力、表面反光、声压或机震。
- 动态构件：脉冲、呼吸、旋转、粒子交换、延迟爆开或衰减规律。

“流体般涌动”若不希望变成液体，必须补“仅描述运动连续性，不是液体、无滴落/飞溅”。特效写清来源、形成、维持、作用、衰减与终点，不允许只写常驻光团。

### 弓箭/生成型武器三阶段

```text
凝聚/汇聚 → 成形与瞄准 → 射出、取消或消解
```

- 用“凝聚/汇聚”替代“突然出现”，并给出物质或能量来源。
- 第三阶段服从剧情；若角色取消攻击，明确消解而非射出，堵住模型自动补全“射出—命中”。
- 弓、箭、尾坠等独立变化部件分别锁定，写清数量、连接关系和是否允许变化。

### 刚性武器结构锁定

最高优先级至少包含：

1. 锁定结构关系，而非只写整体外形。
2. 逐件列出刃、柄、护手、链、坠等组成。
3. 写明不可变形、缺失、融合、断裂或混乱的项。
4. 锁定数量、比例、持物手和部件位置，禁止复制与换手。

## 5. 排除式定义与最高优先级

排除式定义用于纠正模型高概率的默认解释，格式是：

```text
必须出现的可验证结果；不是/禁止出现的错误结果。
```

只对高风险误读使用。例如：

- 纸质目标“碎裂成细纸屑，不是被风吹散”。
- 能量“呈流体般连续运动，但不是液体”。
- 角色“位于同一轴线两端之间的中点”，而非“在附近”。
- 一镜到底时枚举“不得转场、跳变、溶解、切镜”。

空间关系尽量写成轴线、角度、距离、屏幕左右和前中后景；“旁边、附近、中间”只有在无须精确调度时才使用。负向约束不是同义词垃圾桶，每一项都应能回答“它堵住了哪个默认错误”。

## 6. 声音与落幅

音效与画面分栏。单个动作音效按下式写：

```text
声源 + 动作 + 材质 + 质感 + 距离/方向/空间混响
```

例：远景纸片群汇聚，纸质摩擦形成低沉浪潮声，来自画面右后方，带空旷街道长混响。多个音效拆成短句并与动作节点同步，不写成无法定位的一整段。

落幅必须给状态和时长：人物位置/朝向/持物、特效残留、环境破坏、摄影机是否静止或余震，以及下一镜必须承接的条件。动作片用落幅释放冲击；幽默/对白场面用停顿完成反应与节奏。

## 7. 摄影机品牌词的处理

ARRI ALEXA 65 等词可以作为风格触发词，但不能视为模型会准确模拟传感器、透视或色彩科学。用户明确要求时保留，并同时翻译为可执行结果，例如：

- 大画幅空间纵深与前中远景分离；
- 主体清晰、背景柔和虚化；
- 夜景暗部仍有材质细节，高亮特效保留层次；
- 宽画幅构图中主体与规模关系清楚。

不要复述未经核验的品牌历史、传感器尺寸或动态范围数字；本技能只需要能改变生成结果的视觉语言。

## 8. 拆解报告的最小输出

用户只要求“拆解”时，默认输出：

1. 原提示词的一句话机制总结。
2. 六层归类表或分层条目。
3. 有效写法：原机制 → 为什么有效 → 可迁移模板。
4. 高风险缺口：具体会生成什么错误。
5. 加固建议：给出可直接替换/追加的中文句子。
6. 若用户要求，输出按本 skill 完整重写后的提示词，并执行质量清单。

不要把案例专有名词、槽位号、比例、镜头秒数或角色关系冒充通用规则。
