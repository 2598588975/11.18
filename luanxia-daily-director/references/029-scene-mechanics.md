# 从原句到新故事：场面如何运转

用途：创作新的战斗、行走对白、场内调度，或修复“像在慢跑／有运镜却没有信息变化”时，按本场任务选读。战斗与重点视觉高光按原文优先流程完整阅读所选底稿；对白与叙事调度可依导演思维链自行设计，有贴合桥段再选读，实际采用时须完整阅读该原文。本文件解释机制，不替代所引用的原文底稿。资产问题另读 [资产绑定逻辑](asset-binding-logic.md)。

依据：2026-09-27复读当前本地P1/P2/P3的60份非空视频提示词及早期WX1–WX6，重复原句核对后复用、变体分别比较。来源为 [P1](029-p1-media-prompts.md)、[P2](029-p2-media-prompts.md)、[P3](029-p3-media-prompts.md)、[早期WX](libtv-original-prompts.md)。2026-09-28 新增的 [P4](029-p4-media-prompts.md) 中 WX1—WX6 经逐字比较与早期 WX 完全一致，因此没有为本页引入新的视频样本或新规则。本次未观看成片；不是新一轮全部图片与旧文本节点审计。以下“原句”与“理解／适配”分开，不能把理解伪称作者原意或实测结论。

## 1. 保留的是事件、视点和节拍的关系

原文不是动作词＋摄影术语清单。常见组织是：人物已在行动 → 阻力进入 → 角色顺势回应 → 镜头换到最能读懂这一刻的位置 → 接触／释放 → 结果接管画面。声音、衣料和环境继续运动，承接被剪掉的空间与时间。

内部识别四条同步线：**身体与武器做什么；摄影机在哪里移动；焦点／遮挡让观众看到什么；哪一层声音何时响起或退出。** 不把四条线各写成互不相干的段落。镜头可以固定，角色可以暂不动；重要的是此刻的信息与力量关系是否变化。

用户说“旋转”“正面”“踏雷飞行”时先把它当查找线索，辨明动作主体、空间与触发，不把近似口述直接立为通用规则。

## 2. 升格、旋身、环绕和滚转不能混称

| 层次 | 原文定位与作用 | 改写时守住什么 |
|---|---|---|
| 角色旋身 | P2 SC9-2，`v-WQfNolqMMU`镜1，以脊柱为轴带刀向下斩 | 发力链、刃线、前后姿态；不是摄影机转一圈代替人物发力 |
| 摄影机环绕 | P1 LX14，`v-9oBsuZALhi`镜1，侧后跟随改侧前拉退 | 机位确实绕人改变观察侧，背景产生视差；人不必跟着原地转 |
| 摄影机滚转 | P3 SC11-4，`v-0e1FMAHmUG`镜4②，沿光轴360度滚转 | 视界绕观看轴翻转，角色仍由纵深逼近；不是绕人物公转 |
| 升格 | P2 SC9系列：闪避和最高点读姿态，随后恢复爆发 | 明确放慢谁、从何事件开始、到何事件结束，恢复后立即发生什么 |
| 主客体速度差 | WX4镜2，环境／来袭水龙放慢，防守者仍高速三段反击 | 这是特殊主观时间处理，不代表所有升格里主角都自动免疫慢速 |

SC9-2的关键原句：

> 升格结束，云徽随后以脊柱为轴线高速旋身带动苗刀向下斩出，伴随全屏黑白冲击帧，庞大的月牙型能量光刃瞬间淹没整个画面。

这句前面还有“空中最高点—腿部延迟甩动—持刀与拂刀—转焦下方敌人蓄拳—回焦近景聚能”。**不能只留下旋身斩四个字**：升格供观众读危机和蓄势，结束才让发力、冲击帧、满画幅能量接在一起。侧身避让可以替换不适合当前人物的滑铲，但不得另插一段站稳准备，让避让与起跳断开。原文近景满幅和远景闪点3帧、0.4秒后展开是不同机位的描述，不把数字串成额外三次攻击。

## 3. 跑动不是一种速度指令

先选移动用途与接触面，再选原文；不要求每条路线都兼具下表全部效果。

| 场面 | 原文定位 | 身体、空间与摄影机如何配合 |
|---|---|---|
| 沿巨臂高频奔袭 | P2 SC8-4，`v-nGyylrJOxr`镜5 | 巨臂表面在画面下方作引导线；人物从机位后方越过，低位侧后爆发追随；俯身、每步能量爆开、持续上行共同成立 |
| 绕开落锤再升空 | P2 SC7-1，`v-fPoqAak5gT`镜4 | Z字突进迫敌出锤，二次加速离开落点，不停歇至身后起跳；镜头从跟摇接侧跟再上摇，敌方有反制，不站着等 |
| 跑墙接对白 | P1 LX14镜1 | 开场已在垂直高速跑动，发根和裙摆大幅拉扯；翻上墙顶后机位环绕至侧前拉退；插刀成为稳定的前景，再转焦走来的对话者 |
| 踩壁二次弹射 | P2 SC8-4镜2 | 反震落墙、踏点炸裂、借力贯穿；墙不是装饰，是上一击受力终点和下一击动力起点。原文缺接刀须补回 |
| 迎面撞入兽潮 | P3 SC11-4镜4①②③ | 侧前看掠过并冲远→兽潮一侧迎面看角色纵深逼近→侧后跟进交锋；不是三个同义跑步镜头 |
| 化成光体穿场升空 | P1 LX12-2，`v-tN9jNBZqzl`镜4 | 指向性Z字折跃在人群、水滴旁穿越，转向升空后才凝成人形、余能聚成刀；不同于人物全程有实体、只脚下发光 |
| 已在空中持续追逃 | P1 MQ4镜4、P3 SC15-1/2 | 伴飞保持整体平移，转身、振翅或交手是平移之上的局部变化；不因说话、切镜就悬停 |
| 普通同行或撤离 | P1 LX-3.5、LX8、LX9 | 步频和呼吸有生活目的，停步有原因；不移植战斗音爆和冲击坑 |

沿臂原句（SC8-4镜5）：

沿臂／沿墙的“向上”先由支撑面高度决定，不由上摇镜头制造。迁移到新巨物与新地形时，核对手腕、肩部、平台的高度关系；平台比肩高时不能仍写从手腕一路上行到肩部。只修当前冲突的尺寸或路线，不把原文巨物尺寸固定给所有故事。

> 近景侧后低位爆发式跟随（死死咬住云徽），刚砸踏的高楼废墟烟尘中，巨猿巨大的手臂表面呈画面下方引导线构图

再接原文的残影越机位、跳上手臂、俯身高频奔袭与每步爆发，不改成“她开始跑步”。前情已经高速时，不额外加入站立蓄力。位移方向、近景参照高速掠过、能量尾迹、柔性部件受风和跟拍加速度共同构成速度意图；仅把“慢”列入负向词不能补回这些缺失。

## 4. 冲向怪群的正面机位是受冲击视点

SC11-4镜4先在侧前拍横弧与弹射，角色掠过镜头冲向远处；随后原文写：

> 快切兽潮视角，摄影机旋转一圈，19.5s-20s，云徽模糊渺小的身形街道纵深远端顶着横向的雷弧，3帧闪入近景，她将刀压制身侧准备挥砍

摄影机栏明确此处是沿光轴滚转。理解：第一视点给动力，第二视点把观众放在迎击的一侧，第三视点跟进攻击结果。**“看她冲来”不等于“清楚拍她的脸”**；原文此处身形模糊、读的是逼近压力。若新戏需要面部可读，优先找另一个适合的近景节点，不把几帧冲刺拉长为走秀。剪换观察侧时用已建立的街道、敌群位置和攻击轴维持方向，不能只锁人物始终画面左侧。

## 5. 旋身发波怎样让角色成为视觉中心

P3 SC11-7，`v-xRxM0ID02j`镜7的原句：

> 起幅街道空镜，云徽高速旋身（发丝、裙摆、绳带延迟甩动）入画，镜头高速前推到近景，左手向前伸出，掌心雷电开始向外爆发

标题是“中景全身斜角跟随，推进到近景”，并非明确的摄影机360度旋转或面部超特写。角色旋身提供姿态转换，斜向跟随与前推把全身动作收为可读的近景，空后景让轮廓不被敌群吞没；随后远景侧拍横移交代发波与目标的关系。理解重点是**由人物到手势，再到战场结果**，不是“发波必须推脸”。

要在新戏中突出脸：让旋身后的面向、头部视线和推进落幅确实使脸可见，手势和作用方向仍保留；只在必要的短节点读到决断，不必另插眼睛特写。用户不需要脸部高光就不加。SC11-7后半把“身后／画面左侧无兽”和“兽群最左侧”写冲突，应先定角色前后再重映射屏幕方向；保留横移揭示目标的机制，不抄矛盾坐标。

## 6. 从近身力量交给远景后果

- **放手让结果占镜头**：SC11-4/7刀尖擦地、斩击释放后转焦，摄影机离开角色跟洪流前推10米再减速；高处下一机位只看楼间洪流的上部，烟尘慢半拍。不能角色出画后仍声称镜头锁脸，也不能把贴地洪流搬到屋顶。
- **巨物局部保持体积**：SC8-4只给巨拳、手臂、躯干局部；SC7-1由巨大眼球上摇揭示角尖的小人。尺度来自比例尺与遮挡，不是为同框把巨物缩小。远景人物太小时不同时要求睫毛可见。
- **释放位置区别于飞行路径**：SC9-2/4月牙在闪点处纵向向外展开并持续，不是从天空搬下一轮月亮。远处观察者镜头注明同步多视点，不能每切一次就重新斩杀。
- **成片时间区别于事件时间**：同一击的近景、远景和旁观反应若同步回看，分别占用成片秒数，但不能累加成角色一直悬在空中。下一镜落地应接该次动作的实际轨迹；切走期间角色仍有行动或物理变化，不能默认在画外冻结。
- **小动作对大结果**：P2 SC3-2把整股攻势折叠成指尖冰晶，冰晶经已建立的通道落向对手；两地点靠同一物件和出口连接，不是切到远景凭空爆炸。
- **连续空间承担冲击**：P1 MQ4把剑柄朝掌心、剑尖向前的成形方向提前锁定，发射后沿途地表先受毁灭波，最后远处爆炸。别省成“巨剑出现→天边爆炸”。
- **余波也分阶段**：P3 SC17-4巨斧虚影→十字维持→延迟0.5秒后三层不同高度的环同时扩散→残块遮镜。三层是位置关系，不是三次顺序命中。

## 7. 对白、走位与摄影机的接力

本节解释注意力交接；人物诉求、权力差、笑点铺垫与关系证据用 [对局与关系场面](dialogue-scene-design.md) 补齐，不能只设计镜头而没有戏的回应。

### 7.1 同行中接人：P1 LX-4／v-4Bhn2t1v8x

原句：

> 当两人经过前台后，镜头机位平滑顺滑地向后方弧形摇移（Arc），自然过渡为侧后方的跟随跟拍（Following Shot），为云徽从后方追上并入画留出构图空间。

之前先在前台人物上起焦，两位同行者进入前景才拉焦并侧跟；经过前台再绕到侧后，为第三人追上留空间。第三人结束原任务才追上，前台人员仍留原处。新戏可借“结束手续→追上同行者”的因果，不必复制三人身份、前台或台词。若一镜到底，摄影机通道必须可走，不能用隐含瞬移完成交接。

### 7.2 同地不同任务：P1 LX7／v-xR2orNjeNO

两台机器人分别检查两个人。镜头横移把注意力从左组交给右组，背景等候者保留自己的姿态；司联官随后亲自走到右组，话题才汇合。镜头先交接注意，再由人走位完成关系交接。不是所有人围着发言者同步转头，也不是为每句台词剪正反打。

### 7.3 问话引出第三人：P1 LX-2.5／v-LmeJsx1cHi

先指实验管→同伴疑问→摇向原已在侧面记录的研究员→研究员听到后停笔转头回答。声音是入戏动机，镜头是揭示，不是把回答者临时变出来。三人继续走或停在哪个位置写清，后排同行者可有独立观察，不抢主线。

### 7.4 停步不等于停镜：P2 SC-插播2／v-OIIEOxkliY

侧移跟随通话，远光先照亮人物→人物停步转身→机位惯性继续滑一段→露出原被身形挡住的远处事件→转焦。镜头慢半拍让观众跟人物一起发现。此处月牙只占画幅约10%且保持存在，不把主战场的满画幅尺度照搬过来。

### 7.5 门槛、载具和走廊也是动作条件

- P2 SC2-1／v-dFf3grbW40：队伍边聊边挤过舱门，抬头才触发环绕升高，展现外小内大的空间反差；不可省门槛后直接溶解为大厅。原文面朝／背对镜头冲突须统一。
- P1 LX-2、LX9：车厢持续运动、起步令人体迟滞晃动，台词不取消这一背景动作；停靠、开门、下车是明确状态变化。
- WX5镜3：两人同向走廊行走，舷窗固定在她们行进方向右侧；刺痛声打断另一人的手柄练习，关心话语带来抚背动作。反打改变屏幕左右，不改变舷窗的世界位置。
- WX6镜2：听者微反应后，视线把镜头交给窗边物件与晚霞，人物出画但对白继续。穿过玻璃若用于新稿，明确为特效转场或改为隔窗落幅，不伪称实体摄影机无缝穿墙。

## 8. 声音不是事后的装饰栏

声音承担入场、节奏和空间：LX15先鸟鸣再抬头见鸟；LX-3同伴先捂耳、初来者晚半拍，声波才爆发；MQ2来人声音先于身影；SC15-2仍在飞行的角色听到半句产生身体反应，动作打断后半句，摄影机减速让两者出画。

写新对白先确定谁先知道信息、谁的手或步伐被哪句话改变，再选看说话者还是听者。画内、同地画外、通讯器远端和跨镜尾音分清。近景关键对白保留可辨识度；巨物脚步、风声、能量和衣料随距离与速度改变，不把所有音效从头到尾写成“震耳欲聋”。静默可只收环境／能量层；其范围、持续和爆点要一致。

## 9. 如何产生新故事而不稀释原文

**战斗与重点视觉高光依已有格式保真适配；对白、场景移动、关系与故事展开可按导演思维链自主设计。** 后者从人物诉求、信息变化与回应出发，安排走位、运镜、焦点和声音，不强制先找原文；有贴合桥段可以参考。最小替换不等于所有新故事只能换人名；自主设计也不构成任意改写成熟高光关键句或已定剧情的许可。

1. 用用户已有角色、能力与场景确定目标、阻力、人物选择和结果。先问“她为什么必须从这里过去”，不是先列旋转推镜。
2. 将故事拆成少量场面任务，如移动中发现威胁／被迫换路线／借敌攻击接近／一次决胜／对方反应。战斗与高光按功能找原文，完整阅读最接近的连续段；对白与叙事任务可自主组织，也可选择贴合参考。
3. 采用原文时，保留该段的前情动态、核心动词串、镜头观察侧、快慢节点和声画触发；核对招式的前提是否存在。沿臂跑要真的先接上手臂，踩壁要先落壁，召回要先有可召回设定。
4. 不同来源只在一个动作落点、视线交接或段落边界接合，不从五份原文拼同一秒。接口明确人物位置、速度、朝向、武器归属、环境状态及下个镜头接管对象。缺少接口就补最短的可见连接，不补停步整理。
5. 新故事的策略与人物反差在这条连续线上实现。原文没有相近场面时标明新编部分，仍按原文组织密度写动作、镜头与声音，不虚称是原句。
6. 先删重复设定和无用形容词，再控制篇幅。篇幅按本段时长和复杂度取舍，不设固定字数门槛，服从用户本次长度；不凑字，也不为达标删关键动作或延长冲刺。精确子计时只放在转折、升格、爆点与快切节点。

参考段内部校验可用一行：`本镜任务｜源节点/段落｜保留的关键表达｜招式/资产适配｜原文错误修正｜新编接口`；自主设计段检查`人物诉求｜信息变化｜动作/回应｜运镜/焦点/声音的动机｜结果/接戏`，不硬填源节点。两者均不把分析表塞进复制正文。

验收不是“有六节、有术语”就通过：遮去特效名后仍应读出选择与反制；遮去摄影机栏后画面仍有连续动作；遮去画面栏后摄影机应知道起点、触发与终点；原文关键表现不能在精简中丢失。实际生成前只报告文字与绑定检查，不保证同等成片质量。

### 9.1 审美保真与减法对照

把已经成立的原文当作可适配的审美方案，而不是等待润色的草稿。修正明确的空间、计时或资产错误，不借纠错改造无冲突的表演与镜头。这里补充高优先级原文规则，不要求另交一套分析正文。

- **保留机会形成的过程**：SC8-4镜4的劈砸与建筑崩塌接镜5烟尘中登臂奔袭，再接SC9的另一只手压迫。这里可迁移的是攻击余势被利用，不是“先把手臂展示成跑道”。新场面若改成抓桥，也要看抓握、拉扯、回收或另一手攻击怎样继续作用；有动机不代表长时间等待的画面就成立。不要为修复这个问题给所有怪物统一增加挥手招式。
- **因果完整不等于展示完整**：先在内部核对路线、接触与物件状态，再写观众需要看见的节点。前镜落幅、运动方向、短促接触和声桥能承担衔接时，不另加观察路线、站稳、起跑的说明镜头；也不能以“省略”掩盖无接回的武器或不可能到达的位置。
- **保护视觉重点与气质**：记录该节点让观众读的是表情、身体发力、目标还是结果。成熟的冷静表情不自动加扫脸光、挑眉或独立眼睛特写；即使新光效有合理光源，也须证明它不抢原表演。正常环境光照仍可保留，用户明确要求的新表现优先；这不是“禁寒光”的词语规则。
- **保护节奏比例而非仅保护顺序**：比较突进、短升格、爆发、余波各自占用的时间与注意力。原文短冲刺改成长跑、闪避后加整理、聚能前多一次摆势，都会改变效果，即使原句未删。新时长先从整段结构安排，不把各镜同比放慢，也不把余下秒数全部灌进余波。原文具体秒数不是跨故事硬指标。
- **新增项逐项说明收益**：内部用“新增什么／解决哪个缺口／占用多少时间或注意力／删除后损失什么”判断。只是更帅、更细、凑字数、展示新技巧，或删后更集中，就撤回；确有必要的接口优先融入现有动作。无需另立长表或把自审理由塞进生成提示词。
- **检查克制是否被误用**：减少装饰不等于削弱原文夸张强度。该满幅的能量、短暂升格、风压和冲击帧照保留；当前剧情缺少决定性接触或信息时仍要补足。边界是有依据的取舍，不是全部变短、变静或变朴素。

## 10. 不能在精简时丢掉的小约束

原文的细节限制往往在解决一个具体可见错误。按本场风险选取，和对应对象放在一起；不是把所有负向词复制一遍。以下是适用条件与意图，不是成片已验证无bug的保证。尤其区分通用检查与原故事设定：可迁移的是“效果符合当前材质与能力”，不是把纸质怪兽、纸屑或某种元素变成所有故事的常驻内容；素材和用户设定不支持的原文效果不自动继承。

### 先分文字职责：固定图文锁定，背景数据不可读

P1 LX-2的全息平板写“上面跳动着不可读乱码文字”；LX7脑波检测屏写稳定核图像和不可读文字；MQ2把战舰缩略图与不可读滚动数据分开。这种写法的作用是保留科技界面的活动和信息层次，而不要求模型连续生成正确字形。

**先检查用户、原文及参考资产是否已指定文字，再决定可读性；不是先禁止所有文字再等用户纠正。** 已明确的机构名称、标题、等级、刻度和其他要保留的图文，即使不是剧情中心，也不能擅改为乱码。只有未指定、仅提供气氛的背景数据区，才写成完全不可读的抽象符号／数据纹理。约束精确到区域，不把整块屏幕处理成失焦噪声；设备简图、航线、目标轮廓、状态点仍可清楚识别。全息投影的内容可读性与实体性分开，教学模拟如LX5-1不具备真实攻击性。

可按需使用的精简写法：

```text
本界面没有指定可读文案：保留清晰的设备轮廓、状态色点与滚动数据纹理；文字区完全不可读，不生成可辨认的字母、数字或汉字。投影保持半透明、无实体碰撞，不覆盖人物脸部。
```

可读文字的明确原文是P1 LX5-1／`v-zrapo047Op`：其输入记录绑定图片`i-Mwb66W7MXc`（啰嗦的教学板），最高优先级写“全息教学板上的内容不丢失、不变型、不替换”；画面让教鞭从【残响级】划到【界域级】，再指人类一侧的Ⅰ至Ⅴ。原文同时规定教学板在主官身后、身前另有能量漩涡模拟。**固定图文资产、内容锁定、指向具体位置的表演是三件配合的事**，不是把整个教室投影全部转成乱码。

这是归档文字可验证的写法；当前归档未提供该板完整图片内容或图片生成提示词，不能凭上述几个标签还原整板，也不能声称已核验每个字的生成效果。机构名称在LX-2等对白中出现，不等于已经核验某张屏幕里写了哪些机构；用户大致记忆的名称须回查实际资产，不能猜。

迁移到需要清晰文字的屏幕时：

1. **图文内容有唯一来源**：有已确认板图，就绑定该图，锁定指定字词、栏目顺序、图形对应关系和相对排布；只有文案时把准确字词写全，未确认机构名不自行补齐。
2. **内容层与效果层分开**：让扫描光、光标、粒子、边框呼吸等周边层运动，固定标题不随机滚动、重新拼写或被替换。真实资料需要翻页或切换时明确前后两版及触发，不全局禁用变化。
3. **锁的是板内内容，不是屏幕像素位置**：机位移动时板面随透视、遮挡和反光变化；固定内容不漂到人物面前，不镜像反转。关键阅读时机给足占幅、焦点与停留，别在高速掠过、极斜角、过曝或景外同时要求全文可读。
4. **手势与信息同步**：教鞭／手指指哪一标签、何时讲哪一句，位置与文案对应；指针可以遮挡一小部分，不把整个文字栏擦掉。
5. **同屏分区**：标题、机构名称、等级等白名单区域准确可读；只有辅助数据区不可读。“无字幕”仍指不加画外字幕，不抹掉场景内的合法文字。

以下是新写示例，不是源板内容：

```text
· 控制屏图文底图【绑定：】：固定标题只有“设备状态”“回传记录”，按底图保持字形、栏目顺序及相对位置，不丢字、不换字、不镜像。只有下方辅助数据区为完全不可读的抽象符号。扫描线与状态点可运动，不改变标题；阅读节点焦点落在屏幕上，随后转给人物。板面随机位正常透视，不贴死在视频画幅上。
```

若素材不含正确文字，先标为待制图／待校对，或在用户认可的制作流程中用后期图文合成；不靠提示词保证所有模型均逐字正确，也不为避bug擅删用户要求的机构名。检查成片时还需看字形在时间轴上是否漂移，仅首帧正确不算全过程核验。

字幕、场景内文字和台词是三件事：“无字幕”不自动禁止场景标识；“界面不可读”不禁止角色说出信息。人物从已知工作信息说“南端检修门”是合理的；若剧情依赖观众亲自读出门号，则必须提供另一个可辨识证据或启用准确文字例外，不能一面不可读一面要求观众读懂。

### 其他按条件保留的原文细节

| 易被精简丢掉的细节 | 原文定位 | 当前稿需要保留的具体边界 |
|---|---|---|
| 参考只管形状、不管角度 | P2 SC-插播系列 | 特效换观察机位，但外形身份不漂移；远景占幅不照搬近景 |
| 群体不是复制粘贴 | P1 LX8/LX5-1；P3 SC11系列 | 外观体系相同可以，站位、动作、出现时机不全同步；叙事主目标仍一致 |
| 受击效果服从当前材质与能力 | WX1/4、P2 SC6、P3 SC11的不同故事设定 | 仅在相应设定成立时借用：普通实体花瓣不凭空发光；原故事纸质兽碎成纸屑；原故事水龙被斩化回水幕。它们是条件案例，不是跨故事规范；新怪物按当前设定写接触、破坏产物与声音，不默认纸质，也不反向默认所有非纸怪都血肉骨裂 |
| 起幅已经在运动 | P2 SC9、P3 SC15 | 不加站桩蓄势；切到飞行对白后仍伴飞，不因说话停在空中 |

| 疼痛不等于自动战损 | WX6 | 手痛但无伤口、绷带，且不用手端饮料；不让痛感词召来新伤态 |

| 无BGM不等于无声音 | 多数案例的音效层 | 保留本场拟音与对白；短静默单独标范围，不能延长成整段消音 |

检查时问：这句话究竟约束哪个对象、哪一阶段、哪种错误？与正向动作冲突就限定范围，而不是越加越多。例如允许指定遮挡黑场，就不要全局无条件禁止黑屏；允许能量刀气，不等于允许实体刀柄脱落；角色图不继承打光，也不意味着场景图一律不能提供打光。

## 11. 精确控制的条件与原文接口

再生与再握拳、具名速度、标题级硬锁、最高优先级同步声明、分层终结及局部后景空镜的原句定位与适配边界，见 [动作接口与版本第3节](action-interfaces-and-versions.md#3-遗漏机制怎样转入新稿)。需选版本或抛接/回收时同时读其前两节。速度包络的起止事件、机位—人物相对距离与有效阶段须写进相关镜头；它们按场面取用，不是通用强制参数。
