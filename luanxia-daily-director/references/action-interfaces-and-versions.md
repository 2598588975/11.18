# 动作接口正例与版本选择

用于接刀、回收、换手、连续攻防或选择相近版本时。下列短引文已与当前归档核对，只证明文字存在；“正例”指局部状态链成立，不代表全段时间、引用或成片合格。完整底稿仍须阅读，原档不在本次方法维护中改写。

## 1. 可以照着理解的接口

| 接口与来源 | 原句锚点 | 保留的连续状态与边界 |
|---|---|---|
| 武器先行、人同镜追出：P2 SC8-1 镜2 / v-iQqD2oqXL3 | “云徽全身雷电包裹在3帧内向苗刀击飞方向追出” | 前文先踢出刀，再沿同方向追出；这一句本身不是接刀完成，下一镜还须核对回收 |
| 对手打回、追击者接回：SC8-1 镜3 | “渺小的云徽身形闪动出现接住苗刀毫不停顿直接挥砍向巨猿方向” | 巨拳先与飞刀对撞反震，再接住续攻。角色速度、机位与返还轨迹需在新空间成立；不可继承原稿6–7秒镜头重叠 |
| 投剑—反打—俯冲扣柄：P4 WX1 镜6—7 / v-Jq0CVBOiPI | “身体与剑交错的瞬间单手扣住剑柄” | 先有投剑被撞回，剑迎面掠进俯冲路径，角色不悬停扣柄后携剑继续出画；单手规则与唯一实体连续 |
| 抛刀钉墙—空手取回：P3 SC11-5 镜4③—镜5② / v-dxhuIkRxpT | “云徽空手从画外高空落下，手握插在墙上的苗刀刀柄” | 此版本前镜明确向一侧建筑扔刀，后镜先见刀钉敌上墙，再落到柄部。用于新稿时需补可读拔出/脱离状态与到墙路线，不把空手取回当成全链已无缺口 |

没有找到独立、无歧义的换手全文正例时，使用已标明的新编短接口：原手仍握柄→另一手接触并承重→原手松开→新手唯一持有。它可以融入一个连续动作；不冒充归档原句，不要求为四个节点分别切镜。

SC11-6/7 的问题是前段改为持刀换手，后段仍有墙上取刀。若用户选择持刀版，应改后段接口；若用户明确选择抛刀回收版，可依据SC11-5重接。不得为了消除错误暗中恢复用户排除的抛刀、旋转或其他招式。

## 2. 版本按需求选择，编号不是质量排序

以下是当前媒体快照的区别，不强制选某一版；既定素材、剧情与用户选择优先。

| 本次需求 | 候选底稿与实际差异 | 必须核对 |
|---|---|---|
| 飞刀被敌打回，接住后直接续攻 | P2 SC8-1，镜2—3有明确返还/接刀 | 设置26秒，正文至24秒且6–7秒重叠；起距150/200米冲突，不能直接当成配平成稿 |
| 对撞反震落侧墙，蹬墙爆射；建筑接力登臂 | P2 SC8-4，镜2主角持刀对撞后落侧立面，镜4—5建筑崩塌接沿臂 | 镜1踢刀后漏接回；自愈/再握拳仍存在。不能说该版没有反制 |
| 同一巨大释放由多人不同地点看到 | P2 SC9-1/2/4，最高优先级明确镜3/4/5同步多视点 | 能量位置、尺度、构件以实际版本为准；正文19–20秒缺口须修，回看不累加事件时间 |
| 先释放洪流，再碎纸重组为新威胁 | P3 SC11-3/4 | 升格硬锁与正文计时可能冲突；先确定本次关键事件和时长，再统一标题与正文 |
| 群战中抛刀，空手轰石板后去墙回收 | P3 SC11-5 | 只借局部有效接口；落墙路线、拔刀、左右坐标和石板速度时间仍须修 |
| 群战中保持武器在手、换手后拳击 | P3 SC11-6/7 | 不继承墙上取刀残留；SC11-7偏后期快切组织，按全文核对，勿混两个版本同一秒 |
| 五链五刃登场、重量错时落地 | P3 SC16-2 / v-2J2vx0M1pg | 正文“无限延长”与100米、设置22秒与标题24秒不一致；不与双链斧拼资产 |
| 双链双斧交手、腹部接触后光柱式终结 | P3 SC17-3 / v-eafHk06Ib0 | 本体四层与环境三层，摘要和正文延迟有差异；需追踪A/B斧和持有状态 |
| 双链双斧、巨斧虚影转十字星后三环 | P3 SC17-4 / v-iI2jSph2WI | 正文是三层本体＋三层环境，标题仍写“四重”；媒介改为仿真人CG。不能沿用SC17-3的光柱四层方案 |
| 城墙场面需要确定宽度 | P1 LX10为50米；P1 LX14/P3 SC12-1为30米 | 是不同段落设定；当前项目尺寸优先，墙宽与新路线同时核对，不择大数字继承 |

旧原文只用于明确的版本比较或当前归档无对应内容时；同名节点跨文件以文件、标题、nodeKey和关键状态区分。选择理由一行即可，不要求用户审一张大表。采用新媒介、能力或关系的变体时，确认它与当前任务相容。

## 3. 遗漏机制怎样转入新稿

- **自愈/再生**：SC8-1镜4、SC8-4镜3是伤口雾气汇聚与肌肉修复，同时握拳准备继续行动。仅在当前怪物已具备恢复能力时使用；伤口、修复区域、恢复进度与下一招相接，不能一切镜自动复原。
- **具名速度**：SC8系列500km/h写的是角色贯穿速度。换算为约138.9m/s；参数与起终距离、事件时间及背景参照一起核对。速度数字不等于特效，更不能单凭500km/h称“超音速”。
- **标题级速度硬锁**：SC11-5镜4明确“锁死③的升格只能为1s，石板射出前必须结束升格恢复常速”。把关键包络写成短标题/最高优先级：开始事件｜成片持续｜结束事件｜恢复后的动作；正文使用同一约束。SC11-3硬锁2s与正文1.5s冲突，不二者并抄。
- **同步多视点**：除镜内标注，在最高优先级说明哪些镜展示同一事件、哪一阶段、共计一次攻击。每镜占成片时间，角色状态按事件时间演进，不能把回看累计为悬停。
- **分层终结**：分别列本体构件、环境反馈、起源位置、出现顺序/时间偏移和维持/终止事件。不把SC17-3四层与SC17-4三层混写，所有延迟须有明确锚点。
- **后景空镜**：SC11-5/6/7的近景发波节点没有野兽后景，是局部轮廓与视觉中心约束。只锁该观察侧/时段；目标可在画外或下一镜，不能把全战场清空，也不能允许横移后目标坐标自相矛盾。
- **机位—人物契约**：SC9系列侧面平行跟随要求与人物速度同步；SC8-4镜4要求身侧半米。适配时写观察侧、相对距离/范围、同速的有效阶段、主体占幅与解除条件。具体距离要与焦段和景别相容；不把源稿半米＋50mm机械搬到全身构图，也不把绝对同步变为所有跟拍通则。
