# 交付前质量检查

默认从构思/剧本输入完成视频提示词，检查创意、人物逻辑，再检查资产、机位与时间；用户明确只要中间阶段或局部修订时只查相应部分。不为补齐检查表擅自扩大交付。

适用范围：所有段落执行成品、时间、资产、基础空间、镜头和连续性检查；**动作与物理**、**武器与战斗专项**及空间栏中的追逐/距离/动作窗口条目，仅用于战斗、追逐、攻防对抗或以强动作/VFX为主要高光的段落。普通对白、关系戏、日常走动、静态建立镜头和轻微气氛特效可标记为不适用；混合段只检查其中的战斗/强动作节点。

## 成品交付与分段

按任务只检查适用章节；D0检查文本/范围，D1检查完整连续链与相关专项，D2检查完整段。新文戏加载文戏设计与B模板/共用对白字段；战斗加载保真/物理，混合段分节点检查，不以完整检查为由通读无关原库。

- [ ] 用户只提供构思/剧本、未限定中间阶段时，已继续完成适合场面职责的A/B完整视频提示词，不只返回构思提纲；仅讨论、先审台词等明确范围被尊重。
- [ ] 通常按20–30秒的完整节拍分段，优先在合适的换场处切开；没有拆开关键接触与后果，没有为凑段长加无意义动作或改变总时长。
- [ ] 每段独立包含一句话剧情和一句话高光，资产、规格、必要规则与分镜自足；不是整片只有一条总高光。
- [ ] 各段局部时间从0开始，全片范围放正文外；正文无分析、来源引用、未采用建议或校验报告，复制范围清楚。
- [ ] 本版已融入的补充与尚未采用的创意建议已分开；建议有具体位置、做法、效果与设定/资产代价，不是空泛“增加电影感”。

## 五项视觉前缀与光色

- [ ] 每个完整可复制段开头均有五项，或在用户指定总控中包含同等五项；局部修订/原文提取未被扩成全稿重写。
- [ ] 光影色彩写清光源世界位置、当前方向、软硬/柔化、补光取舍、配色、对比、高光、阴影和主体曝光，同场反打未翻转世界光源。
- [ ] 当前分镜优先；未将古风范例的9:16、暖日光、桃粉配色和慢推强加于夜戏、科幻、动画或战斗；特效有指定出场时刻。

## 创意与导演判断

- [ ] 已按段落分工：战斗与重点视觉高光保留已有格式及原文优先流程；对白、场景移动、关系和故事展开可自主设计，参考桥段可选，未要求全片逐段套底稿。
- [ ] 自主设计能追踪人物诉求、信息变化、动作回应及有动机的机位/焦点/声音交接；正常文戏调度未被可选创意审批阻塞，关键改动已定剧情的方案仍先讨论。

- [ ] 已把用户的小创意补成当前阶段可用的设计，而非只复述“帅气、电影感”；构思/剧本阶段也有铺垫、回应或反差，不把所有创意推迟到运镜。
- [ ] 主要高光有铺垫和结果，辅助亮点有强弱；去掉光效词后仍能读出人物选择、关系或战术。
- [ ] 足部/腿部开场、前景遮挡、背景小动作、画外音、失焦、荷兰角等有具体职责，未机械凑齐、反复使用或擅加路人；低机位没有自动变成窥视角度。
- [ ] 遮挡是保焦、交焦、藏切还是延迟揭示已经明确；揭示的信息此前实际存在，非跳变生成。
- [ ] 战斗不是轮流展示招式：有争取目标、反应与利用变化；力量差通过策略成功的限度、姿态和破坏反馈体现。
- [ ] 已定剧情、对白与能力边界未被审美改写；新设定与备选创意没有冒充用户确认内容。

## 对局、笑点与关系（新写/增强文戏或修改其关键节拍时）

- [ ] 人物诉求、条件与回应能读出信息/选择的变化；无冲突关心未被硬写成摊牌或夺权。
- [ ] 权力差有让路、中断、门槛/物件控制、视线或距离等依据，未把机位高低当社会地位公式。
- [ ] 喜剧有正常预期、可追溯的反差信息、揭示与回应；反差未提前泄露，笑点未靠全员夸张表情或无因改人格。
- [ ] 关系变化/确认落在可见动作，已定亲疏与立场不因微笑擅改；没有强求每场改变关系。
- [ ] 关键台词、手部/视线/步频、声音桥与镜头交接互相承接；第三人已有位置/任务/进入动机。
- [ ] 采用WX等桥段时完整读取该原文；自主设计未冒充原句，未继承无关伤势、武器、能力或源稿时间错误。

## 原文审美与减法对照

- [ ] 已合并核对用户当前与既有上下文中的“要／只要／不要／仍保持”；排除项的同义动作和等价视觉结果也已移除，没有删掉原词却换近义词带回。
- [ ] 每条连续战斗高光只有一个主底稿；次级来源只补明确缺口。若只借眼神、表演、声音或余波，没有夹带该来源中未被要求的招式、身体运动、特效结构或机位。
- [ ] 核心动作链的实质动词均可追溯到用户要求、主底稿或必要连接；来源中的标志动作若无当前收益已删除。用户主动删招后，只重建重心、持物手、支点、轨迹和落点所需接口。
- [ ] 高光参考包含机会形成与对手应对；没有把动态威胁改为对象摆好等待，或仅凭剧情动机忽略画面中的配合感。
- [ ] 已区分内部因果验算与必须呈现的节点；衔接尽量融入现有动作，未把每一步拆成准备镜头，也未掩盖接刀或空间硬缺口。
- [ ] 新增动作、表演、特写、光效各有具体收益；删除后更集中者已撤回，未以“合理光源”或“不改胜负”代替审美必要性判断。
- [ ] 与来源比较了突进、升格、释放及余波的节奏比例；没有只保留原句却拉长高光前摇，也未把减法误用为削弱原文强度。

## 时间

- [ ] A/B按用户或现稿优先、新稿按任务选择；未按镜数拒绝字段制，混合段没有重复两套总设定。
- [ ] 字段制括号时长与镜头区间一致；并行事件共用窗口、未重复计时；只有持续秒数时已累计对白对应的绝对局部时间。

- [ ] 所有镜头时间连续，无重叠、无空档；有黑场或停顿时显式计时。
- [ ] 每镜内部动作秒数之和等于该镜持续时间。
- [ ] 所有镜头时长之和等于目标时长；若已知实际模型设置，二者也一致，未知设置不假称验证。
- [ ] 对白时间足以容纳正常语速，且没有与不可能同时完成的动作冲突。

## 资产

- [ ] 多参考按身份、造型、持器比例、场景、特效、声线和首帧分工；不会相互覆盖无关维度，首帧没有冻结后续动作，特效外形图没有绑死新机位。
- [ ] 同一身份的多视图／状态变体未增殖成多个人物；人物自身左右、正背遮挡和真实服装活动部件已核对。没有把不确定结构硬写成确定衣型。

- [ ] 所有 `{{Node …}}` 引用存在且与节点连线/输入一致。
- [ ] 角色、道具、动物和武器数量明确，未在后续镜头无故增殖。
- [ ] 角色声线不会串给其他角色；画外音和画内对白已区分。
- [ ] 空引用、重复引用和仅有名称但无用途说明的资产已处理。
- [ ] 引用的实际节点类型匹配用途，图片未充当声线、音频未充当场景；同名资产按所属项目与状态变体区分。
- [ ] 每段每个角色绑定均主动附已知外观、服装主体/配色与本段初始状态，不只写姓名或编号；未提供外观不臆造，缺素材用【绑定：】明确待补。
- [ ] 描述字段与资产类型对应：人物写外观服装，场景写空间结构/材质/光照，道具武器写形态/比例/使用规则，声音写声线或声源；没有统一套人物模板。
- [ ] 资产只列本段需要的对象，后段登场人物/天体不提前变成常驻背景；参考范围和首次可见时刻清楚。

## 空间与连续性

- [ ] 人物左右、朝向、路线、入口/出口和固定地标前后一致。
- [ ] 涉及追逐、远射、冲锋或拉开距离时，已核对关键节点的起始距离、位移动作、结束距离及固定参照；每次距离变化都由可见动作和足够时间产生，没有靠切镜或后一镜数字凭空改位。
- [ ] 战斗关键节点已核对相对速度、动作耗时、对手同期位移与释放时剩余距离；站桩、移动射击和后撤射击均按动作窗口判断，不预设为错。若写站定，角色没有无原因后移，摄影机后拉未被误当作角色位移。
- [ ] 重要距离不只写成数字：镜头中有同框纵深、地面引导线、巨构参照、运动视差、位移尾迹或沿途破坏等可读证据；焦段与构图没有把远距关系压成近身站桩。
- [ ] 每镜起幅可由上一镜落幅到达；跳时、蒙太奇、闪回和转场均显式标注。
- [ ] 持物手、服装状态、湿身/伤势、破坏程度和道具位置连续。
- [ ] 未在越轴时无说明地交换屏幕方向。
- [ ] 伤势、武器显隐、特效、星球揭示等有本段起始→事件变化→尾态，未把后段状态或镜尾状态提前锁给全段。
- [ ] 各段独立规则与全片连续性相容；没有依赖“全部同上”，也没有互相矛盾的全局常驻/禁止条款。

## 镜头

- [ ] 新写或优化打斗、创意高光时，已在关键节拍主动比较[运镜库及场面调用规则](camera-movement-library.md#invocation-rules)，所选方法有信息、情绪或节奏收益；保留用户已定高光，不为覆盖条目添镜头，也未带入图示中的8K超写实、人物、场景及爆炸。
- [ ] POV归属、可见身体／持物和实际位移明确；角色主观视点、对角色的前跟、FPV没有混称。变焦／推拉／拉焦、升降／俯仰、环绕／光轴滚转分别写清。
- [ ] 采用[C01动态前景遮挡转场](camera-movement-library.md#c01)时，已写物体入画→遮满藏切→移出露下一镜及动作／声音接续；通常用于段落中途，未误做片尾黑场，未凭空加入与场景限制冲突的动物或道具，也未遮掉唯一的交锋证据。
- [ ] 子弹时间、倒放、360度等有本场用途，且服从用户的速度和视点要求；复合运动有可追踪路径与落幅，快切或甩镜未掩盖关键接触，时间效果没有暗中改变角色能力和事件耗时。
- [ ] 使用[15项战斗运镜](combat-camera-methods.md#快速索引)时，来源编号与已有方法映射准确；图示24/35/50mm、360°和0.1秒未被固化为配额或统一规格。F01环绕保住双方交锋区，F05主观与F10肩后分清；F09人物翻滚、F13摄影机轴向翻转及空间换位分别有依据和方向恢复。
- [ ] F08的短升格、单帧保持、动画hit-stop与F04子弹时间按所选形式执行；F12区分角色加速、机位加速、播放变速、抽帧与真实瞬移。短停与变速占用成片时长，未重复命中或增加事件行动窗口；普通冻结帧未同时要求机位绕行。
- [ ] F03有真实起手与持器接口；F07攻击物从释放到接收端有唯一实体链，能力支持离体与转向；F06/F11有可通过路径。F14/F15从既有受力／释放读到持续后果，未凭镜头跟随或拉远新增命中、规模、伤势和结局。

- [ ] 人物旋身、摄影机环绕、光轴滚转、前推和升格分别有明确主体与职责；迎面冲刺未擅改为慢速脸部展示，近景发波未误称原文规定了面部超特写。
- [ ] 行走对白中说话者、受话者、独立任务及镜头交接可追踪；声源／视线／动作触发调度，不是句句反打。门槛、载具运动和行进地标未因切镜重置。

- [ ] 每段成片要求已写摄影基底：乱霞号真人电影风格未另指定时默认ARRI ALEXA 65；已定机型、媒介与画幅优先，未强加给动画等其他风格。
- [ ] 摄影基底与逐镜参数分工明确，未以机型名替代焦段、机位、构图、焦点及运镜；未把机型名当作8K等输出规格保证。
- [ ] 清晰度要求与本镜景深、运动模糊和有意失焦相容，关键接触可辨，未把所有镜头统一锁成全景深或全程虚化。
- [ ] 摄影机栏只写焦段、机位、运动、构图、景深和速度感。
- [ ] 画面栏写可见动作，不用“高级、震撼、电影感”代替事件。
- [ ] 每镜有明确主体；多个并行动作使用“同时”绑定。
- [ ] 快切、升格、黑白冲击帧和运镜变化都有持续时间或明确触发点。
- [ ] 运镜写明起点、触发、路径、加减速与落幅；转焦与景深、摇摄与平移、变焦与前推没有混淆。
- [ ] 多视点展示同一动作时已注明连续承接或同步回看；运动距离、速度与成片时间相容。
- [ ] 同步回看的成片时长没有累加成角色滞空／蓄力时长；切走期间人物与物体没有无故冻结，回到主体时仍接同一次动作的实际轨迹。

- [ ] “异种纪元”可直接调用；完整创作已完整读选用原文并尽量保留其结构、字段与有效句式。用户明确保留A/B或只借局部规则时才映射进对应字段，未强制统一所有原文格式。
- [ ] 只用一套主格式、无重复总设定；只选镜头未连带换画风，未把海滩、异种、血色、特定人物/地标/能力和绑定序号当通用风格。
- [ ] 同一场景的光照时序、太阳/主光方向及材质状态连续；情绪改变未无故改变天气，异常发光和遮挡有实际来源与周边反馈。

- [ ] 本次是吸收用户认可原片的有效写法，未仅凭术语/措辞扩展为原作挑错；只处理明显影响新稿使用的冲突。参考档案、方法提炼、用户反馈和本次生成/看片证据分开。

## 动作与物理

- [ ] 每次攻击写清起点、轨迹、目标和结果；命中/格挡有接触点，闪避/落空/取消有明确错开或终止节点。
- [ ] 关键动作已按“前一步尾态与重心→发力支点→躯干转向→双手/武器状态→轨迹→接触/释放→惯性与下一步起幅”核对；没有姿态、手部、支撑脚或武器连接断链。
- [ ] 已按当前角色资产列出实际存在的柔性／次级部件（如发束、裙片、束带、耳、尾、挂饰）；高速、转向、腾空、急停与命中阶段分别写出需要的迟滞、重力和回摆，没有只在全局写一句“自然摆动”后让战斗镜头失效。
- [ ] 拉弓、蓄力、武器生成或变形可站定或移动完成；选择与距离窗口、角色能力和本镜目的相符，没有姿态、持物手、支撑脚或连接动作矛盾。
- [ ] 双方都有受力或闪避反馈；动作结束后有分离状态。
- [ ] 环境破坏来自明确接触、攻击或余波，不凭空发生。
- [ ] 关键重击已按“力量方向→接触点→局部受力→全身传递→速度/重心变化→位移→环境传播→持续尾态”核对；冲击帧、闪光或冲击环没有替代实体受力过程。
