# 战斗创意编排：从合格动作到有记忆点的段落

与 [武器物理拆解](combat-weapon-breakdown.md) 配合使用：该文件负责结构、能量与受力，本文件负责战术变化、空间利用、反差和镜头兑现。案例出处见 [全库索引](029-directing-pattern-catalog.md)，这些是文字方法，不代表成片验证。

## 1. 先写交锋意图，不先堆招式

在已有胜负和剧情内，确定双方此刻要做什么：逼近、试探、封出口、夺回武器、拖延、掩护、击倒或救人。对手不能只等待展示。借原文高光时连同前置攻势和后续应对一起看，路线和破绽应由交锋产生或由当前任务合理形成；即使有伸臂、抓握等动机，也要检查镜头是否把敌人拍成供主角表演的稳定支架。回收、反击或失衡可与突进同拍，不为此硬塞第二套攻防。

用“**抢取什么 → 对手怎样改变局面 → 主角怎样利用变化 → 付出什么或落到何处**”编一条攻防线。每个连续动作承接前一动作的后摇、惯性、空门或破坏结果；不要求每击都有反转。

弱者可凭判断成功闪避、短挡或设置阻截，但成功的作用要与力量差相容：争取半步、换位、避开正中，不自动变成伤害无敌反派。强者可以转身缓慢、攻击瞬间极快；速度反差比全程匀速冲刺更压迫。

## 2. 从原文抽出的战术生成器

| 机制 | 如何用于新场景 | 回查案例 |
|---|---|---|
| 武器与人分路接力 | 武器先到逼敌应对，人物利用其反应抢路线；写脱手、飞行、接回的唯一实体链 | P2 SC8-1/4；WX1 |
| 攻击物变踏点 | 进攻或受力使手臂、回弹竹身、倒落断板短暂成为路线，主角借未尽的运动连续进入；不是对象先摆好等主角起跑 | P2 SC8-1/4、SC9系列；WX2 |
| 借反震改变进攻平面 | 正面对撞→被震向壁面→踩壁二次突进；不是被击飞后无过程回到原位 | P2 SC8-1/4 |
| 招架改变落点 | 防守者偏开刃线/拳路，主攻击继续摧毁旁侧设施；既展示招架有效，也保留敌方力量 | P2 SC8-4；WX1/2 |
| 破坏生成下一威胁 | 碎纸重聚、倒塌物封路、烟尘藏起势；必须符合本项目材质/能力，不能随意加复活 | P3 SC11-3/4 |
| 身体与环境成为武器 | 借切下的板块推扫敌群、尾击把被格开的弹体反送；写清推动点和前后轨迹 | P3 SC11-5、SC17系列 |
| 高低错层攻防 | 地面冲刺→跃起避横扫→遭上方拦截→借下坠续攻；高度转换来自动作，不是机位跳变 | P2 SC7-1、SC9系列 |
| 表面结束、危险未结束 | 先给胜利者判断，再露仍在防守/转移的人；保留先前可追溯的线索 | P2 SC7-1；P3 SC17-1 |
| 小动作兑现大尺度 | 指尖压缩、轻轻一放与远景的大后果形成反差；用轨迹/通道连接原因和结果 | P2 SC3-2；P1 MQ1文本节点 |
| 相同瞬间的尺度切换 | 近景看动作、中远景看路径、远景看影响；标明同一次事件，不重复扣伤害 | P2 SC9系列；P3 SC17-4 |

迁移机制，不抄角色标志：不能把雷电、踩头、三次冲击环、百米破坏写成乱霞号所有角色的统一招式。优先利用用户已有场景和能力；新能力会改变设定时先询问。

## 3. 让动作“巧”且可拍

### 武器接力不能剪丢中间状态

写清 `手中 → 脱手 → 飞行/嵌入 → 接触柄部 → 重新持有`，镜头可用一瞬完成接回，不必冗长。因果链用于内部验算，不是每个箭头都要独立切镜；观众能由轨迹和相邻镜头读懂时，保留动作中的省略，不增加站稳、观察和重新准备。若采用能力回收/生成，则先有这条设定。归档 SC8-4 从踢刀追出到下镜持刀，省略了接回；SC8-1 有接刀节点，可借鉴。SC11-6/7 改成武器仍在手中后却沿用了“墙上取刀”，属于版本残留，不能继承。

SC11-5保留了抛刀—钉墙—空手取回的局部正例，SC11-6/7才是删抛刀后的版本残留。原句与新编换手接口、版本选用边界见 [动作接口与版本](action-interfaces-and-versions.md)，不能把整组案例一并判成负例。

### 闪避不是后滑动画

给出威胁线与离线方向：看肩/刃起势→单脚压地→短距斜向爆发→刀锋擦过原位→另一脚着地接续行动。头发衣摆迟到而躯干先出危险线。角色灵巧体现在换重心、旋身让线、低身穿过攻击内圈和借落脚立即反应，不靠长时间翻跟头。能力允许时蹬地点局部凹陷，轻落不必每次炸出大坑。

### 招架不是举着盾等挨打

防具/临时能量罩在关键接触前成形，受力压入持有者的腕肘、肩背、髋与后脚，随后偏导、反推、碎裂或主动撤掉，让另一只手/下一步可继续行动。武器刃长、杠杆、身体姿态决定承力方向。持续盾仅用于剧情确需的持续压制。

### 烟尘是信息工具，也是实际空间

先有爆点或破坏，局部尘幕遮起势；用重甲步声、刀尖掠影或压弯的尘线提示位置。挥刀将尘幕压开、主轮廓出烟后再读接触；不能把“烟里看不见”作为无轨迹命中的解释。尘幕随风变薄，背景裂槽与残骸仍在。

## 4. 重击必须有持续效力

按该招性质挑足够的可见阶段，而不是全部重复说明：

**起势的重量 → 加速与破空 → 实际接触 → 力沿身体/地面传导 → 主体分离 → 破坏继续传播 → 余响与余尘。**

例如跳劈：蹬地点压凹/碎屑下落，起跳衣摆拖后；刀落压中防具，身体被压低；冲击帧卡在实际接触；落地裂槽沿刃线向外延展，暗色斩压先行、板块翘起与尘浪稍后；再切受击者震飞/滑移。若剧情规定肩伤，交代破防和偏身令刃线擦中肩部，而不是直接由空中跳到伤者翻滚。新招效力与原设定相符，不把未命中照样写成人体受伤。

衣料、头发和绳带提供近景速度；地面脚印、碎屑传播与远景倒塌提供尺度；相同受力不必在每栏重写。

## 5. 能量材质与时间过程分开

全局只定义一次颜色和结构层。镜内写当前阶段及关键变化：**形成 → 维持 → 释放 → 接触 → 衰减**，没有释放时可取消或保持。

- 火球不是喷火器：先有离掌可辨的团状核心，轻盈浮动，细丝向上拉伸；出手后球体整体脱离手掌，尾迹由其运动留下，不是手掌连续供火的软管。是否带喷流由角色设定决定。
- 飞刃不是长在空中的光墙：由刀锋/挥斩接触区脱离，沿确定平面传播；若只是贴刃光效，则不擅自变成离体攻击。
- 三层武器光效若已指定，须在精简时保留各层颜色、位置和职责；不要把“深色刀体/刃缘能量/外侧折射畸变”压成“暗光一闪”。这里是结构示意，具体三层以项目已定版本为准。
- 持续光效也有强弱：待势微弱、起手聚集、碰撞增强、收势衰减；实体武器与光效消失不是同一件事。

## 6. 冲击帧与冲击环不是同一种效果

| 手法 | 观众读到什么 | 使用边界 |
|---|---|---|
| 黑白高反差冲击帧 | 一次关键接触/爆发的瞬间断裂感 | 刃、接触点、双方剪影仍可辨；不是连续黑屏，也不是每击闪白 |
| 低饱和度冲击帧 | 保留金属、肤色残色和空间层次，强调迅速抢招 | 适合用户指定的救场碰撞；不能自动替换成黑白或多次闪烁 |
| 负片/红色剪影帧 | 更强烈的风格化异变 | 归档 SC3-1 有此设计，仅在本场画风允许时选，不作为默认真人感 |
| 升格 | 看清表情、刃线擦身、姿态或下一招将发生的紧张 | 指定开始、屏幕持续时长与恢复点；别让整场慢悠悠 |
| 抽帧/残影 | 省去中间运动显示、强调爆发速度 | 起点、方向与终点可追踪；与真正瞬移区分 |
| 空气折射冲击环 | 接触压缩空气，传播到尘雾/碎屑可见 | 环起于力源，方向/透视/传播面正确；快速扩张、变薄、消散 |

近身撞击的气环、脚下贴地的尘环、远处大范围毁坏不是同一尺寸。轻落、试探和主重击有等级差，避免每次动作都“核爆”。若想要分层多环，写清同时或依次、各自高度和半径；例如 SC17-4 的三环是不同高度同时扩散，不是三次新命中。

帧数需落入既有时段，24fps下3帧为0.125秒；不是在30秒之外另加。精准帧数是生成/剪辑意图，未检查视频前不得承诺模型已做到。短暂失焦服务揭示，不能遮住本已极短的碰撞帧。

## 7. 摄影机从动作主体交给结果

打斗不是永远贴脸。一次重击可先低机位读起脚与刀路，接侧面看双方接触，再让人物出画、镜头追踪余波，最后远景读破坏宽度。反过来，远景证明规模后可切眼神给性格，但不可在伤势成因未读清时先切表情。

动作层与镜头层配合：Z字闪移用横摇与短平移追主路线；跳劈上摇再下摇；被震飞用跟摇并在落地处减速。荷兰角给斜向冲力，冲击后适时稳定一拍。强弱交替才能突出高潮。

### 用15项战斗运镜兑现攻防

新写或优化战斗时，按[15项战斗运镜索引](combat-camera-methods.md#快速索引)主动比较对应方法，选读实际采用条目；通用路径见[运镜库](camera-movement-library.md#invocation-rules)。先有本场攻防，再让摄影机交接起势、威胁、接触与结果；镜头不能替人物完成位移或改变胜负。

| 动作节点 | 可选方法 | 需要保住的动作证据 |
|---|---|---|
| 起手与逼近 | F02贴地冲刺、F03拔剑推进、F10肩后追踪 | 发力、离鞘／持器、威胁距离；推进不延长本已紧迫的动作窗口 |
| 缠斗与闪避换位 | F01环绕锁敌、F05第一人称、F09翻滚跟随 | 双方路线、刀锋让线、支点与落脚；转镜不交换人物实际位置 |
| 腾空及战场路径 | F04子弹时间、F06升降俯冲、F11空间穿越、F13翻转 | 高度、落点、真实净空与重力参照；环绕、滚转、人物翻身分开 |
| 释放与关键接触 | F07跟随剑气、F08撞击短停、F12高速变速 | 唯一攻击实体、接收端反应与受力；短停和变速不造成二次命中或额外行动时间 |
| 后果与收尾 | F14环境破坏跟镜、F15终结拉远 | 受力起点、破坏传播、残骸与人物尾态；无设定不新增毁城或新伤势 |

主图六阶段可作为F01的组织参考，不成为每场六镜公式；来源中的24/35/50mm、360°和0.1秒均按本镜取用。动作快时可稳定跟拍并留清接触，突出一击时可短慢读；选冻结、动画hit-stop或变速须写清作用范围与恢复节点。新方法支持当前战斗写法，不以套新图为由重写已选成熟高光。

## 8. 交付前的创意验收

- 去掉光效形容词后，动作是否仍有策略和人物差别？
- 是否有来自现有地形、道具或对方动作的利用，而非无来源突然多一招？不适合利用时不强加。
- 高光是否先有线索，再兑现，而不是靠段首“高光：很帅”宣告？
- 攻、防、反击、分离是否各有可读节点，关键的接刀、换手、落脚是否被剪丢？
- 能否分辨连接动作、局部有效招和决定性重击，而不是全程同强度？
- 相对原文，冲刺、升格、释放和余波的时长与注意力分配是否被新增拖剑、摆势、特写或装饰光效摊薄？已成立的高光不因“补亮点”再加准备拍。
- 结果和用户锁定对白不变；为提升表现改动了什么，是否只在授权范围？

答案不理想时先改战术与镜头任务，不通过增加字数、帧闪次数或所有数字再乘十来补救。
