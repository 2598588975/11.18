# 咒蓝篇下 · 图片与视频提示词的可复用规则

来源、范围、完整节点和局限见[项目索引](zhoulan-media-index.md)。这是对原画布提示词的提炼，不是作者隐藏 skill 的全文，也不是已验证的成片结论。用在乱霞号的资产设计、多参考绑定、巨物动作、变身、救援、生活对白和冲击帧时，按需取相应章节；不把咒蓝、重庆、港式奇幻、墨青琥珀或特定尺寸强加给其他项目。

## 1. 图片先定职责，再写画面

原库的图片不是一律“电影海报”：主资产、结构卡、空场、道具、材质与插切帧各有职责。只请求图片提示词时直接交付所需图片，不续写视频或强制补一套资产。

| 职责 | 原文的有效组织 | 迁移边界与来源 |
|---|---|---|
| 人物/巨兽主资产 | 主体身份 → 可辨的脸与体态 → 身体结构和连接 → 材质/局部发光 → 完整轮廓 → 环境尺度 → 光影 | 主图可放在环境中以建立电影质感；不要求一律白底。巨兽先读 [ZLI004](zhoulan-image-prompts.md#zli004)，人物按名字检索图片库 |
| 多角度结构卡 | 指定唯一造型来源 → 同主体几个视面 → 同比例同连接 → 中性照明、完整轮廓与间距 | 多个视图不是多个角色；四视图是这些案例的选择，不是所有资产的强制数量。见 [ZLI030](zhoulan-image-prompts.md#zli030) |
| 场景空间母版 | 固定地标与前中后景 → 门/台阶/道路/落脚面 → 预留站位或搬运路线 → 机位与光源 | 无人空场是为后续调度留空间，不是最终成片必须空镜。机车与石墩之间的站位留白见 [ZLI007](zhoulan-image-prompts.md#zli007) |
| 单件道具 | 唯一数量 → 实际握持尺度 → 结构、开合状态与材质 → 完整轮廓 → 接触阴影 | 道具图里的桌面和特写大小不成为视频布景和真实尺寸；闭合花苞、开盖盒子按当前状态选择 |
| 材质/色光参照 | 明确只取颜色、密度、边缘与层次 → 限定不承担地点和角色 | [ZLI008](zhoulan-image-prompts.md#zli008)把魔气写成近黑体积雾、少量低饱和紫边，避免凭“魔气”自动画锁链、触手或霓虹火 |
| 独立冲击帧 | 指定原事件与方向 → 允许变换的绘画媒介/限色 → 保留的主体结构 → 是否为隐喻 | [ZLI139](zhoulan-image-prompts.md#zli139)的月裂是视觉隐喻，不增加真实月球毁灭情节；视频只在指定时间调用 |

### 1.1 结构、比例、发光分开控制

- 有四臂、三足、双肩附属物等复杂结构时，写清数量、根部、连接与前后遮挡。某视角看不到一肢不等于删除；附着在肩的龙形不自动变成独立召唤兽。当前角色没有这些部件时不要照搬数量。
- 巨物用普通窗格、车道、栏杆、桥墩提供尺度锚；主体完整入画靠取景距离与画幅，不靠横向拉伸、缩小成宠物或切掉肢端。远近景切换时保持相同真实尺度。
- 先写实体皮毛、羽片、鳞片或袍料，再写光沿哪里流动、照到哪里。金火只在羽缘、熔光只在缝隙等是原案例的材质选择；可迁移的是发光仍让实体、关节和遮挡可读。
- 空场先为下一动作留下能站、能过、能承接的实体位置。例如承接公交的缓桥和近直立攻击跑道是两块桥，不因同属“断桥”合成一个物体。

### 1.2 局部编辑先限定改变范围

区分“保留原几何，只改灯光/颜色”和“允许重新编排视角、背景、构图”。[ZLI014](zhoulan-image-prompts.md#zli014)只改夜景照明，不改柱台—石阶—坑的几何；[ZLI030](zhoulan-image-prompts.md#zli030)允许将单图重排成多个视面，但主体比例不变；[ZLI139](zhoulan-image-prompts.md#zli139)允许重构为象征画面，不再要求复刻街景。不要同时写“整体不变”又要求彻底换布局。

原库还有保留同一构图、分别改黑白负片/冷紫/红黑/木刻的冲击帧变体。它们是可选视觉方案，不能在视频中自动变成全部连闪。

可按需求填入的图片写法，非强制字段表：

```text
<图像职责与输出形态>。参考<已提供资产>只负责<身份/结构/空间/色光>；允许改变<本次范围>，保留<关键几何、数量、比例或状态>。
<主体外观与材质>，<当前单一状态>。<完整轮廓、连接与尺度参照>。<机位、前中后景和可行动空间>。<真实光源、表面受光、局部发光与暗部层次>。只排除本任务容易误生的对象或表现。
```

原文的 `--stylize`、`--chaos`、`--hd`、模型名和画幅原样归档，属于当时的提示词/节点配置，不转成全部图片平台的通用语法。新任务按目标模型当前支持项写，不能把原稿某个数字宣称为最佳参数。

## 2. 视频参考必须说明“取什么、何时用”

接入既有[资产绑定逻辑](asset-binding-logic.md)，增补以下更细的边界，而非重复要求用户为每项职责重新做图。

1. **主资产与结构补图有优先级。** 主图定身份、衣装、材质、清晰度和既定电影质感；多角度卡仅补侧背几何，不继承白底、平光、站姿或拼图。主图和补图冲突时按本段明确分工处理，不能把补图遮住的下臂误判为只有两臂。
2. **特写需要还原真实尺寸。** 面部特写不能生成巨头；石符、玉莲、玻璃罐先缩到手掌、两指或衣兜可容纳的尺度，再匹配透视、景深、接触阴影和光向。靠镜头靠近来读刻纹，不为看清把小道具放大。见 [ZLV048](zhoulan-video-prompts.md#zlv048)、[ZLV006](zhoulan-video-prompts.md#zlv006)。
3. **位置参考不必是首尾帧。** [ZLV007](zhoulan-video-prompts.md#zlv007)的截图只给座位、桌面与周围关系；重新设计机位和自然动作，不整图动画化、不复刻截图中的看向画外表情。只有当前用户/平台明确指定首帧时才锁起幅，不把这条变成“永远不许复刻首帧”。
4. **角色、材质、地点、状态分开继承。** 神兽日光图可只取外形，再按夜景受光；完好面馆图可只取布局，保留已经掀开的屋顶；水帘图只提供水材质，形成仍在镜内发生。参考图不自动清零损伤，也不提前播放结果。
5. **参考照明不等于全片压黑。** 夜色需要保留湿石高光、江面和远灯层次。ZLV030/044/006明确改用原始场景图质感，不再采用另一张重绘暗化图；这是该版本的资产选择，不是“夜景修图一律禁用”。
6. **音色、口音、台词、情绪分别指定。** 声音样本只给该角色的音色与共鸣，不复制样本台词/背景声；需要重庆话时落实发音句调，不只是普通话夹几个词。原本普通话角色仍保留普通话。没有实际音频时写文字声线，不伪造编号。

图片输入数量、图 N 和混合顺序以当前实际绑定为准；档案里的 6/8/12/16 张图是不同节点的配置，不是平台输入上限。视频输入中的 2 秒黑屏只作原项目活动说明归档，不新增、不默认当作激活素材或风格参考。

## 3. 视频骨架与乱霞号格式衔接

多数原视频采用：**输入图片说明 → 视频目标 → 基础设定 → 感官与音效建议 → 氛围与画质 → 画面内容 → 负面约束**。独立补充对白使用“视频目标与独立情境”“对白与声线”等变体；4秒变身也会省去单独目标标题。应完整读所选正文，不能据此把所有原文抹平成一模一样的七栏。

- 用户要求贴合该项目原文时，保留其外层栏目与时间段叙述，逐镜自然串起“机位/运动—动作—接触—状态—声音”，不强拆原句为新表格。
- 普通乱霞号任务仍用既有 A/B 骨架：输入说明并入资产，目标并入剧情/高光，状态/空间进入最高优先级，摄影、动作与声音进入镜内对应栏。已确认原稿的局部修改只改指定位置。
- 新写完整视频继续执行既有五项视觉前缀，可合入原骨架开头总控；原文归档和原样投喂不追加。图片提示词不强加视频五项前缀。

原案例覆盖4、12、15、16、18、20、22、24、26、28、30秒等长度；短段只完成一个转折也成立，不为凑长度重复动作。实际节点时长、正文时间线和剪辑接点分别核对，不能只信标题。

## 4. 强动作：把状态变化拍成证据

### 4.1 起势—响应—干预—结果

[ZLV048](zhoulan-video-prompts.md#zlv048)把抢夺写成魔手前伸、张掌、收指、回拽，石符受拉后才加速；侧向绿光实际接触后原牵引才断、两符才分叉。可借的是动作因果与同空间证明，不能把所有法术都加上两条紫线。

同理，[ZLV046](zhoulan-video-prompts.md#zlv046)先抓梁、拉身、后肢蹬压，再蹬碎桥端腾跃；近身双爪真正压到护层，对手位移、自己受反作用后才有余波。光爆、飞屑和冲击环强调接触，不代替接触。

### 4.2 多臂/多人：按当前时段分工

[ZLV002](zhoulan-video-prompts.md#zlv002)固定自身左上掌扣右上腕，左下掌按胸，右下拳反击。自身左右与画面左右分开；每条肢体有根部与当前工作，不能同一臂同时扣腕、按胸、持物。分工不是全片固定姿势，解除、换手、接物都要有动作节点。

[ZLV030](zhoulan-video-prompts.md#zlv030)的控制权有明确失效条件：宿主仍在体内时影响魔臂，真正离体的瞬间立即停止。迁移时找当前能力实际依赖什么、何时结束，不让人物在条件消失后继续远控。

### 4.3 城市翻转：用不动参照证明物体在动

[ZLV045](zhoulan-video-prompts.md#zlv045)先断连接、离支座、再刚体抬转；窗格车道保长度，灯具管线有滞后，水平江面和向下落石证明桥本身在翻。相机滚转不能代替场景运动；原案例明确不要连续U形折纸城市，不把这项美术排除扩为所有奇幻项目的禁项。

原桥A、载客缓桥B、空桥C、支撑残墩C0各有用途，不能换名不换几何；两条进路最终指向同一对手。可迁移到追逐、救援的做法是为每一落脚面和保护对象建稳定身份，禁止切镜后随意变坡度、位置和承载对象。

### 4.4 变身和唯一性通过连续身体完成

剧情确定为“本人变兽”时，按 [ZLV035](zhoulan-video-prompts.md#zlv035)写同一身体中心向外增长、原肢体转为兽形、衣物如何收隐、凝实与承重；回人先降到可承重位置、脚接触后受力。不能同时留下人形旁观者和兽形尸壳。外部魔气包住正常宿主则是另一机制，宿主不能随八十米外壳拉长。召唤或分身剧情按其已有规则，不套本人变身限制。

### 4.5 双线同步不靠“同时”二字糊过去

[ZLV030](zhoulan-video-prompts.md#zlv030)先建立左侧救人、右侧攻击的不同通道；攻击已发动、宿主离体、控制解除、敌人来不及结印、命中，依次给出可见节点。随后 [ZLV044](zhoulan-video-prompts.md#zlv044)把前侧托人与后侧收魔分开，保护对象不进入吸收路径。复用时验算当前行动窗口和各镜之间的并行时间，不复制原段秒数来硬套新距离。

法器的唯一性也用动作串起来：原地展开 → 最后一缕魔气进入 → 闭瓣截断怒吼 → 光相缩回同一实体 → 手掌接稳。天空光相、地面实体、手中实体不是三件法器。

## 5. 生活戏、声音与冲击帧

### 5.1 情绪由行动与物件兑现

[ZLV031](zhoulan-video-prompts.md#zlv031)嘴上嫌弃加班晚归，手上重新点炉火、加豌杂与萝卜；对白和工作并行。回到 [ZLV006](zhoulan-video-prompts.md#zlv006)，同一生活物件的小罐萝卜承担重逢回报，伤势、痛哼和疲惫继续，不把救援后自动写成无伤暖色MV。借关系机制时重选当前人物已有物件，不把泡萝卜塞进别的故事。

[ZLV007](zhoulan-video-prompts.md#zlv007)提问—放筷—看盒—回答，用视线与动作把物件变成叙事重心；画外续声让答案不中断。声音落点先确定说话人、原字、时间、画内外，再控制喘息与口型，不因切道具特写把台词重说一遍。

闪回要明确过去状态、原演员身份、现时伤痕是否存在；用脚步进入或筷尖碰碗作为声桥，剪辑硬切不等于物体真实变形。原案例省略煮面时间有明确“短时省略”，不伪装为完整连续实时动作。

### 5.2 一张冲击帧的有效范围

[ZLV014](zhoulan-video-prompts.md#zlv014)在四秒里把现实压缩、上摇引导、1.4—1.8秒月面绘画插切、同向四臂动作切回、主体停环境余动连起来。复用时明确：进入的动作/遮挡、帧图负责的时间范围、媒介改变、是否仅隐喻、切回现实的匹配点和落幅。

“只用一张、一次”是这个四秒强化段的选择，不是所有作品的冲击帧配额。不可将项目里六种静态色彩变体自动六连闪，也不能让月面意象改写剧情中真实天体的状态。音效有抽低、重击、空隙与惯性余响，避免从头到尾同音量轰鸣。

## 6. 版本选择与可迁移边界

| 源版本差异 | 使用方法 |
|---|---|
| B43-V03A/B、B44-V03等写四束牵连与逐次断束；B45-V05、B46-V05明确排除线状连接体 | 先选当前剧情机制，再读该版本完整正文和前后接口。不把“断三束”接到“从来没有束缚”的下一段 |
| 图片 ZLI014 调暗场景，ZLV030/044/006则指定原始场景的光影纹理，不用重绘暗化图 | 将调整记录为可选方案，按当前选定资产取用；不把夜景等同于整体压黑 |
| 图片库制作了两种神兽多视图，部分后续视频明确不输入它们 | 已制作不等于必须输入；按本次节点实际引用和参考职责选图，不自动把全部资产接上 |
| 主资产存在不同甲片、皮毛、羽色和构图版本 | 材质、脸、比例随当前采用版本锁定，不把多个版本的优点叠加成新角色 |
| 同一桥段有12—30秒版本和新增独立补充 | 不能把多个完整版本串成“全剧情”。原名、nodeKey与本段起止状态共同定位 |

以上是文本差异，不证明哪版更好。未获得用户选定或看片证据时，不宣布最大版本号、最新时间戳或带“采用”字样的标题就是最终版。归档原文不修订；实际改编才按当前用户要求修接口、计时和引用。

交付前只检查当前任务适用的新增点：参考职责与序号可追溯；特写尺寸已还原；多肢/附属物连接可读；落脚面与保护对象未混；动作、声线和状态没有跨版本冲突；冲击帧/闪回能返回当前时间线；本段目标实现且未抢演下一段结果。沿用乱霞号既有质量检查与战斗三链，不另增加无关审核流程。
