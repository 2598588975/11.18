# 资产绑定：引用分工、镜内调用与状态

用于多张人物图、武器比例图、场景、声线、首尾帧或混合输入的写作与核对。这里是从归档提示词提炼的语义分工，不声明某平台新增功能，也不代替实际上传、连线和生成设置检查。

## 1. 一份参考只负责明确的维度

资产绑定的逻辑是：**哪个引用 → 证明什么 → 不继承什么 → 哪些镜头／状态使用**。不把所有图混成“全部严格参考”。同一角色可有多个互补参考，不因此生成多个角色。

| 职责 | 原文依据 | 应落到当前提示词的边界 |
|---|---|---|
| 面部身份 | P1 LX-2.5、P3 SC11-4：全身引用后另写面部基准 | 面部图管脸；全身图管比例和衣服；同一身份，不是两个演员 |
| 服装与体态 | P3 SC11-7等的人物锁定 | 写实际服装层次、贴身／自由部件和左右不对称，不因动作需要凭空增加长裙片 |
| 武器本体 | P2 SC4-1、P3 SC11-4的苗刀单图 | 刃—柄—尾坠的结构、材质、数量；柔性尾坠允许运动，连接根部不漂移 |
| 人物持器比例 | 同上另绑定持刀比例图 | 人与武器的相对尺寸、握持关系；不自动继承该图脸、衣服或姿势 |
| 环境与细节 | P1 LX12-2、P2 SC1-1：城墙轮廓与近处细节分开 | 全景管布局，细节图管材质构件；不把不同视图复制成两座城墙 |
| 色彩与光照 | P1 MQ2天空色卡、P2 SC3.5天空参考 | 只约束已说明的色彩／光照，不凭色卡新增天体或继承无关构图 |
| 特效外形 | P2 SC-插播/插播2的月牙图 | 原文明确仅参考结构、外形、颜色，不参考低机位；新机位仍可远眺俯瞰 |
| 首帧构图 | P1 LX15、P2 SC9-2/4 | 只锁指定起始时刻的布局与动作阶段；后续允许按提示词运动，不冻结整段 |
| 固定屏幕图文 | P1 LX5-1绑定“啰嗦的教学板”，内容不丢失、不变型、不替换 | 已确认文字、栏目与图形对应关系视为资产内容；保留板内相对排布与字形，正常参与透视，不把整板禁成乱码。详见[文字分工](029-scene-mechanics.md#10-不能在精简时丢掉的小约束) |
| 声线 | 多数角色资产及对白段 | 音频绑定给角色身份；本句情绪、远近、口音与通讯失真另写，不复制样本台词 |
| 群体风格 | P1 LX8、LX5-1 | 参考服饰体系，个体外貌和动作有差异；单只怪物参考可供复数实例，但数量、尺度另定 |

完整原文按 [媒体索引](029-media-prompts-index.md) 定位；图像生成的设计意图见 [资产原文](029-asset-prompts.md)。文字里有描述不等于已经看过实图；需要判断服装结构或持握时看用户提供图／实际可用资产，不从文件名猜。

开放创作中的全新人物可以提出暂定视觉设计，明确是新设计、尚无素材；不得冒称来自已绑定图片，也不把试写人物加入用户正式世界观。用户既有角色缺少信息时，仍不臆造身份和关键造型。

## 2. 身份不变，状态和可见性会变

内部区分三个对象：角色或道具本身、状态变体、本镜是否可见。例如同一巨龟的普通态与冻结态不是两只龟；普通态参考也不能抹掉上一镜已经形成的冰层。云徽古装、日常装、战斗装分别属不同造型，按本段选定版本，不把优点叠穿。

- 静态资产栏：身份、结构、初始状态、参考职责。
- 最高优先级：数量、唯一性、世界地标和高风险边界。
- 镜内：谁进入／离开、什么变化、何时生效、什么延续。

例：刀起始在右手→脱手钉墙→接柄拔出→重新右手持有。不能因资产栏写“主角的刀”就跳过接回；也不能写“全程右手持刀”又要求空手攀爬。刀光减弱不等于实体刀消失。

同一件裙装正面可见的绑带，背面可能被布料遮住；按人物自身左右描述，不随机位反打交换。多视图板上的几个人像是一个角色的多个视图，不是出场人数。镜头外的角色可继续说话，但必须标明声源和位置；资产列入本段不代表每镜都要入画。

## 3. 引用语法与实际绑定不是一回事

保留当前项目已确认的 `{{Mixed N}}` 或 `{{Node …}}`，不要跨平台直接互换，不猜N，不把原画布nodeKey复制到用户新项目。占位统一用中文【绑定：】，未提供的声线也留待绑，不把图片编号塞给声音。

操作实际画布时检查引用解析到的节点、类型、项目归属、可用媒体和本视频的输入连接；节点有名字但无媒体、错误项目同名节点、空引用都不算完成绑定。编号前缀只能作为提示，不能代替实际类型核验。只写提示词且未连接平台时，明确“文本映射已核对／实际输入待核验”，不称已绑定成功。

归档中的警示：

- P3 SC15-2有场景／声线引用类型错配，P3 SC16-3及P1 LX14有台词旁跟图片引用；保留角色与声音分工，纠正实际引用。
- P1 LX-2.5资产栏声线空缺而对白段有音频；合并核对，不因一栏空着就发明新声线。
- WX3节点设置为5秒，正文仍有约30秒动作；引用齐全不等于生成参数一致。
- 早期输入列表中出现2秒黑屏视频，只能确认它曾作为输入；不能推断它是必需的“激活素材”，不默认添加。

## 4. 冲突解决与优先级

用户当前明确指定的外观、状态和参考分工优先；其次是本项目已确认的对应职责素材与连续性。旧原文的角色、怪物材质、能力、破坏产物与机构名称不覆盖当前故事；例如借纸质怪兽战斗的镜头写法，不等于把新怪物绑定成纸质或让其受击化成纸屑。参考资料之间矛盾时先看是否职责不同；若同一职责确实冲突且会改变身份／关键造型，指出冲突并请求选择，不静默混合。

例如人物图是贴身短款裙装，却文字写成飘扬长裙：删改错误衣型，只让实际存在的下摆边缘、束带、碎发和尾坠响应风压，不改成“所有衣料不许动”。未看清后侧结构时不要猜分片数量。武器长度与持器图不一致时说明比例冲突，不能为了炫技偷偷把短刃改成长枪。

场景图可仅参考城市建筑元素，不继承光照；也可按用户要求同时锁夜色。不是所有场景都一律“不参考背景、打光”。特效图可锁月牙轮廓而不锁机位与占幅；首帧图则可以锁机位，但其运动出口必须与下一动作兼容。

## 5. 用少量文字把职责写清

以下是待绑定模板，不含任何真实上传编号；仅填本段需要的项，不要求用户为每一维额外制图：

```text
· 角色A【面部绑定：】【造型绑定：】：同一人物。面部参考负责身份，造型参考负责体态与服装；<简短已知外观、实际衣型>。不继承人物设定图的背景与打光。本段起始<状态>。声线【音频绑定：】，仅用于A。
· 武器【绑定：】：唯一一把，<尺寸、刃柄结构、连接部件>；持器图【比例绑定：】仅参考人物与武器的相对尺寸，不覆盖面部或服装；起始由A右手持有。
· 场景【绑定：】：<布局与地标>；参考<材质／建筑元素／光照的所需范围>。起始<完好或已有破坏>，镜内破坏延续。
· 特效图【绑定：】：仅参考<形状与层次>，不继承原图机位；本段形成、移动与持续时间按分镜。
```

只提供一张角色图时可同时承担身份与造型，不制造重复待绑项。已有声线在资产栏定义一次，镜内每条台词就地标说话者与正确音频引用；复杂多人、画外接话或易串音处重点重申，不反复抄全套外观。每个独立生成段保留必要身份和状态，镜内只重述变化与高风险调用。

交付前检查：引用用途匹配；本段需求都有素材或明确待绑；图像描述与已见素材一致；世界坐标不受参考视角绑死；状态进出可追踪；声线、画内／画外和口型要求相容。检查结果留在正文外。
