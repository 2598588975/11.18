## 选择规则

**主动选用、按需落实，不设使用配额。** 新写或优化打斗、创意高光时，主动比较适合关键节拍的方法，让镜头承担动作交接、空间揭示、情绪强化或节奏变化；已有表达有效就保留。读索引、下方场面调用规则及被选条目即可，不必每次通读24项。

- 用户当前的视点、速度、画风、禁项与已经确认的镜头优先。战斗成熟高光仍执行原文优先流程；本库支持摄影执行与情绪、节奏增强，在本次允许调整的镜头内主动选用；保留已选主底稿的动作链和招式。
- 图中的“电影级8K超写实”、演员、场景、光线、爆炸和子弹均为示例，不默认写入项目。二维动画用虚拟机位、绘制透视、背景层视差、方向拖影表达同一方法，保持项目已定媒介。
- 一镜先选一个主导运动。确需复合时说明先后或同时、哪个对象保持稳定，以及结尾停在哪里；不能在同一瞬间同时推进、绕行、滚转、变焦、拉焦而失去主动作。
- 速度感来自角色位移、空间视差和动作节拍；切镜次数、晃动幅度不等于速度。交锋的接触、受力、分离要可读，冲击帧留在接触事件内，不用甩镜藏掉命中。高能运动之后及时给出可辨的落幅。
- POV是否允许手、武器、发丝入画按当前需求决定，不从图中默认继承。用户明确“看不到视点人物”时，连肩背、手和武器边缘也不出现；人物没有退，视点不能凭空后撤。
- 子弹时间、倒放、时间交叉、完整360度运动只在叙事或明确风格需要时选用。它们不默认开启，也不是全局禁止；不能因为库中有该项就给角色增加时间能力，或把快打整段改成慢放。

## 打斗与创意镜头的主动调用

新写或优化打斗、追逐、强视觉段落时，在突进、目标交接、攻守反转、腾空、破坏揭示与英雄收尾处主动查本表；创意段落同时考虑视线、声音、遮挡和情绪变化。可在内部比较少量合适方法，选出有明确表现收益的一种，直接落实到分镜，用户不必点名技巧。下表是候选方向，不要求每个节点切镜，也不要求全部用完；已确认的高光只在本次允许调整的范围内适配。

战斗选镜时同时查[F01—F15索引](combat-camera-methods.md#快速索引)的动作接口：近身换位用F01，低位接近用F02，空中慢读用F04，主观／肩后分别用F05／F10，空间升降／穿行分别用F06／F11；细节只加载本场采用的条目。

接镜与速度按以下规则落实：

- **速度随事件变化**：在发力、追上、交锋、急停处安排加速、跟住或减速，允许稳定跟拍拍出高速动作。关键接触保留方向与受力证据；动画可用短促冲击帧加强命中，随后接分离与后果。镜头减速不等于人物减速，升格另写进入及退出。
- **在动作中交接**：出手、目标转移、碰撞或反应可成为切点，相邻镜接同一次动作的后续相位；既定同步回看另标。保持主运动方向，越轴用可读的连续绕行或中性机位过渡。甩镜、环绕后用清楚的落幅交还方向，可继续跟拍，不必每次另插静止镜。
- **让观众读懂空间**：连续攻防可用中全景与足够景深保住双方和接触；细节特写用于关键识别或反应。路线或优势变化时适时给关系镜头，避免始终贴脸。拉焦与有意失焦放在需要的注意力交接处，不盖住唯一交锋证据。
- **按风格调整强度**：动画可适度夸张透视、视差和镜头加速度，真人保持可理解的机位轨迹；同段围绕主方向与主视点发展变化。子弹时间、全周环绕和时间剪辑可以作为高光选择，写清用途与回到主节奏的节点，不连续铺满高强度旋转或慢放。

## 经典进阶：A01—A08

<a id="a01"></a>
### A01 POV主观视角

- **适用**：需要观众从某个角色所在位置承受威胁、寻找目标或经历移动。视点归属必须明确，不等同肩后镜头、对着主角拍或无人机视点。
- **执行**：以该角色眼位起幅，朝其实际注视方向取景；随真实转头、蹬跃、侧闪改变朝向或位置。自然呼吸感可选，不自动加入大幅晃动。攻击者逼近时用相对距离缩短和画内尺寸增长表达压迫，焦点持续跟随来人。
- **落句示例**：从防守者第一人称正对迎面冲来的对手；镜头先留在实际站位，待防守者横向闪避时同步侧移，刀锋掠过旧视线后稳住新落幅。按本镜要求锁定身体和持物是否可见。

<a id="a02"></a>
### A02 子弹时间

- **适用**：某一瞬间的姿态、弹道或空间关系值得额外阅读，且不会削弱本段要求的高速节奏；不需要画面中真的有子弹。
- **执行**：注明进入的动作相位、表现时长、机位沿哪侧绕多少弧度、退出时接回哪个动作。可表现近乎凝固而镜头运动，不把它当作正常实时机位绕行；只有确需全周展示才使用360度。
- **边界／落句**：接触前极短时间放缓，镜头沿既定一侧短弧揭示双方武器错位，随后回到正常速度完成碰撞。另算表现时间与事件时间，不凭空给另一角色额外进攻窗口，不改变角色能力。

<a id="a03"></a>
### A03 希区柯克变焦（Dolly Zoom）

- **适用**：突然理解威胁、心理失衡、空间压迫；只在背景纵深与透视变化能被读出时有用。
- **执行**：机位前推同时缩短焦距，或机位后拉同时增加焦距，使主体在画面中的尺寸近似不变，背景透视关系明显改变。写清方向、触发和结束状态。
- **边界／落句**：人物意识到身后危险时，机位向前而焦距同步变广，面部占幅保持，身后走廊被视觉拉伸；认知落定后停止变化。普通推近、单独变焦、前后拉焦都不能冒称此法。

<a id="a04"></a>
### A04 迈克尔贝环绕运镜

- **适用**：英雄起身、强者登场、决心转变或力量对照。名称作为图中索引；成品要写具体低位弧线、速度和落幅，不能只报导演名。
- **执行**：从主体侧前低位沿圆弧移动，可配合轻微升高或人物起身；已有光源在人物轮廓上形成连续变化，背景视差增强气势。环绕角度取决于要揭示的信息，不默认绕满一圈。
- **边界／落句**：角色握紧武器抬眼时，镜头沿同一侧低位短弧移至正侧前，落幅于人物和其面对的威胁。图中的爆炸、直升机、逆光炫光不随此方法自动加入。

<a id="a05"></a>
### A05 跟拍（普通＋稳定）

- **适用**：走位、追逐、同行对话和完整攻防；根据观看目的选后跟、侧跟或前方后撤跟拍。
- **执行**：明确跟谁、相对站位、镜头距离及何时加减速。稳定跟拍保留地面与背景视差；普通跟拍可有与运动相符的起伏，但不无故晃动。主体被跟住不代表环境停止移动。
- **边界／落句**：侧前方同步跟住奔跑者，前景柱体快速掠过；其踩停时镜头短促减速并落到目光目标。前方后撤跟拍可以看见被拍者本人，不能与该人物自己的POV混称。

<a id="a06"></a>
### A06 低角度拍摄

- **适用**：强调身高、威势、蹬地、武器与天空的剪影；它首先是机位选择，可以固定，也可与跟拍结合。
- **执行**：说明相对地面的高度、朝上仰角和取景边界，保留必要的地面接触。超广角仅在有意夸张时选，不自动把所有脸与肢体拉伸。
- **边界／落句**：机位靠近石面，仰拍持刀者踏入并停稳，支撑脚、刀身和上半身形成清楚纵线。低机位不等于窥视衣内，不自行增加暴露角度。

<a id="a07"></a>
### A07 悬停变焦

- **适用**：保持机位位置，从环境或全身聚向表情、手中物件；用于明确的注意力收拢。
- **执行**：机位基本固定，通过改变焦距连续改变取景范围，焦点跟住同一目标；机位不动时没有前推造成的视差变化。图示中的人物背面到正脸若要发生，必须另有转身或切镜依据。
- **边界／落句**：远景暂留人物与环境，人物听见声音抬头时平滑变焦至上半身，停在其表情变化上。不与推轨、拉焦或Dolly Zoom混写，不无理由反复伸缩。

<a id="a08"></a>
### A08 甩镜（急摇／Whip Pan）

- **适用**：跟随射出物、追上突然移动的对象、响应画外声或连接两个方向明确的信息点。
- **执行**：写明从谁甩向谁、方向、触发和落幅；甩动途中允许短暂方向性模糊，落到新主体即减速恢复清晰。若中间藏剪口，要明确是剪辑连接并匹配运动方向。
- **边界／落句**：箭离弦触发向右急摇，在箭将抵达的刀前落稳，保留真实格挡与受力。不能每一下挥刀都甩一次，也不以模糊遮住唯一的命中证据。

## 特色创意：B01—B12

<a id="b01"></a>
### B01 逆光升高运镜

- **适用**：由人物情绪揭开其所在环境、结尾格局展开、归来或远行。使用场景已成立的背光来源，月光也可，不强制换成日落。
- **执行**：从近景或中景向后上方移动，逐步显露脚下位置和远处层次；主体由细节变成环境中的轮廓。是一条连续升高后退的路径，若改成切镜组须单独标明。
- **落句**：人物站定望向远处，镜头越过肩侧缓升并后退，最终露出整片遗迹和月盘，让人物留在可读的前景位置。

<a id="b02"></a>
### B02 360°俯冲螺旋环绕

- **适用**：已明确的坠落、空中翻身或强空间翻转；需要完整360度观感时才选完整版本。
- **执行**：把俯冲高度变化、绕行中心、半径、方向和落幅分开写清。绕主体环行不等于镜头绕光轴滚转；若需要滚转另写角度，不从名称推断两者同时发生。全周运动要有容纳它的时间与空间。
- **边界／落句**：镜头从腾空人物侧上方沿下降螺旋绕行一周，保持人和落地点的关系，结束时回正地平线并看清着地。若只需短弧俯冲，就按实际路径命名，不谎称完成360度；近身关键碰撞不默认用此法。

<a id="b03"></a>
### B03 平滑升降环绕

- **适用**：在人物、平台和周围建筑之间连续建立层次，表现舒展或宏大；与B02的急促俯冲分开使用。
- **执行**：高度平滑变化，机位同时沿可追踪的弧线绕主体，说明最终变为平视、仰视或俯视。高度变化不代表光轴必须滚转。
- **落句**：由人物侧后低位沿外侧缓升环绕，前景栏杆逐渐退出，落在能同时看到人物所在平台与远景的高位构图。途中不要无由穿过实体或越轴后丢失方向。

<a id="b04"></a>
### B04 垂直拉升／缓慢下降

- **适用**：揭开墙体后空间、逐层展示建筑或把全局落回某个人。
- **执行**：机位沿垂直方向移动，交代起止高度或可见地标；需要时平滑调俯仰维持目标，水平位置及滚转保持稳定。不要把原地上摇说成垂直升高。
- **落句**：从台阶前人物的胸口高度垂直升至墙顶，露出院内路线；或从高位缓降至人物视线高度，把注意力交回表演。

<a id="b05"></a>
### B05 侧拍慢推／俯拍慢拉

- **适用**：前者用于走心台词、微表情和情绪递进；后者用于孤独、离别或人物与环境的距离。
- **执行**：这是两个可选分支，不要求连续做完。侧拍慢推保持侧前角度接近；俯拍慢拉保留向下观看关系，后撤揭开周围空间。写清由什么表演或信息触发。
- **边界／落句**：人物收住笑意时，侧前镜头缓推至表情；对白结束后也可另选俯拍慢拉，让空旷环境进入画面。不要在高速对抗中用慢推替代攻击过程。

<a id="b06"></a>
### B06 FPV穿越机视角

- **适用**：环境穿越、沿路径追踪、俯冲穿洞或空间探索。视点属于飞行摄影机时，不误称某个地面角色的眼睛。
- **执行**：先给入口、转折、可通过的间隙与出口，再设加减速和必要倾侧；关键通道保留清楚边缘，退出时建立方向。过洞要求有真实净空，不能穿过墙柱。
- **边界／落句**：镜头沿水面加速，侧倾穿过断拱空隙，出拱后减速抬升，落到前方石台。是否一镜到底依项目而定，不自动把整片改成FPV或增加飞行角色。

<a id="b07"></a>
### B07 上帝视角

- **适用**：交代包围、进退路线、两人间距、阵形及破坏范围，观众需要读懂平面关系时使用。
- **执行**：机位高处垂直向下，保留可辨的固定地标与主体位置；需要扩大全局时沿垂直方向拉高。普通斜俯拍与90度正俯视要分开命名。
- **落句**：从正俯视交代两人分别位于水池两侧，随真实跑动看清追击与绕行路线；空间关系读清即接回动作，不为了宏大把人物缩到不可辨。

<a id="b08"></a>
### B08 诺兰式时间操控

- **适用**：项目已需要的时间交叉、闪回、倒放或不同速度并置。此条是时间组织与剪辑候选，不是单一摄影机运动，也不凭名称调用其他导演skill。
- **执行**：写明每段所属时间层、正放／倒放／升格、可辨的衔接信号及回到主时间线的位置。事件时间与成片时间分别核算；倒放的物理结果和角色是否感知必须服从剧情。
- **边界／落句**：先呈现既定事件结果，再以明确闪回补足原因，回到同一主时间线继续动作。连续30秒决斗只要求更快时，不自行加入倒放、时间能力或碎片化蒙太奇。

<a id="b09"></a>
### B09 弧形／蛇形／螺旋推进移镜

- **适用**：弧形用于揭示侧面与关系；蛇形用于沿真实障碍探索；螺旋推进用于逐步逼近与空间压迫。
- **执行**：按本镜目的选其中一条路径。弧形写弧心和观看侧；蛇形写S形经过的实际前景遮挡；螺旋推进写向中心收拢的半径及是否升降。默认保持地平线，滚转另行说明。
- **边界／落句**：镜头从柱后沿一条小弧线接近人物，前景遮挡退出后露出其目光对象。没有障碍或新信息时不用无目的S形乱摆；同类温和情绪版本可选C04。

<a id="b10"></a>
### B10 虚实焦切换（图中别名：焦点呼吸）

- **适用**：发现线索、转移注意力、目光回应或同空间关系揭示。
- **执行**：规范写法为“拉焦／转焦”：前后主体都真实存在，说明谁先清晰、何事触发、何时把焦点交给谁，机位是否固定。光学上的“焦点呼吸”是调焦时视角的伴随变化，与拉焦不是同一概念，不强制生成画面缩放。
- **落句**：先让近处花枝清楚、后景人物虚化；画外脚步触发拉焦，花枝虚下去，后景来者清楚。不要同时要求前后全锐利，也不让焦点变化凭空生成新角色。

<a id="b11"></a>
### B11 贴地滑行运镜

- **适用**：强调落脚、车辆或角色掠过地面的速度，表现水纹、碎石和支撑点；可用于威势登场或短段动作跟随。
- **执行**：镜头以贴近地面的高度水平滑行，交代跟随对象、朝向和终点，近景地纹快速通过；是否仰拍另行说明，不能把超低位与固定仰角绑定。
- **边界／落句**：镜头贴着湿石沿人物蹬地方向滑行，水花与地缝形成强烈近景视差，在落脚处稳住并接上身体动作。避开需要看脸、手部格挡的决定性瞬间，不擅自切断关键接触。

<a id="b12"></a>
### B12 逆光推镜

- **适用**：归来、决心、对峙剪影或温柔情绪，场景已存在合适背光时选用。
- **执行**：向人物推近，控制背光与暗部，使脸部或武器轮廓按本镜需求可辨。光晕和眩光有真实来源；太阳、月盘或爆炸余辉沿用当前场景，不为方法擅自更换时间和光源。
- **落句**：月盘位于两人身后，镜头轻推至左右对峙的清楚剪影，弓弦与双手持刀姿态保持完整，落幅后留出短促阅读时间。剪影不意味着吞没全部辨识结构。

## 通用高级：C01—C04

<a id="c01"></a>
### C01 遮挡无缝转场运镜（动态前景遮挡转场）

- **适用／位置**：用于同一段落中途的动作接续、视角交接或有依据的地点／时间转换。20—30秒段落可在中间需要衔接的节点调用，不绑定某个秒数；通常移出遮挡后立即继续叙事，不默认把最后一次遮满处理成片尾黑场。用户明确要求片尾衔接时再用于尾部。
- **主动调用条件**：人物转身、擦镜经过、追逐换位、前景动物横穿，或需要从一个观看侧接到另一个观看侧时，考虑借运动前景藏切。选已成立或适合本场的斗篷、衣摆、翼膜、马身、车体等；运动须有来向和原因，不为凑转场打断动作，也不每次有人经过都切镜。
- **执行链**：明确遮挡物、入画侧、触发动作和下一镜内容；前景贴近镜头扫过，逐步占满画面，在完整遮满的瞬间藏切；下一镜延续可衔接的扫动方向、速度、材质与亮度关系，遮挡物移出后露出下一机位或新空间。机位可保持不动，由物体主动掠过；也可由跟拍靠近前景触发。关键是画面被实体短促遮满，不需要摄影机钻进物体，也不以无来源的黑屏或淡出替代。
- **可选例子**：以下分别选用，不连续叠加；同空间可承接同一遮挡物，换场时用有视觉依据的遮挡边缘匹配。
  - **斗篷／衣摆扫镜**：人物向右转身，斗篷下摆顺惯性贴近镜头从左向右扫满画面；遮满时切到侧后机位，同一方向的衣料边缘退出，人物承接原转身继续冲向目标。
  - **蝙蝠掠镜**：蝙蝠从既定来向掠近，近处翼膜或密集飞过的蝙蝠群短促遮满镜头；藏切后沿原来向退出，露出后续镜头。远处一只小蝙蝠只掠过角落不能充当全幅遮挡。
  - **马匹横穿**：镜头留在路边，马从左向右跑过近前景，贴近的马身短促遮满画面；藏切后马身向右退出，露出新的观看角度或后续空间，蹄声可跨镜延续。远处马腿扫过但仍看见背景时不能藏完整剪口。
- **接戏与声音**：同一次动作换机位时承接动作相位、左右位置、持物与速度，遮挡期间人物仍按事件时间继续运动；换地点或时间须在下一镜说明，不借藏切重置战斗距离。衣料掠风、翼拍或蹄声可做短声音桥，随下一镜距离与环境调整，移出遮挡即交回主体与空间方向。
- **使用边界**：这是隐藏剪辑。遮挡物服从角色服装、资产和世界观；允许新编的段落可按氛围设计短暂经过的蝙蝠或马匹，不必扩写成新角色或支线，已有“无其他人物／生物”等限制时改用本场衣摆或物体。关键格挡、命中与受力证据保留在遮挡前后可见的位置，遮挡不掩盖唯一的交锋证据。

<a id="c02"></a>
### C02 呼吸运镜

- **适用**：安静特写、等待、含蓄情绪或近乎静止的环境空镜，需要很轻的生命感时使用。
- **执行**：机位极小幅、缓慢前后微动或轻微起伏，构图基本稳定；不要同时添加大幅变焦或拉焦。它不同于B10的焦点变化，也不等于手持抖动。
- **落句**：等待回应的近景保持人物眼神清楚，镜头只有不夺目的微小起伏，表演变化仍是主体。固定机位要求优先，高速冲锋不套慢速呼吸节奏。

<a id="c03"></a>
### C03 升降横移复合运镜

- **适用**：开篇空间交代、露出遮挡后的路径、沿建筑层级转换关注点。
- **执行**：同时垂直升降和水平位移，明确起点、两方向速度变化、遮挡关系及最终构图；两轴可协调，不必数值速度相等。没有另外要求时保持地平线稳定。
- **落句**：镜头从近处石墙外侧同时上升并向右平移，越过墙顶后让池面和后方通道逐层进入，落在完整空间关系上。交代何时越过遮挡，不能直接跳到终点。

<a id="c04"></a>
### C04 轨道弧形推镜

- **适用**：人物表情、细腻关系和柔和气氛，需要比直线接近更丰富的背景视差时使用。
- **执行**：沿小弧线平滑靠近主体，保持选定构图锚点，缓慢减小距离；弧心、观看侧和落幅要清楚。如果只是定半径圆周移动，应写环绕，不冒称推近。
- **落句**：从人物侧前中景沿同一侧小弧线缓缓靠近，背景栏杆发生轻微视差，停在表情变化上。它是B09弧形路径的克制情绪用法，不为了区分编号强行叠加两次环绕。

## 写入分镜的方式

沿用乱霞号当前A或B格式，不额外向可复制正文追加“使用技巧清单”。在摄影机字段写出：**视点／机位与景别 → 动作或信息触发 → 路径及速度 → 焦点交接 → 落幅**。简单镜头只写实际需要的部分；人物行动、攻击特效和受力后果仍放画面内容，音效跟随其真实事件。

具体场面按上方[主动调用规则](#invocation-rules)比较候选，再读取对应方法卡；只把采用的方法写成可见路径与落幅，不向成品罗列未采用的技巧。

完成后检查：技巧是否改善了本镜的信息、情绪或节奏；是否改坏用户指定视点、速度或成熟镜头；起止位置与焦点是否可执行；运动与时间效果是否混淆；关键接触是否可读。没有收益就删去新增技巧。库条目不等于已验证某模型可稳定执行。
