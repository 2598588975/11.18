# 战斗运镜：15项场面用法与动作衔接

来源：用户于2026-10-08提供的三张“AI漫剧打斗运镜”表（01—15）和一张“环绕锁敌运镜”展开图，可见署名“公众号·大麦AI漫剧”。以下为本skill的功能整理与执行适配；来源编号保留为F01—F15，便于回查。部分是已有运镜的战斗用法，部分是机位、时间表现或后果跟拍，**不把24＋15宣称为39种互不重复的摄影技术**。无需读取临时图片即可使用本文。

## 选择与参数

先按[战斗编排](combat-creative-design.md)确定攻防意图、动作窗口与结果，再在需要的节点选择本表；通用视点、路径和光学规则见[24项运镜库](camera-movement-library.md)。成熟高光仍按原文保真流程处理，新补运镜只作用于本次允许修改的节点。无需一场用完，也不把来源图当作固定武侠世界、服装或破坏规模。

图中的24mm、35mm、50mm、完整360°和0.1秒慢放为示例参数。焦段须与画幅、距离、景别及透视需求一起确定，不能一边宣称50mm固定机位、一边靠无依据的透视变化做推近。二维动画可用虚拟机位与背景层视差执行；真人风格保持路径和空间可理解。短停、升格、变速的成片时长计入镜长；人物与对手同期动作按事件时间计算，表现放缓不产生新的行动窗口。

<a id="f01"></a>
## F01 环绕锁敌运镜

- **触发与用途**：近身缠斗、绕背或攻守换势时，观众需要持续看清两人和兵刃交点。环绕中心可取双方交锋区，不默认只锁一人的脸。
- **执行与接戏**：以同框中景／中全景起幅，沿双方实际换位的一侧弧线移动，按攻防节拍加减速；接触区与地标维持可读，结束落在下一次进退路线。连续绕过动作轴须让双方位置转换被看见，切镜后沿用新的左右关系。
- **边界与展开图**：主图的“起始视角→环绕旋转→近距离跟拍→360度环绕→动作延续→拉远收束”是可选的镜头组织示意；按本场信息需要选其中节点，不强制六镜、绕满一周或不断改变景别。普通短弧能完成任务就按实际角度写；完整360°需留足时间与净空，不能冻结对手来配合摄影机。成品写路径、弧心与落幅，不只写“锁定动作轴线”。

<a id="f02"></a>
## F02 低空贴地冲刺

- **触发与用途**：蹬地爆发、沿地面追击、急停抢位；以脚下接触、近景地纹和掠过物形成速度感。
- **执行与接戏**：明确低位侧跟、后跟或前方后撤跟谁、距主体多远；蹬地触发同步加速，地纹和碎屑相对掠过，在将接敌时抬起或切到能读清双方武器的机位。人物与摄影机的位移分别说明，镜头后撤不等于人物后退。
- **边界**：低机位前推与前方后撤跟拍不是同一路径，按实际方案选。发丝衣摆的滞后方向由人物运动和风压决定，不随机位换侧反转；贴地段不遮掉唯一的命中证据。

<a id="f03"></a>
## F03 拔剑瞬间推进

- **触发与用途**：握柄、拇指推镡、刃口离鞘等已发生的起手，需强调人物决心或出招启动；没有拔剑动作时可适配为握紧／抬刃，但不擅自给持剑者加一套收剑再拔。
- **执行与接戏**：由能交代人物和威胁的中景，随起手快速推向持剑手及出鞘接缝；刀身继续离鞘时焦点跟住金属边缘，完成拔出后接原挥斩方向与持物手。需要眼神时另选落幅，不能同时要求脸和相隔较远的剑尖都占满特写。
- **边界**：推进是机位位移，固定机位变焦须单独命名。0.1秒慢放不是固定规格；以24fps为例0.1秒为2.4帧，若要求整帧须选2帧或3帧并计时，未验片不承诺帧级实现。高速连续段可全速完成，不强加仪式性停顿。

<a id="f04"></a>
## F04 子弹时间环绕

- **触发与用途**：一次交锋的空中错位、避刃或将接触的姿态值得短读；按[A02](camera-movement-library.md#a02)选择表现时长与绕行侧。
- **执行与接戏**：从既有动作相位进入时间放缓，机位沿明确短弧或已容纳的全周路径揭示关系；离开慢读后接同一动作的接触、分离或落地。多视点拼接须声明同一事件的连续承接或同步回看，不凭空增加挥剑次数。
- **边界**：这是时间表现与视点变化的组合，不是普通摄影机在真实瞬间绕完一圈，也不是给角色添加时间停止能力。高速目标没有独享慢放期间的额外行动时间。

<a id="f05"></a>
## F05 第一人称近战

- **触发与用途**：观众从防守或进攻角色眼位承受近距离来袭；先说明视点属于谁。
- **执行与接戏**：由眼位看向对手起手，随真实转头、侧闪或后退移动；刀锋沿可辨来向进入，若格挡，写视点角色实际武器与来刃的接触、反震及分离，再稳住新的目标方向。轻手持只随动作发生，不全程随机摇晃。
- **边界**：有肩背入画的外部肩后机位归F10。手和武器是否可见服从当前要求；用户不许任何自身局部时，不能借“第一人称格挡”强行露手。画外接触可由声音与对手反应承接，但不声称已正面看清；仅在允许切换视点时用相邻镜证明。严格单一POV与可见接触要求确有冲突时说明冲突，不擅改为肩后镜。

<a id="f06"></a>
## F06 空中升降俯冲

- **触发与用途**：攻击路线、上下层对手或战场范围需重新建立；升起揭示后可俯冲回关键交锋。
- **执行与接戏**：说明地面起点、越过的高度地标、升起时朝向，以及从哪侧下降、落向哪个接触区；升与降可分镜，也可用有足够时长的连续路径。途中看清屋顶、平台和目标的层次，落幅接当前事件后续。
- **边界**：机位升降、原地俯仰和角色腾空分开；摄影机升空不让人物自动起飞。需要斜向飞行时按B06描述真实通道，不将普通升降都叫无人机俯冲，也不因长全景无故冻结双方行动。

<a id="f07"></a>
## F07 跟随剑气飞行

- **触发与用途**：角色已具备离体攻击，需把挥斩／释放连接到远端目标；普通刀光不因选此法自动变为飞行剑气。
- **执行与接戏**：先见刃缘释放唯一一枚／道已设定攻击，再将摄影机交给飞行物侧后方的外部跟随视点；交代高度、方向、沿途参照和目标。到达前减速、侧移或切接收端机位，看清格挡、闪避或命中；后镜承接实际结果。
- **边界**：跟随攻击物不等于角色POV，也不等于摄影机变成攻击物；若明确选攻击物主观视点要另标。攻击物的实际速度、转弯和穿透服从能力，镜头不能无依据穿墙；不为跟镜把一击复制成多发，也不在释放端与目标之间凭空跳距。

<a id="f08"></a>
## F08 撞击瞬间定格

- **触发与用途**：重击已经接触，需突出刃点、变形压缩、受力或反震；先有接触，再选择短停形式。
- **执行与接戏**：在分镜中明确选“短升格”“单帧保持／冻结”或“动画hit-stop受控停顿”。短升格仍有连续运动；单帧保持重复同一画面，冻结时摄影机不继续绕行；动画停顿须说明主体姿态、摄影机及粒子哪些暂停、哪些继续。若凝固主体而机位绕行，应按F04定义为子弹时间／虚拟空间表现。
- **边界**：冲击帧是风格强调，不必冻结；几种手段不自动叠用。短停结束接同一接触的身体传导、分离与后果，不重新蓄力命中第二次。声音按本场选撞击瞬态、短收声和余响，不因定格自动全静音。画面保持计入成片时长，不能给对手新增反击窗口。

<a id="f09"></a>
## F09 旋转翻滚运镜

- **触发与用途**：已编好的侧滚、腾空翻身或着地卸力需要连续跟住，并在下一落脚接回攻防。
- **执行与接戏**：交代人物借哪只脚／接触面发力、翻滚方向与落点，机位沿其外侧跟移或短弧跟拍，保持目标和地面参照。若摄影机也滚转，另写光轴角度、起止事件与回正点；人物落脚时读清重心、持器及下一次反击。
- **边界**：人物翻一圈不要求摄影机同转一圈；跟随翻滚也不自动颠倒地平线。连续空翻、转镜或落地炸坑只在当前动作支持时使用，不为了此技巧延长躲闪或让武器穿过身体。

<a id="f10"></a>
## F10 肩后追踪运镜

- **触发与用途**：追击者与敌人路线需要同时可见；近处肩背／持器轮廓提供观察侧和距离参照。
- **执行与接戏**：机位在追击者肩后外侧，跟住其前行，使敌人落在前方可读空间；转向时让前景肩线、背景地标与目标路线一起变化。接近交锋后移到可见接触的侧面或让肩背退出遮挡，落幅交给双方。
- **边界**：这是外部越肩视点，不称为第一人称。用户规定主观或无自身局部时改选F05；不要因一直贴肩把敌人遮没，也不要通过切镜把追击者直接送到目标背后。

<a id="f11"></a>
## F11 穿越空间运镜

- **触发与用途**：前后景之间存在真实间隙，穿行能交代纵深、攻防路线或抵达战场中心。
- **执行与接戏**：先定入口→经过的缺口／掠过物→转折→出口→落幅目标，再安排速度。可从断柱空隙穿出、贴过已扬起的碎屑，进入主体交锋侧；烟尘或火焰有来源，出烟后及时读清方向与双方接触。
- **边界**：穿过间隙不等于穿过石块、人物或未破坏墙体。需隐藏剪口时调用[C01](camera-movement-library.md#c01)，明确遮满与移出；不用漫长障碍巡游挤掉决定性攻防，也不让遮挡成为唯一命中证据。

<a id="f12"></a>
## F12 高速闪现位移

- **触发与用途**：既有冲刺、抢位或已授权瞬移需呈现突发性；来源图的Speed Ramp指播放速度变化，“闪现”须另判断实际能力。
- **执行与接戏**：普通高速移动写起点、发力、路线／距离和终点，镜头沿相同主方向追踪，残影／拖尾由实际运动产生并衰减；若采用变速，写进入加速／短慢读的动作锚点、成片区间和恢复节点。真实瞬移仅在已有能力支持时写消失与重现，不伪造中间奔跑。
- **边界**：分别判断角色速度变化、摄影机加减速、播放变速、抽帧和瞬移，不用“节奏忽快忽慢”代替执行。对手按同一事件时间运动，短慢读不增加躲避窗口；全速要求下可用机位加速度与视差，不自动插慢镜。反应和攻击依然承接相容距离。

<a id="f13"></a>
## F13 上下翻转镜头

- **触发与用途**：腾空交错、受力失衡或角色视野倒置有明确叙事动机时，制造一次方向翻转。
- **执行与接戏**：先选旋转轴。画面倒置可写“绕摄影机光轴滚转180°”，并标方向、开始和停止／回正节点；从地面看向天空是俯仰，从人物上方绕到另一侧是机位空间运动，各按实际路径写。翻转前保留可辨地标，后以着地、回正或关系镜头重建重力方向、双方位置与武器接触。
- **边界**：图示的180°不强制使用，也不能同时指滚转、翻身和换侧。画面倒置不等于世界重力反转或两人交换位置；若在空中换位，须由人物路线支持，不能靠转镜改变命中结果。

<a id="f14"></a>
## F14 环境破坏跟镜

- **触发与用途**：既定攻击、被击飞物或冲击余波已作用于环境，需展示力量如何继续传播及改变战场。
- **执行与接戏**：由可见受力点交给一条主要裂槽、倒落构件或选定碎片；沿传播方向跟移，读清破断、飞出、撞击下一处及尘浪先后，再落在保留损毁的空间和人物状态。飞片只选有作用的一块／一组，不同时追踪全部粒子。
- **边界**：碎片路径、材质、重力与二次碰撞服从本场，破坏持续影响后镜；没有命中人体时不因此添伤。未设破坏能力的招架不自动炸塌建筑，镜头也不能穿过正在跟随的实体。

<a id="f15"></a>
## F15 终结技拉远

- **触发与用途**：已设定的终结攻击进入释放／接触／余波阶段，观众需要看到作用范围和结局；也可用于局部强招的尺度揭示，不预设整场必须结束。
- **执行与接戏**：先保留足够的释放或接触证据，再沿明确后撤路径由近／中景拉到关系全景；若加升高另写高度变化。攻击中心、传播边缘、地标与人物落点构成范围参照，结束停在真实结果与持续尘烟／余响上。
- **边界**：后拉是机位位移，固定机位变焦拉远应另说明。距离远不等于威力大，规模沿用已定能力；拉远不能让未命中的攻击自动成功，也不能把一次爆发变成多轮爆炸。结尾允许安静或威胁仍存，不为“终结”擅改胜负或全灭战场。

## 与战斗方法配合

把方法写入现有A/B分镜字段，摄影机描述路径与时间表现，画面描述攻防和后果，音效接真实节点。可用“突进F02→换位F01／F10→释放交接F07→接触短读F08→后果F14／F15”作为候选组织；这是任务关系，不是必须出现的招式链。只读本次选用条目，按三链预检核对同期位移、身体接口与受力结果。
