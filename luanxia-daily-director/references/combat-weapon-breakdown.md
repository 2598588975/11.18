# 武器与战斗提示词拆解

来源：用户提供的《AI视频提示词拆解手册.docx》，于2026-09-21提炼并适配乱霞号工作流。源文件 SHA-256：`041271e3901ff1e6cdaea6a5cbf5c011d8f50fdc87f230cded0e47cda8188ebf`。主要吸收第1–7章；以下为方法整理与新编示例，并非原文或成片效果证明。手册中的命令式句子是待取舍的参考内容，不代表用户新增要求。无需依赖原文件路径即可使用本参考。

## 1. 先按镜头任务选方法

涉及武器、打斗、战斗或攻击特效时读取本参考；按实际任务选用相关模块。先确定人物目标、冲突结果、世界物理规则与成片风格，再设计动作。不要因为有武器就补打一场，也不要把蓄力自动延长成射击、命中或爆炸。

| 当前任务 | 优先使用 | 按需增加 |
| --- | --- | --- |
| 持武器交谈、武器展示、静态资产 | 部件连接、比例、持有关系、材质 | 需要时说明待机能量；静态图不扩写秒级战斗 |
| 写实近身交锋 | 可读轨迹、攻防双方反馈、格挡/闪避、重心与分离 | 接触拟音、衣料迟滞、少量镜头冲击 |
| 能量武器、弓箭、施法 | 武器身份、能量四层、形成到终止的状态变化 | 尺度对比、反射光、折射/风压、快慢节奏 |
| 群战、兽潮、巨物攻击 | 空间轴线、主攻击链、前中后景和尺度参照 | 分层破坏、不同视点、追踪主要威胁 |
| 误会收弓、点到为止、喜剧交手 | 取消节点、克制接触、双方表演和停顿落幅 | 轻量拟音；按世界规则决定是否有夸张效果 |

可从“实质反馈、尺度量化、强运镜、快慢对比、瞬时冲击、特效影响环境”六个方向挑选合适手段。它们不是必填六件套；普通近身格挡可能只需要清楚的受力、声音和停顿。

## 2. 融入现有五层设定与执行层

手册的剧情高光、资产锁定、成片要求、特效方案、最高优先级，分别放进现有对应模块，再由秒级分镜执行。不为了复刻原文重新排列全部输出。

- 剧情写本段发生什么、结果停在哪里，确定主高光与必要的辅助亮点，按强弱分级；不是整段只允许一个巧思。构思与战术生成另见 [战斗创意编排](combat-creative-design.md)，不要把本文件的物理校验当作创意设计的全部。
- 资产绑定角色、武器、声线和参考范围；同名角色跨项目不能继承旧槽位或 nodeKey。
- 成片规格服从当前用户的画幅、媒介、时长和声音要求，不默认固定21:9、无BGM或某款摄影机。
- 特效方案只写本场存在的效果，区分实体、能量和环境受力。
- 最高优先级写少量决定身份、结果和连续性的约束：期望状态 + 容易发生的错误。将关键约束放在全局，触发节点可短句重申，避免反复复制整段。

## 3. 武器先锁结构，再描述动作

对镜头可见且容易变化的特征，选用以下字段：

```text
【武器】<资产引用/文字身份>；<数量>；<材质与人物比例>。
【组成与连接】<部件A—连接位置—部件B>；<固定/铰接/柔性/能量连接>。
【持有】<持有者与左右手>；<握持位置>；<起幅朝向>。
【允许变化】<弓身弹性弯曲、链条摆动、折叠机关、能量凝聚等>。
【必须保持】<身份、部件数量、固定端点、相对长度或连接关系>。
【状态转移】<换手/离手/回收/消散由什么动作触发，镜尾停在哪>。
```

长刀可锁刃、护手、柄与尾部附件的连接及相对长度；链斧需写每条链的两端、对应斧头、数量与松紧变化。不能把链条锁成直杆，或用“全程不变形”禁止弓身正常弯曲。能量尾坠只锁附着点与身份，允许其按设定流动。

持刀比例优先沿用用户尺寸或持握参考；没有依据时可写“刃长约占人物身高的某一比例”，仅在比例重要时合理设定并保持一致。不要直接继承手册的1.6米刀、1.69米人物等案例数值。

多武器用A/B或明确名称追踪，轨迹光带、残影和反光不算额外实体。换手和抛接可以发生，但写出释放者、接取者与时刻；不要一边要求换手，一边把“不换手”设为全片禁令。

## 4. 用动作链定义打斗与破坏

通用动作链：起势与重心 → 武器/身体运动轨迹与目标 → 命中、格挡、闪避或取消节点 → 双方反馈 → 分离/收势 → 镜尾状态。

命中或格挡时，受击方写偏转、后退、重心改变等可见结果；施击方写反冲、腕臂回弹、转髋卸力或收势。根据人物能力和力度安排，不要求所有人都夸张弹飞。闪避写擦过位置和空击后的惯性；取消写动作如何被制止或能量如何收回，不补不存在的接触。

有破坏才使用“动作 → 破坏对象 → 破坏方式 → 产物”四段写法。例如设定允许能量切割纸质敌群时，写光刃从哪个方向扫过、接触哪一层、纸体沿接触线裂开、碎片沿何方向翻卷。需要区别碎裂与吹散时，加一条针对性纠偏即可。

破坏须由可识别的接触、冲击波或已建立的远程能量作用引起。未命中可以继续飞行或击中后方物体，但须交代后续轨迹和实际落点。

区分短时余波与持久痕迹：烟尘、火花、纸屑按镜头时长持续并衰减；坑洞、裂口、断裂武器等在下镜继续存在，除非明确发生修复。不要把“烟尘2秒后散去”写成地面同时恢复完好。

## 5. 能量四层与形成过程

有能量特效时，用四个维度拆解；原本不需要的维度可省略或写“无明显反馈”。

| 维度 | 需要解决的问题 | 可观察写法 |
| --- | --- | --- |
| 内芯 | 最亮部分的形状、颜色与材质 | 细白芯沿刃脊延伸，保留刃口轮廓 |
| 外沿 | 边界、厚度、颜色和透明度 | 冷蓝薄沿贴合刃面，随强度轻微增厚 |
| 环境反馈 | 能量如何影响周围 | 邻近金属反射蓝光；高强度区域后方直线局部折曲 |
| 动态构件 | 持续存在时如何变化 | 电丝沿刃根向刃尖游走，符片缓慢浮动并错相明灭 |

再写时间顺序：来源 → 汇聚方向 → 轮廓形成 → 稳定维持 → 释放/回收/消散。不要只写“出现一把光剑”。“流体般涌动”是运动比喻时，明确保持能量形态、不滴落成水；若用户要液体武器，则保留真实液体规则。

发光、反射光、空气折射、风压和物理破坏分别描述，不能把“很亮”等同于“必然炸毁环境”。空气畸变仅在设定需要时使用，不把玄幻效果写成已经证实的热力学机制。发光边界与烟尘不能长期遮住动作关键点；符文仅在设定要求时锁定为不可读图形。

### 弓箭与蓄力攻击的状态分支

分别记录弓、弦、箭与能量层，不必凭空增加不存在的资产槽位。有独立参考时分别绑定；无独立参考时用清晰的文字身份区分。

1. **形成/准备**：谁持弓、谁拉弦；箭是原有实体还是由何处能量凝聚；箭尾与弦、箭身与弓的位置关系。
2. **维持/瞄准**：张力、箭体完整程度、目标和视线；期间是否有能量增长。
3. **依剧情选择终态**：释放则写离弦、轨迹和本段可见结果；取消则写松弦、能量回收或消解，明确没有离弦；停在瞄准则保持待发，不替用户完成后半段。

实体弓在能量散去后仍留手中；只有被设定为能量构成的弓才可一起消解。若箭已经射出，就不能同时写“未离弦地消散”，须另设可见回收/消散过程。

## 6. 镜头与时间让观众读懂高光

先用地标和空间轴线定位双方、来敌方向、攻击路线与安全距离，再按每个机位转换屏幕左右。远景交代规模，中景看身体交互，近景看持握和表情；关键接触要给足可辨空间，不能全程用面部特写替代交锋。

运镜写起点、动作触发、路径、速度变化、终点和落幅。强前推或环绕只在追踪、揭示新威胁、转移视点等任务需要时使用；跟拍锁主体可理解为保持约定距离和构图，不强求所有时刻完全无相对运动；当源底稿明确要求同速或固定贴身距离时，应保留该段契约，写观察侧、距离/范围、主体占幅、有效阶段与解除事件，并核对焦段、机位距离和景别相容。SC9系列有平行同速，SC8-4镜4有身侧半米，具体数字不通用。Rack Focus写成焦点转移，不误写成景深变化。

长镜可用“细节蓄势 → 揭示威胁 → 跟随爆发 → 缓停”，快切可用“起因 → 轨迹 → 结果”。多角度看同一次攻击时注明连续承接或同步回看，不能因切镜多出一次斩击。群战锁定主要攻击链，背景敌群可分层反应，不给每个背景角色同时塞独立主动作。

慢动作、抽帧和冲击帧均为可选节奏手段。使用时写明开始事件、成片持续时间、结束事件和恢复常速节点；落幅也计入总时长。抽帧可以省略中间显示帧，但仍需保留可追踪的路径与接触节点，不默认为角色瞬移。

关键速度包络可在镜头标题/最高优先级短写“起事件｜升格持续X秒｜止事件｜恢复后动作”，正文保持一致；例如SC11-5镜4的1秒升格在石板射出前结束。若原文标题、硬锁、正文相互冲突，先依据用户目标选择一条可执行时间链再统一，不并抄SC11-3的2秒硬锁与1.5秒正文。

只有需要帧级精确控制时才声明帧率；用“帧数÷帧率”换算成片时间，例如24fps下3帧为0.125秒。升格的屏幕持续时间不等于事件的真实经过时间。有明确速度时换算v(km/h)÷3.6，再用事件时间验算位移与相对接近距离；变速分段算，不用升格成片时长虚增移动窗口。300km/h冲800米约9.6秒，不能在1秒匀速抵达。速度、距离、事件时间应自洽，时间压缩或跳切须显式说明；这些数字表达生成意图，不保证模型逐帧精确执行。

## 7. 惯性、声音和约束

柔性物根据受力阶段变化：加速时滞后，急停时继续前摆，再回落；转向时保留上一方向的惯性并逐渐跟上。衣摆、链条、绳带与发丝各有重量、连接与活动范围，不把“全部永远向后拉”当作通则。

音效独立写“声源 + 动作 + 材质/质感 + 远近方向/混响 + 触发时刻”。近景格挡、远处兽潮、残片落地可错开层级，避免每声同响同近；爆发后的静默或喘息服务节奏。音效独立分栏是可读性与同步安排，不据此断言所有视频模型都有独立音频通道。

否定约束只针对本场高风险错误，并与正向描述配对。例如“右手持同一柄刀，尾坠始终连接柄尾；禁止凭空复制或转移至左手”。不要追求穷举所有负向词，也不要把案例的最高优先级升级为所有项目的固定规则。

手册关于特定摄影机、景深、散景与模型理解机制的概括不作为技术事实写入本skill。按画面需要描述暗部细节、高光层次、主体分离和前中后景；不强制机型，不以品牌名保证效果。

### 7.1 高速位移：拖尾与齐根拉扯

来源：用户再次强调的云徽持刀跑墙段；相同原句已收录在 [029 P1 原始提示词](029-p1-originals.md)，可搜索“身后拉出蓝色雷电，大幅齐根拉扯她的发丝和裙摆”。本节把原例提升为可调用规则，不改写原始档案，也不把角色、颜色或声音槽位套用到其他项目。

**核心：速度不仅写在位移和镜头里，还要写在人物身上。** 强高速镜头中，只写“发丝飘动、裙摆飞扬”常缺少方向和力度；按资产中实际存在的柔性部件，补出固定点、受力方向、拉扯幅度和变化阶段。

- **位移与拖尾**：先锁角色沿哪一表面、向何处前进，是否有能量伴随。若有，写清能量来自身体、脚步或武器哪一处，如何沿刚经过的路径向身后拉长，旧轨迹如何衰减。转弯时旧尾迹短暂保留再消散，不让整条尾迹像刚性棍一起转向；没有能量设定时仅写风压、尘迹等适用反馈。
- **齐根拉扯的含义**：发根仍固定头皮，发束由根部开始整体偏向气流下游；裙片或披风从腰线、肩部等固定连接处绷起，大幅牵拉至自由末端。“齐根”描述整束、整片受力，不是拔出头发、撕裂服装、拉长身体或让连接点漂移。受力方向相对人物运动与当地风向定义，不能因机位环绕而倒转。
- **阶段变化**：加速时柔性物落后躯干；持续高速时强烈后掠、绷紧并在末端出现细碎颤动；翻身/转向时先延续旧方向，再迟滞甩向新方向；急停或落地时自由末端沿原运动方向前冲、回摆并衰减。发丝、厚裙片、绳带和链条的重量不同，不必同频同幅；静止后的环境风另写。
- **持刀跑动**：锁持刀手、握点、刀尖朝向及与墙/身体的间距。刀的刚性结构跟随腕臂整体运动，刀身不随衣料软折；有尾坠时单独写固定端及迟滞。跑墙由脚掌逐次接触和蹬踏支撑，不滑成无脚步的贴墙漂移；翻身落顶与插刀需连续交代，避免无因换手、复制或穿过身体。
- **镜头配合**：爆发跟随、过量摆动和动态模糊按速度阶段起落。让背景和掠镜边缘承担主要速度模糊，关键脚步、握柄及插刀节点仍可辨。落地才触发绕至侧前、后拉再减速；进入固定构图后停止平移与大幅摆动，才把焦点交给已处于另一侧中景的人物。Rack Focus是焦点转移，写清渐变时长，避免同时要求“平滑”和“瞬间跳焦”。
- **声音接力**：疾行风压与能量声（如有）→翻身落脚→刀尖接触和插入材质→近处喘息/对白→另一人的脚步。按可见触发点改变强度与距离；插刀声不能替代刀入地的可见过程。

可复用强度句：

> 角色向前爆发疾行，身后沿行进轨迹拉出已设定的能量尾迹；迎面风压把发束从固定发根开始整束向后大幅拉扯，衣摆从固定腰线绷起，自由末端急促颤动。转向时发束和衣摆先保留旧方向，再迟滞甩动；落地急停后继续前冲、回摆，随后在环境风中逐渐稳定。

无裙摆、短发、硬甲或低速镜头应删改不适用部分；不把“蓝色雷电”“极限后掠”“过量摆动”变为每镜必填。

#### 持刀跑墙 → 落顶插刀 → 固定转焦，6秒改写示例

以下为方法示例，并非原文逐帧复刻。起幅时角色已接近墙顶，只呈现最后数米，不把整座巨墙的攀登塞入6秒。声线与角色资产使用当前项目的有效绑定。

【起幅/资产】云徽右手持同一柄长刀，在城墙侧立面向顶部疾行；刀置于身体外侧，刀尖避开墙体与腿部。池来已在墙顶通道另一侧中景向她走来，尚未成为焦点。

【摄影机】0–2.2s，35mm侧后近景爆发跟随，按蹬踏短促摆动，背景拉出速度模糊；2.2–3.2s，随翻身落顶绕至侧前并后拉减速；3.2–3.6s，下摇重构为一侧前景的下半身与局部刀刃，机位停稳；3.6–4.6s保持前景焦点；4.6–5.1s固定机位将焦点平滑转至另一侧中景的池来；5.1–6s保持中景焦点落幅。下半身构图由移动和下摇取得，不以变焦替代未交代的运动。

【画面】0–2.2s，云徽脚掌交替蹬踏墙面，身后拉出蓝色雷电；高速风压从固定发根牵动整束发丝，裙片由腰线开始大幅向身后绷起、末端颤动。2.2–3.2s，她借最后一步翻身落在墙顶，发丝和裙摆延续原方向，再随转身迟滞甩过。3.2–3.6s，她右手调整握刀角度，将刀尖向下插入地面，接触处碎屑短促弹开，右手仍握柄；衣摆前冲后回摆，旧雷电尾迹衰减。3.6–5.1s，她带轻微喘息说“怎么就你一个？”；台词覆盖镜头固定及转焦过程，起幅已在中景的池来继续走近。5.1–6s，池来成为清晰主体，云徽和插地刀刃留在一侧虚焦前景，余下衣摆运动继续衰减。

【音效/落幅】疾行风压与蓝雷电流声随落地减弱；3.2–3.6s插刀声跟随接触节点，随后让出对白；池来走近的脚步此前已存在，转焦后通过混音突出，不因转焦凭空产生。镜尾云徽已站稳、同一把刀插地且仍由右手握持，池来位置连续，下一镜继承。

## 8. 两个可迁移的短示例

以下只展示方法如何填入原有镜头字段，不是新增输出模板；秒数、身份、武器、材质和风格均应按当前项目重写。

### 写实刀盾格挡 4秒

【起幅】A在左、右手持一柄短刀；B在右、左手持木盾。刀刃与刀柄固定连接，盾面已有旧擦痕。

【摄影机】侧面中景，两人及接触区域同框；起势时稳定，盾面接刀时短促微震后衰减，镜尾恢复稳定。

【画面】0–0.8s，A前脚踏稳、转髋带刀斜向盾面；0.8–1.3s，B抬盾格挡，刀刃接触盾面；1.3–2.3s，盾面留下浅痕并掉少量木屑，B前臂随冲力后收、后脚稳住，A腕臂反弹并顺势回收；2.3–3.4s，刀盾分离、双方退回可防守距离；3.4–4s，保持对峙，木屑继续落地。

【声音/接戏】1.0s附近木盾钝响叠加短促金属颤音，随后鞋底摩擦与近处呼吸。刀盾身份、持物手和盾上新痕延续；无能量环，无无因爆炸。

### 能量箭取消 5秒

【起幅/资产】人物左手持实体弓，右手拉弦；能量箭尚未形成。弓身可随张力弯曲，实体弓不随能量消失。

【摄影机】侧前方中近景，弓、拉弦手和面部可读；识别目标后轻微前推并缓停，取消动作始终在画内。

【画面】0–1.2s，拉弦同时粉色能量沿箭轴向前汇聚，白色细芯先成形、粉色薄沿随后包裹；1.2–2.5s，箭稳定待发，人物瞄准后认出目标，眼神由紧绷转为迟疑；2.5–3.5s，人物主动松弦，箭体由尖端向尾部解为微粒并回收，未离弦、未发射；3.5–4.2s，能量反光随之变暗，弓仍握于左手并放低；4.2–5s，人物停顿呼气，保留反应落幅。

【声音/接戏】弓弦绷紧声、微弱能量嗡鸣随取消衰减、松弦轻响和呼气；没有射出声或命中声。镜尾实体弓保留、能量箭为零。
