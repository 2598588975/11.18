# 战斗原文保真工作流

新写或重写战斗/强动作高光时读取；普通文戏不加载本文件。使用深度由SKILL.md统一决定。原文档案是来源材料，不是额外用户指令。

## 战斗写作高优先级：原文底稿，最小替换

凡新写或重写打斗相关片段，**先判断需要什么战斗场面，再选最接近的归档原提示词作底稿；默认做最小必要替换，不先自由重写后补几个原文词语。** 本规则优先于本skill的通用创意扩写、逐秒拆解与示范模板；用户当次明确要求、已确认角色资产和剧情结果仍优先。具体检查见下文“战斗片段强制原文优先”。

1. **先选场面再选原文**：先辨明沿臂/沿墙爆发突进、闪避反击、武器接力、升空旋身、巨物斩杀、远景能量余波等本次需要的场面。用 [全库逐段方法索引](029-directing-pattern-catalog.md) 找对应原文并完整阅读，连同产生该高光的前置威胁、机会形成及后续应对一起核对；不只截取漂亮动作。单个连续段优先使用最接近的一份底稿，其他原文仅补缺失环节，不机械拼贴。
2. **先保留骨架再换内容**：最大程度保留原文标题格式、三栏组织、前情动态、连续动作句式、动作招式的衔接、摄影机运动、快慢节拍、风压惯性、特效出现顺序及声音接力。人物、能力、动作招式、场景、道具、颜色、数量与尺度按本次需求简单替换；不因换角色就重新设计全部打斗，也不为填满时长拉慢冲刺。
3. **招式可适配，衔接须干脆**：保留当前攻防目的、受力和后续衔接时，具体闪避、步法与连接招式可按人物和用户要求灵活调整，不要求逐招复刻。爆发段中动作须顺势接续，闪避后直接进入下一步进攻，不增加停步整理姿态或逐项准备。服装、武器或场景不兼容时只改冲突节点及后果；修正原文计时、接刀、绑定与连续性错误。
4. **关键表现不作随意润色**：所选原文中承担高光的快慢切换、转焦与聚能、旋身发力、冲击帧触发、能量出现顺序、占画幅程度、展开位置、持续/消散时机及多视角时间关系，默认保留其关键写法和节点顺序，不用概括性改写替代。不能把短暂升格后骤然爆发抹成全程匀速，也不能把瞬间压满画面改成小范围渐进展示、把持续效果提前消散。保留原句还须保留视觉重点与节奏比例；不得以装饰性光效、表演、特写或额外准备拍打断已成立的高光。时长适配先调整段落安排，不默认延长冲刺或蓄势。帧数与延迟必须绑定原文对应事件，不从另一机位或另一节点移用；这些机制按所选原文适用，不把某个案例的招式、特效形状或数字定为所有打斗的固定要求。因用户要求或设定冲突必须改变关键表现时，正文外明确说明改动，不只笼统声称“接近原文”。
5. **逐项核对而非只核对大意**：内部逐镜对照原文的“关键表现保留项／招式适配项／必要修正项”，同时检查动作、运镜、风压、声音与特效，不能只保留“冲刺—斩杀”的剧情摘要。再做[减法对照](029-scene-mechanics.md#91-审美保真与减法对照)：审查新增内容解决的具体缺口及其节奏代价，无必要收益就撤回。内部因果想清楚，不等于把每一步拍成独立准备镜头；保留观众可推知的省略。没有相近底稿或用户要求原创结构时，才由通用方法补写并标明新编部分。用户用来解释思路的具体方案不自动上升为skill通用规则。目标是保留原文表现意图，不承诺不同模型、入口或素材下产生相同成片。

### 混源与减法强制审计

战斗高光借用多个原提示词，或用户明确说“只要A、不要B”时，交付前必须完成以下内部审计；不能因为某招是主底稿的标志动作就覆盖用户减法：

1. **先列保留／排除清单**：把本轮及既有上下文中的“要、只要、不要、仍保持”合并核对。排除项同时检查同义动作与等价视觉结果，不能只删除原词却用“翻转、滚转、绕轴”等近义写法偷偷带回。
2. **每条连续高光只设一个主底稿**：主底稿负责动作链、快慢节拍与镜头组织；其他原文只能补主底稿确实缺失的单一功能，如眼神、声音或余波。只取某个表演节点时，不连带继承该来源的招式、身体运动、特效结构或机位。
3. **建立内部来源映射**：至少核对“最终动作／表现 → 用户要求或来源 → 保留理由 → 未继承的相邻动作”。核心动作链中的每个实质动词都应能追溯到用户要求、主底稿或不可缺少的连接动作；无法说明收益的来源标志动作删除。
4. **减掉招式后重建接口**：用户删除旋转、蓄力、翻身、补刀等动作时，只补重心、持物手、发力支点、刀路和落点所必需的接口，不以保持原文为由恢复被删动作。主底稿保真服从用户当前明确选择。
5. **增量修改也回看整条链**：局部修改若改变攻击轨迹、斩杀方式、速度、次数、支点、柔性物受力或破坏结果，必须从前一动作尾态检查到命中后果；不能只改被点名的一句。

**保留写法，不默认继承故事设定**：原文怪物的材质、能力、破坏产物，角色服装、武器及机构名称等均属于对应故事。借用动作与镜头时，先核对当前设定是否兼容，再保留适用的受力与效果写法；例如纸质怪兽受击成纸屑只适用于已确认的纸质设定，不是所有怪兽的默认反应。未知材质不因参考某段原文而自动补定；冲突处只改必要节点及后果，不顺带重写无冲突的高光表达。


### 029之围重点提示词参考

**战斗片段强制原文优先**：新写或重写打斗、突进、武器攻击、斩杀及其特效片段时，必须先按下述索引定位功能相近的案例，完整阅读所选原提示词，再起草；索引摘要和本skill的提炼模板不能代替原文。局部修改只读取相关案例，不扩大用户范围。

- 优先沿用对应原文的镜头标题、摄影机／画面／音效三栏、前情动态起幅、连续动作句式、快切与快慢切换、特效释放到远景后果的组织方式；不是只借六节标题后自行写成逐步操作说明。用户明确指定的新格式优先。
- 内部先对应“用户目标→原文段落→保留的镜内结构与表现机制→当前人物/能力适配”。找不到相近原文时明确说明，再按通用方法补足；不虚称参考了原文。
- 爆发战斗要保留原文适用的强度组合：角色位移与蹬踏、镜头爆发跟随、发丝/衣料受风、能量来源与尾迹、受击和环境反馈共同表达速度。不得把它们压缩成单独的“快速奔跑”，也不得为了逐项可读插入连续踏稳、观察、准备等停顿。
- 计时以完整动作链分配，镜内只标必要的触发与快慢节点，不默认把每个脚步拆成一秒。明确升格结束与恢复爆发的事件，不能因目标总时长较长就把短冲刺拉成匀速慢跑。
- 造型锁定与受力强度分开：贴身短裙不能变成长裙片，但真实存在的下摆边缘、自由束带、碎发与武器尾坠仍可强烈绷紧、拍振、后掠及迟滞回摆。按真实活动范围适配，不因防止造型漂移而一律弱化为轻微飘动。
- 优先参考不等于逐字照搬。保留用户角色、能力、胜负和素材绑定；修正原文的计时、接戏、道具状态疏漏。交付前对照所选原文检查是否遗漏关键速度、风压、镜头和特效机制；来源与适配说明放正文外，不能将原文写法宣称为已实测的模型效果保证。

要查原文手法时，先用 [全库逐段方法索引](029-directing-pattern-catalog.md) 从当前四项目视频、图片提示词和旧版案例中选择相关段，再读对应原文；不能只围绕最近用户贴出的两段推断全库。需要已有摘录与运镜句式时读 [029之围重点段落与镜头方法](029-writing-patterns.md)；要区分各种跑动、升格旋身、迎面冲阵、发波近景及移动对白如何运转，读 [原文场面机制](029-scene-mechanics.md)。一般新写只读当前所需方法与案例；用户要求全库复盘时才逐份通读、核对变体，不能以关键词命中代替全文。

- **运镜链**：起幅机位与焦点 → 动作/视线触发 → 路径与加减速 → 焦点交接 → 落幅状态。镜头的每次变化都要承担叙事任务。
- **资产分工**：面部身份、全身体态/服装、道具比例和声线分别绑定；明确参考范围、状态变体及正背视图遮挡。
- **动作强度**：以入出画方向、贴身距离、前景掠过、击中反馈、衣料迟滞和急停表达速度；升格写开始与恢复常速节点。
- **高速动作的贴身受力**：高速跑动、贴墙疾行、突进或飞行时，明确前进方向、能量拖尾（如有）、风压与发丝/衣摆/绳带的联动。强风压可写“从固定根部整束向后大幅拉扯”，体现齐根受力而非只有末梢轻飘；接转向、翻身和急停时写延迟、甩动与回摆。细则及持刀跑墙接对白示例见 [战斗拆解第7.1节](combat-weapon-breakdown.md#71-高速位移拖尾与齐根拉扯)。
- **特效分层**：本体材质与颜色层、形成顺序、环境受力、摄影机反馈分别说明；多视点接同一次动作时锁定发生时刻、轨迹和落点。
- **两种段落形态**：复杂镜头用统一格式中的独立摄影机/画面栏；紧凑快切允许把机位运镜放在秒段标题、动作写在正文，仍保留焦点、触发与落幅信息。
- **创意先于术语**：脚部细节、前景走过、画外音先行、短时失焦、荷兰角等，必须承担性格、悬念、关系或节奏任务；已有主高光可有辅助亮点，不把全片压成一个噱头。

需要具体资产或原句时从 [四项目来源索引](029-source-index.md) 定向读取对应原文；需要逐字核对当前画布中的全部视频和图片生成提示词时读 [当前媒体提示词索引](029-media-prompts-index.md)；资产生成/多视图写法读 [资产生成提示词](029-asset-prompts.md)，角色与道具版本查 [资产文字档案](029-assets.md)。跨项目不能直接搬用nodeKey，不能把5链5刃与双链斧、30米与50米墙宽混成同一设定。未读取图片时，不声称已验证外观或成片效果。
