# 视频提示词五项视觉前缀

本规范来自用户于2026-11-11提供的提示词范例。用户强调：重点是光影，所给整套审美适用于真人古装，具体情况具体设计。五项是工作台的组织方式，不是一套通用画风；即使同为真人古装，闺阁日戏、夜间烛光、室外阴天和肃杀场面也须分别设计光色。适用于新写或明确要求更新的完整视频提示词；不是新增创作阶段，也不触发额外菜单。只讨论、只改台词/局部镜头、提取原文或原样提交已确认提示词时，尊重原任务范围，不自动扩写。

## 放置与优先级

- 每个可独立复制生成的段落，先写【全局视觉风格】【画面规格】【光影色彩】【镜头与物理】【一致性与执行】，再写该段素材职责、时间轴和原有声音等模块。五项内容在每段各写一次，不能用“同上”或“见全片设定”省略。
- 用户另有明确格式时保留外层骨架，在开头总控/成片要求中容纳这五项；已有同义内容合并到主位置，不叠两套风格锁。逐镜只补具体景别、动作、光线变化和例外。最终正文写实值，不留模板占位符。
- 用户当前要求及当前分段的时间轴、镜头、人物动作、道具、准确台词和特效，高于通用前缀；已确认项目风格、参数、资产及世界规则高于技能范例。发现两个已锁事实互相冲突时指出冲突，不静默改稿。
- 新稿可在授权创作范围内补摄影与光色设计，复用项目已有值；仅影响拍法的方案不冒充用户已确认值。已确认最终提示词进入执行阶段后逐字透传，不能临提交时自动加前缀。
- 示例只提供写法。9:16、50—85mm、28—35mm、浅景深、1%—4%推近、汉服、桃粉配色和右后方暖日光均不是跨题材默认值。未指定的动物、道具、人物、光效和情节不能为了填字段而新增。

## 五项要写到什么程度

1. **全局视觉风格**：题材与时代处理、媒介/画风、精修程度、人物形态与皮肤表达、本段可见材质。真人保留面部结构、皮肤和织物细节；动画按已定画风描述线条、色块、渲染与材质，不强加毛孔或真人比例。
2. **画面规格**：项目画幅、适用焦段/景别、景深和焦点对象；具体构图、人物位置与焦点交接服从本段镜头。焦段与景别、机位距离相互匹配。工具另设画幅时与正文一致，不把文字描述当作参数已设置的证据。
3. **光影色彩**：必须写成可执行的一段，至少交代主光来源与固定空间方位、相对人物方向、色温倾向、软硬及柔化方式、补光/轮廓光的取舍、主辅色与点缀色、对比度、高光/阴影处理及主体曝光。不用“高级、电影感、氛围光”或相机品牌代替这些内容；不必虚构开尔文数、灯具型号或精确光比。
4. **镜头与物理**：按戏确定固定、剪切、推拉、跟随、手持等运动方式、速度和边界；衣物、发丝、饰品、毛发及环境动态遵守已定重力、惯性、接触和延迟。战斗、高速追逐及已确认超自然设定按当前镜头执行，不能被文戏的慢推或静态范例禁掉。
5. **一致性与执行**：锁定同一人物的脸型、年龄、发型、服装、首饰和身高比例，以及同场布局、固定地标、家具、光源位置与调色。当前分段才出现的人物、动物、道具、特效按出现时间限定；未明确出现的不生成。回忆柔焦、叠化、花瓣等只在对应分段明确要求时启用。

## 光影连续性重点

- 先锁世界光源，再写当前机位看到的受光面。例如日光来自临窗坐榻后方的窗户，开场位于人物右后侧；反打、人物转身后，画面左右和受光面按真实几何关系变化，不能把“画面右后方”固定成随摄影机移动的灯。
- 同场同一时段继承主光、调色和曝光逻辑；换场、昼夜变化、关灯或特效发光导致的改变，注明触发点与结束状态。特效只能在要求的时间出现，且其照明反馈服从既定效果。
- “面部始终明亮”适用于本次柔光古风范例；夜戏、剪影或悬疑段按项目设计保留必要暗面及主体可读性。补光可以弱或无，不为补齐字段硬添轮廓灯。

## 可填模板

```text
【全局视觉风格】
<题材/媒介、时代处理、精修程度、人物表现及本段材质>。

【画面规格】
<已定画幅、适用焦段/景别、景深及焦点规则>。具体景别、构图、人物位置和焦点交接严格服从当前分镜。

【光影色彩】
<主光来源及固定空间方位>，在当前机位从<人物相对方向>照入，呈<色温倾向>；经<柔化方式/直接硬光>形成<软硬与阴影边缘>。<补光和轮廓光取舍>。整体以<主色、辅助色、点缀色>组织，<对比度>，高光<处理>，阴影<处理>，主体<曝光与可读性>；同场后续镜头沿用该世界光源与调色，指定变化按时间轴执行。

【镜头与物理】
<本段运动方式、幅度/速度及边界>。<可见服饰、毛发、饰品和环境物>遵守<本项目重力、惯性、接触及延迟规则>。

【一致性与执行】
<本段身份、造型、比例、空间、光源与调色锚点>保持一致。当前分段的时间轴、镜头、人物动作、道具、准确台词和特效优先；未明确出现的人物、动物、道具与特效不得生成，特殊效果仅在指定分段和时刻启用。
```

## 用户古风闺阁范例（限定题材使用）

以下仅整理前五条，清除原稿“人物眼镜、动作 具体景别”的残留文字，不继承其人物、Mixed编号或剧情。

```text
【全局视觉风格】
非严格朝代复原的古风汉服竖屏短剧，写实电影摄影结合克制的精修质感。人物五官精致，比例略带东方二次元审美，同时保留真实脸型、皮肤毛孔和面部结构，禁止蜡像感与过度磨皮。本段出现的汉服纱料、刺绣丝绸、珍珠首饰、纸张、木材和动物毛发保持真实材质；材质列举不代表允许新增物件或动物。

【画面规格】
9:16竖屏，以50—85mm人像焦段、中景、中近景和特写为主；环境全景使用28—35mm。浅景深，焦点落在当前分段指定的人物眼睛、手部或核心道具上。具体景别、构图和人物位置严格服从当前分镜。

【光影色彩】
暖白日光从临窗坐榻后方的窗户照入，开场机位下来自人物右后方，经竹帘和半透明纱帘柔化；人物正面使用低强度柔光补亮，发丝和肩部形成浅金色轮廓光。整体为象牙白、浅桃粉、灰绿色、淡金色与深棕木色，中低对比，高光轻微柔化，阴影保留细节，人物面部始终明亮并保留立体结构。反打与人物转身时按同一窗户的固定位置换算受光方向，保持同场光源与调色连续。

【镜头与物理】
镜头以固定机位、剪辑切换和1%—4%的缓慢推近为主，禁止明显手持晃动、快速甩镜和无指令环绕；具体运动服从当前分镜。衣袖、裙摆、纱帘、发丝、耳坠和流苏遵守真实重力、惯性与延迟摆动。

【一致性与执行】
所有分段保持同一人物脸型、年龄、发型、服装、首饰和身高比例；保持同一闺阁布局、窗户方向、家具位置、光源位置和调色。当前分段的时间轴、镜头、人物动作、道具、台词和特效优先级最高。本段未明确出现的人物、动物、道具和特效不得生成；只有对应分段明确要求时，才使用回忆柔焦、叠化、花瓣或其他特殊效果。
```

## 交付前核对

- 每段五项完整、具体且可独立复制；没有同义设定互相冲突，也没有跨段“同上”。
- 光影色彩包含可执行光源、方向、软硬、补光取舍、色彩和明暗表现；反打未导致世界光源跳位。
- 五项未覆盖具体镜头、项目锁定值或已确认画风；日景、夜戏、动画、战斗各按自身场景填写。
- 本段资产和特效均有明确出场依据；未把示例人物、道具、窗帘、花瓣或动物带入其他项目。
- 文本检查不等于生成验证，不凭规则更新宣称画面质量已提高或成片已通过。
