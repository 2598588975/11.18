# 异种纪元：调用与原文保真格式

## 1. 何时进入

用户在创作或提示词语境中说“异种纪元”即可调用本技能，不必加“乱霞号”、编号或完整技能名。“异种纪元风格”“按异种纪元写”“用异种纪元镜头”同样识别，按用户指定的借鉴范围执行；作品事实问答或纯粹提及名称不自动转成创作任务。

| 用户要求 | 执行方式 |
|---|---|
| “异种纪元，写这段剧情”／“按异种纪元原格式” | 从原库选最贴近的案例，完整读原文，以其格式与写法为主适配 |
| “乱霞号格式，借异种纪元画风/镜头” | 保留A/B或当前指定骨架，完整读实际借用的源案例，尽量保留对应镜内表达 |
| “只用异种纪元的焦点交接” | 只应用该方法及相关原文片段的有效写法，不自动更换整段画风、故事或格式 |
| 只说“异种纪元”，无剧情也无当前待处理稿 | 简短确认进入该模式，询问要处理的内容；不虚构成稿任务 |

用户已定的格式、资产、故事、时长、画幅及摄影体系优先。一个段落只有一套主格式；不把源格式与A/B全文叠在一起。未指定异种纪元的任务继续原乱霞号默认。

## 2. 保存了什么、用时怎样读

[完整源提示词档案](yizhong-ep4-original-prompts.md)保存2026-10-13读取的全部75个视频节点映射、31份不同的非空完整正文和2个空节点记录。73个有正文节点中的逐字相同副本合并存正文，细小差异也单独保留，不以归纳摘要替代。源文的顺序、标题、镜头字段、台词、时间和句子保留原貌；网页中显示为“图片 N”的引用保留显示文本，不冒充平台底层绑定导出。

执行顺序：

1. 用场景任务、信息揭示、表演关系、镜头路径或风格查索引/全文，选最贴近的一份主参考。不要仅因都出现“巨物”就忽略场景目的和运动关系。
2. **完整阅读所选源提示词**，包括场景美术、风格锚点、核心元素（若有）、每镜的画面、对白与声音；不是只读搜索摘录。借多个案例时，各自读完整原文，明确谁负责什么。
3. 先确认哪些字段、关键句式、运镜触发、快慢节拍、焦点/声画交接直接沿用，再替换当前角色、道具、地点、能力和有效素材绑定。尽量小改，不先自由重写再撒回几个原文术语。
4. 保留原稿有效的镜头密度和表演细节。无法直接适配时，只改不兼容的节点及必要接口；当前源库没有对应部分时可新编，并在正文外注明，不伪称原文。
5. 只处理明显影响当前成稿使用的问题，例如总时长不合目标、资产引用无对应素材。用户已认可原片，不凭措辞、术语习惯或个人偏好扩大挑错、润色与重构。

完整读取示例（路径按实际安装位置替换）：

```text
python <skill目录>/scripts/read_case.py --source YZ --search 巨物 俯拍
python <skill目录>/scripts/read_case.py --source YZ --case YZ30
python <skill目录>/scripts/read_case.py --source YZ --case v-AzkcAVEWkr
```

脚本保留正文，不修正、不摘要输出；搜索只用于定位。也可直接定位档案中的 `## YZxx｜` 并读完该节。具体画风/镜头选项见 [可选规则](yizhong-visual-camera-options.md)，菜单用于选择，不能代替实际采用案例的完整阅读。

## 3. 优先保留的原文格式

以所选原稿的真实结构为准，不要求31份原文全部统一。常见完整结构如下；这是写作位置示意，成稿填入本次内容：

```text
场景美术锁定 【场景名】
位置：具体地点
空间：人物位置、路线、层级与尺度
材质：本场实际出现的表面和物件
灯光：时段、主光方向及变化条件
背景：地标、景层及背景活动
重力 / 物理：本场物理与已设定异常规则
基调 / 限制：本场影像、声音及必要限制

【一、风格锚点】
贴近所选源文的画风、摄影、光照、材质与情绪写法。

【二、核心元素】
本段角色、道具、场景的已知设定及有效绑定。

【三、画面内容】
镜头 SX-01｜0 — X 秒｜X 秒｜本镜具体事件
相机 / 焦段：机位、焦段、运镜及触发
构图：前中后景、尺度、虚实与视觉重点
画面 / 动作 / 表演：沿用所选原文的展开顺序、细节密度及动作/反应连接，替换为当前内容。
对白（如需要）：角色与准确台词；必要声线、状态、语气和声画位置。
音效（如需要）：与画面事件对应的声源、远近和变化。
```

一些原文直接在场景美术后列镜头，或将风格锚点放在后面；按该原文保留顺序。原文没有独立“核心元素”或空对白栏时不为统一强补。原文已有的“相机／焦段”和“构图”尽量分开保留，避免压缩成概括性镜头一句话。新项目必要的资产绑定和声音资料放进最接近的字段，不借补字段重排全篇。

复用动作段时延续既有战斗原文保真规则；文戏也尽量贴合实际所选源文的视线、停顿、手部动作、对白和声音组织。只作普通自主文戏且未选择源案例时，不把全局所有文戏强制改成套稿。

只借画风或镜头、并明确保持乱霞号格式时，按 [统一格式1.4](unified-format.md#14-额外可选规则异种纪元画面与镜头包) 嵌入A/B。无论外层选哪种格式，源文关键表达优先于为了整齐而泛化、改写。

## 4. 交付前的小核对

- 实际采用的案例已完整读过，未用菜单或索引摘要替代。
- 外层顺序、逐镜字段和镜内有效写法与主参考尽量贴合；为当前项目作的必要替换没有稀释关键节拍。
- 源档仍保留原文，当前项目的素材编号、角色身份、故事结果和规格有效。
- 来源与新编说明留正文之外；没有把用户对原片的认可写成本次新稿已生成、已看片。
