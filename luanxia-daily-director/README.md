# 乱霞号导演提示词 Skill

独立的 Codex Skill，用于将剧情、桥段与参考资产整理为导演设定和可执行的秒级分镜。

## 能力

- 角色、武器、场景和声线资产锁定。
- 摄影机与画面内容分栏，明确起幅、动作触发、运镜、焦点交接与落幅。
- 武器结构、攻防因果、能量分层、破坏反馈和声音设计。
- 高速跑动、贴墙疾行与突进：能量拖尾、发丝和衣摆齐根受力、转向迟滞、急停回摆。
- 时长、空间轴线、持物手与跨镜连续性检查。
- 收录《029之围》文字案例与写法提炼。
- 收录《熵乱归序》四个当前项目（029之围 P1/P2/P3 与乱霞号日常 P4）的完整视频与图片资产提示词快照。
- 支持直接说“异种纪元”调用：按场景完整读取源提示词，尽量贴合原文格式、画面风格、逐镜字段和声画节拍。
- 收录《异种纪元》第四集75个视频节点映射与31份不同的完整提示词；逐字相同副本共用正文，差异版本分别保留，2个空节点单独记录。
- 异种纪元提供5类画风、12种镜头用法及质感/场景美术选项；未点名时不自动套用。

## 安装与调用

将本仓库下载或克隆到 Codex 的 skills 目录，并将目录命名为 `luanxia-daily-director`。`SKILL.md` 应位于该目录根部，`references` 与 `agents` 保持原有相对路径。

在对话中使用：

> 用乱霞号 skill，将这段剧情写成 30 秒分镜。明确资产绑定、摄影机、画面、音效，以及高速动作中发丝和衣摆的受力。

也可以直接说：

> 异种纪元，把这段剧情写成视频提示词。先读最接近的完整原文，尽量保持原文格式和镜头写法。

> 乱霞号格式，选异种纪元的暖光生活、前后景反差和焦点交接。

第一种默认贴合源格式；第二种保留乱霞号A/B。需要直接检索完整原文时：

```text
python scripts/read_case.py --source YZ --search 转焦 阴影
python scripts/read_case.py --source YZ --case YZ30
```
