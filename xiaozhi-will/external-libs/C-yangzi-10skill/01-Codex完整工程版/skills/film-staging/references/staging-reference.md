# 正面走位图：制作、使用与修订

## 三层隔离

1. 图像层：白底或很淡的细网格；人物是清楚可读的低饱和度细轮廓，单人单色，不填色块、不做阴影纹理。图上不画字母、姓名、图例、编号。减轻风格分量，但不把线条淡到不可读。
2. 视频文字层：只说明位置、姿势、朝向来自位置材料，风格、脸、服装、光线、材质来自用户的角色和场景参考。视频提示词中不带入“扁平、矢量、网格、线稿、示意图”等画风词，连“不要线稿”这样的否定句也不写。画风词只留在本页的绘图提示词中。
3. 附件层：真实场景与人物参考在前，正面走位图在后；走位图不进入首帧角色。平台不能区分用途时，使用文字锚点与实际首帧，不假装附件机制有效。

## 绘图提示词模板

```text
使用【实际原始画面】仅作为构图依据：保持画幅、摄影机角度、裁切、人物数量、位置、姿势和尺度。
输出正面看到的简洁技术线描，白底，可用极淡细网格；人物仅用低饱和度细轮廓表示，轮廓清楚、内部留白，不绘制实色块、阴影、纹理、写实面容或文字标签。
【逐人：画面位置—轮廓颜色—可见身体范围—姿势—身体与头部朝向—视线—道具的形状及人体参照位置】。
【固定家具/建筑的轮廓及位置；没有的就不添加】。
保持原画面裁切，被边缘截断的身体在绘图中同样截断。只保留原图实际可见元素。
```

画幅在工具参数中设置并与原画面一致。图例另交文本：蓝色轮廓＝角色 ID、位置、朝向；橙色轮廓＝另一角色 ID。示例色不是固定角色分配，同项目一经确定就复用。

检查四个易错处：被裁切身体被补全；头部角度和视线混淆；道具高度从喉部滑到胸口；凭空新增人物/道具。道具同时用人体位置和相对方向锚定。

## 交给视频编译器的连接段

角色标签必须与实际平台附件对应，不制造“已上传”的假象；可用项目命名 `@staging_项目_场次_vNNN` 与 `@loc_项目_场景_场次_vNNN` 作为资产登记名，若平台只支持图片序号则建立实际映射，不把登记名当 API。

```text
【位置材料实际标签】仅定义【场景实际标签】中的人物位置、姿势和朝向。
画面风格、光线、色彩、脸、发型、服装、环境与道具材质均依据【场景/人物参考实际标签】。
图例（仅在此文本中）：A＝蓝色人物＝【角色实际标签】＝【位置、姿势、朝向】；B＝橙色人物＝【角色实际标签】＝【位置、姿势、朝向】。
这些颜色仅对应人物身份，服装和调色依据人物与场景资产。
【逐人写完整的物理位置与接触点】，在【具体动作触发时刻】之前维持该位置，之后沿【明确路线】到达【终点】。
```

按用户已选美术风格写风格约束；来源默认真人写实，不据此把用户动画项目改成真人。视频文本从已核对的文字空间说明编写，不靠再次猜读简图重建空间。

## 修订与版本

- 修改指令按轮廓颜色指认对象，如“蓝色人物移到沙发左端”，并保留文本图例。
- 每次从原始真实画面重新绘制，不能用上一版示意图反复转绘叠加误差。新机位需要该机位的原始画面或标明假设的文字规划，不能把旧机位图说成新机位原图。
- 哪张图变了，只升哪张资产的标签版本；重画走位图不自动改场景图版本。每镜仅用活动版本，登记依赖，旧版留档。
- 若需要路径，给每条路径独立颜色与文本绑定，写明 START/PATH/END/TRIGGER；相机箭头必须明确只代表机位路径。

质检分两次：图稿检查轮廓、裁切、姿势、道具高度、人数和构图；实际视频生成后再检查位置、服装串色、文字/线条/白底污染。只审图稿不能声称视频质检已通过。
