# 空间规划：世界坐标到当前机位

先用文字或用户所需图形建立平面布局，再按摄影机视点写走位说明。原模板提到 Claude/HTML，是一种呈现方式，不要求切换产品或生成网站。

规划要素：

- 固定地标、房间边界、入口出口、家具与不能穿过的障碍。
- 世界 X/Y 方向、比例尺或明确为估计的尺度；人物相对地标的位置与彼此距离。
- 身体朝向、头部朝向、视线目标分别记录。
- 相互作用轴线、摄影机位置及其所在一侧、看向方向。
- 移动的起点、路径、终点与触发节拍；检查路线是否被障碍阻断。
- 道具尺寸锚定为真实可见的参照关系，算术要成立，不能只说“巨大”“很小”。

只凭一张图不能推断被遮住的完整房间，缺区标未知或规划假设。俯视图仅供推理，不作为视频上传附件。

完成后为每人写一段当前机位可见的说明：画面位置、景深层、身体与头部朝向、姿势、看向谁、接触什么。换机位重新投影，不能简单把左右词互换。首尾状态分别写全；跨镜可以继承世界事实，最终提示词必须重新展开。

示例请求模板：

```text
为【场景】规划俯视布局，标出固定地标、人物世界位置、朝向、视线、人物距离、比例尺或估计尺度、互动轴线和摄影机一侧。
检查【动作路径】是否穿过家具/人物或造成没有过渡的越轴。
在布局下为每人写当前机位的独立走位说明，包含画面位置、朝向、视线、姿势和接触点。
已知事实：【实际输入】。未知处：【最小缺项或明确的规划假设】。
```
