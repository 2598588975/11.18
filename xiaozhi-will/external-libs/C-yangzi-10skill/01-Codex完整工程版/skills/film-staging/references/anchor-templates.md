# 人物位置锚点

从世界空间和当前机位推导，不凭模板填造百分比。坐标采用画面左上为原点：x 向右、y 向下，百分比同时配“左三分之一/中央”等视觉描述，注明锚点是人物中心或脚底等同一口径；缺少测量时标为估计。占画比例注明高度、宽度或面积，不能混用。

## 单人

```text
时刻/动作阶段：
人物身份与状态 ID：
世界位置（相对固定地标）：
画面位置与景深层：
身体朝向、头部朝向、视线目标：
姿势、重心和身体可见范围：
接触点（脚下支撑、左/右手接触物）：
表情与身体状态（以已定 ACTING 为准）：
本镜主要动作及触发时刻：
结束位置、姿势、道具和视线：
```

## 多人

每人分别填写上述锚点，再写：

```text
人物距离与前后层次：
双方视线关系：
互动轴线与摄影机一侧：
谁能在什么时刻沿什么路径穿过哪里：
画面留白在哪里、怎样随动作变化：
遮挡/接触关系及其变化：
```

摄影机和光线取自已确认镜头方案，不在位置模板内另设计一套。以动作可执行为目标，不能无依据把所有镜头限制为一个动作。

Seedance 2.0 可让稳定人物标签起动作句。2.5 的职责表/图例保留标签，动作正文写“阿岚——持折扇的女子——转向门口”，不要让 `@A` 单独承担表演主体；可见特征来自实际资产，不因轮廓颜色而改服装。模板不携带具体案例人物或故事。
