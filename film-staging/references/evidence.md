# 来源、证据与冲突处理

用户补充 `D:\洋子\走位.zip`，来源说明标注 OSideMedia/higgsfield-ai-prompt-skill 3.40.0。适配依据：

- `templates/seedance/staging-reference.md`：正面图三层隔离、颜色图例、原图重绘和标签版本。
- `top-down-map.md`：俯视只供推理；输出文字走位，不上传平面图。
- `multi-character-anchor.md`、`single-character-position.md`：身份、位置、景深、朝向、视线、接触、状态及多人关系。
- `worked-example-two-character.md`：字段参考；未把案例人名、霓虹黑色电影风格写成默认。
- `skills/shared/house-rulings.md`：P2-11/12/13/14、P3-3；`provenance.md`：来源标签边界。源包还含词库、旧模型规格与负面约束汇编，仅按本任务所需提炼，不批量加载或当作实时能力声明。

正面图原文同时记载实践者称“显著提升”和一次记录不完整的 A/B 结果：两轮各 12 单元，第二轮镜像平衡后朝向跟随 6/12；报告另有 0/18 风格串入，但 18 与 24 的样本口径不同且未解释，路径、模型、日期未记录。因此：保留实用的团队沟通与防串色结构，不宣称锁位成功率或保证零污染。这是源文件的报告，本适配没有复现实验。

新版规则覆盖旧资料的同项冲突：

| 旧说法/容易误用 | 本版处理 |
|---|---|
| 俯视图可以作为视频空间参考附件 | 仅规划，文字投影进视频提示词；另做当前机位正面图 |
| 标注六格板与正面位置图同类 | 前者供导演沟通，后者单镜无字、颜色轮廓、仅位置职责 |
| 走位图可以当首帧 | 禁止混淆用途；首帧用成片风格图 |
| 蓝色人物对应蓝衣服 | 颜色只绑定身份，服装由人物资产决定 |
| 对旧图继续改图 | 回原始真实画面重绘；修改哪个资产才升哪个版本 |
| 2.0 和 2.5 标签同样写动作 | 2.0 可标签起句；2.5 标签留职责表，动作正文用名字及可见特征 |
| 固定六格、固定三动作或机械时间块 | 原案例的局部写法，不升级为所有任务的硬规定 |

原文的未决问题（身份文字长度、颗粒、已烘焙镜头风格是否再写入视频提示词等）不在本次更新中擅自裁定。实际用户设定和当前任务条件优先。
