# 密集动作与多景别剪辑

## 适用与目标

用户说拖拉、戏少、连招不够、要更多切镜，启用密集模式；同一项目后续改写延续已确认的密度偏好，不要求用户每次重复。单镜、慢速展示、重量特写等明确要求优先。密度、身体受击、角色材质和环境反馈应同时保留。不能为修受击而把整片变成一拳慢放，也不能为密集删掉接触证据。

先遵守主入口的单次最长30秒、一次完整交付规则；本文件的15秒骨架只是短片参考，不是拆段上限。30秒纯对打可起排约18—24个事件、14—18镜，含起身、召剑与觉醒的段落给必要转折留时，不把预算当硬指标。先分配动作与镜头时间，再填写细节。下列数量是15秒快节奏样片的创作起点，不是参考视频实测数据、模型上限或生成保证：

- 约10—14个有效攻防事件，组织成4—5组相连动作链；拳、肘、膝、腿、兵器、抓控按人物打法取舍，不强制全用。
- 约8—10个镜头，常用1—2秒一个镜段；全景/大全景至少2处，中景承担连续攻防，近景或接触特写提供2处左右的重音。每种景别承担不同信息，不平均轮播。
- 至少两次明确攻守转换和两次身体高度或距离变化，例如贴地→起身贴打→被逼退→反抢近→腾空/摔落。不得只把同一胸口直拳换名字凑数量。
- 常速爆发为主体。总慢放/冻结占时以约1秒以内作为初始预算，选1—2处短标点；只写“短暂”仍容易被拉长，补“接触一瞬后立刻常速接下一招”，不要给单拳独占3秒段。
- 开场边入场边交锋，不留完整站桩建立镜头；结尾只用约1秒交代结果或新威胁。余波与追击、收势、反应同框发生，避免专门等粒子落完。

不强制卡满数字。动作确实不可执行时先缩短蓄势、完整复位、慢放和重复描写，再简化难招；调整后仍应兑现用户的密集诉求。保持时间轴整数秒，短暂停顿嵌在镜段内，不将全部镜段标成小数秒。

## 什么算有效动作

一次攻击及对应的格挡/闪避/受击结果合计为一个事件，不拆成两个虚增数量。连续三拳有各自落点和结果可算三个；同一拳的蓄力、命中、慢放回看、飞尘不算四个。补步和布料飘动是反馈，只有改变攻防或位置条件才形成新事件。

优先短链串联：拨开前手→直拳打肋迫使收肘→摆拳攻头；对方回柄逼退→下潜避刃→近身肘膝反击。下一招利用前一招留下的姿态或破绽。身体尚在失衡时即可追击，不能每招等双方站正再开打；也不能让已倒地者无过程出现在空中。

轻快击用“招式＋落点＋一个有方向的反应”一句完成。较重一击再补重心、材质和重音。把同时发生的反馈写成同时发生，不将胸、肩、头、脚、衣服、尘逐条排成六个先后耗时动作。

## 真正切镜，保留动作连续

每镜至少明确时间、景别、机位、攻防与切点；焦段按需，不让一串规格挤掉动作。除第一镜外，以“切”“硬切”“接动作切到”等清晰语言写转换。推近、拉远、平移是镜内运动，不能冒充多镜剪辑。

| 景别 | 职责 | 可用切点 |
|---|---|---|
| 全景/大全景 | 躲刃、贴地移动、腾空、摔落、拉开距离，建立双方位置 | 武器掠过、身体转向、起跳或落地 |
| 中景/中近景 | 同框读出两三次连续攻防，兼顾发力与反应 | 格挡被打开、反击启动、对手失衡 |
| 近景/特写 | 拳肘接触、握柄被撬开、膝击压缩、受击表情等关键细节 | 接触前切入，接触后立刻切到位移或下一击 |

特写保持动作速度，不自动慢放；包含必要的接触双方或可辨身体局部。以运动方向、人物朝向、武器位置、背景锚点保持主轴。允许全景直接切特写、特写直接切全景，无需慢慢推过中景。镜头不能把同一次攻击重新演一遍，也不能切掉所有命中，只留下发力和倒地。

快切不等于持续震镜、甩镜、模糊和随机角度。保留1—2个稍长的双人中景承载完整连招，短特写作标点。声音尾声可跨切，下一攻击起音可接上前一击尾声；无需每次切镜重新铺风声。

## 15秒编排骨架

这是内部时间与景别样例，不是固定招式，也不必额外交付第二份分镜表。最终只给一份融合提示词。

| 时间 | 景别 | 推进任务 |
|---|---|---|
| 0—1秒 | 低位全景 | 边侧滑/翻滚边避开第一击，直接入战 |
| 1—3秒 | 双人中近景 | 贴近连续三击，落点与防守不同 |
| 3—4秒 | 接触特写 | 接住刚才动作的结果，顺势肘击或破防，不重放前一拳 |
| 4—6秒 | 斜侧中景 | 对手反击两次，主角受压后闪避，攻守转换 |
| 6—7秒 | 近景 | 抓控/拨柄与短打，同时交代局部受击 |
| 7—9秒 | 全景 | 扫腿、腾挪或踢击改变高度与距离；结果随动作完成 |
| 9—11秒 | 双人中景 | 追上失衡对手再打一组短连招，对手仍有抵抗 |
| 11—12秒 | 命中特写 | 本片主要重音，接触极短顿挫后立即恢复常速 |
| 12—14秒 | 全景 | 接力向展示摔落或击退，同时推进追击/反制 |
| 14—15秒 | 近景或中景 | 一次有意义的结果或威胁变化，动作中结束 |

该样例10镜，不意味着每镜只打一招。1—3秒和9—11秒等段落可承载数次短促对招；受击和衣料余波跟随连招延续。

## 对比视频与定位拖慢

先按相同时间窗口比较，例如两片前15秒，不用26秒片总招数直接证明15秒片密度低。分开记录：有效攻防事件、明确切镜、景别变化、滞空/停顿、静止收尾、角色高度/距离变化。剪切检测只提示候选切点，须结合连续画面确认；不将甩镜、闪白或一次剪切的过渡帧计成多镜。

连续抽帧可以显示某一时间段姿态几乎不变；不能只凭单帧认定精确速度、真实慢放倍率或声音。保留参考片自身的长滞空/缓慢尾声等反例，不把它说成全程快切，也不机械复制它较长片长的占时。

常见修复：
- 3秒只打一拳：改为两次短攻防铺垫＋一次重点命中；将详细受力压成同一动作中的反馈。
- 上勾命中后悬停2秒：保留瞬间短顿，马上接击退/追击或切下一招。
- 最后2—3秒站着看尘：将落地余波与追击或对手撑起反制重叠，结果镜压短。
- 全程中景跟拍：明确插入全景的空间动作与接触特写，使用动作接切，保留主轴。
- 动作多但像乱跳：减少无过渡的空翻或长距离招式，保留密集短链；不把整片退回少招慢讲。

交付前数事件、数实际切镜，核对至少三种景别；检查是否存在连续两秒以上无新攻防、位移或信息变化的段落。发现空耗优先修它。上述时间阈值是密集模式的编辑检查，不是所有叙事视频的通用禁令。
