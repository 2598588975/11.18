## 场景诊断与素材边界

先识别用户要的体验：感受连续攻防的力量、速度与环境规模。仅为动作展示时，使用非叙事规划，不编造复仇、心理创伤等剧情；用户指定反转时，落实为前后空间或能力状态变化。

从当前图片/视频提取地表、空气、服装道具、光源、风向。区分观察与新增设计：图片不能证明角色有灰烬重组能力；参考词可以提供这一创意，但不能当作素材中已经发生。只看抽帧不能宣称听过重音或验证了动作速度。

建立简短内部表：

| 条目 | 必须确定 |
|---|---|
| 当前素材 | 每张图绑定谁、绑定场景还是造型；三视图是同一人物 |
| 地表 | 松沙/碎石/硬土/木板/积水，哪些材料真实存在 |
| 空气 | 风向、湿度、雾尘密度、逆光方向 |
| 身上材料 | 尘、汗、毛发、布纤维、甲片、护具和武器 |
| 主效果 | 优先选受击对象自身的材质系统；不默认地表粒子 |
| 辅助效果 | 最多一种有明确用途的支持效果 |
| 强度 | 身体反应有轻重；环境强弱服务事件，不要求每击环境爆发 |
| 终点 | 退到哪里、留下什么、尘屑如何落回、破损如何延续 |

已给场景或让你设计时直接做合理选择，不再展示20个场景让用户选。

## 两个VFX技能的分工

- **特效构建引擎**：选材质和主效果，构建来源→触发→轨迹/深度→作用对象→峰值→衰减/残留；搜索术语时每个词只担任一个作用，不能堆同义词。
- **本打戏技能**：负责接触点、发力、收招、受击、防守、位移、镜头轴线和动作时间预算。
- **Seedance VFX**：保留同一效果设计，把它压缩成模型可表现的动态语句；核对重力、风、碰撞、遮挡、光照和终态，不在压缩时重新换一种魔法。
- 有外部技能时读取并使用；不可用时按本文件完整执行。不要依赖只写“调用两个技能”的空转接。

内部效果卡：功能；媒介；来源；触发；材料/形状；路径/前中后景；接触；身体/环境/光响应；峰值；余波/终点；起音/重音/尾音。交付文本只保留可见可听内容，不出现卡片字段或术语ID。

## 环境材料与三层空间

| 环境 | 常驻层与前景 | 接触反馈 | 可持续结果 |
|---|---|---|---|
| 松软沙漠 | 背景逆光浮尘，前景稀疏失焦沙粒横掠，局部低空流沙 | 蹬地向后抛沙，侧滑外缘弧形沙幕；拳击震落衣上积沙；落地掀扇形沙浪 | 脚沟、滑痕、落地沙坑；粗沙先落、细尘被风带走 |
| 戈壁/硬土 | 浮尘与已有砂砾；明确硬土/岩层 | 重击碎开实际接触的硬土壳/岩角，碎石弹跳，粉尘后涌 | 崩角、裂隙、散落砾石；不同尺寸落地时间不同 |
| 雨夜街巷 | 前景失焦雨线，背景薄雨雾，积水反光 | 踩水扇形喷溅；拳击甩出衣料水珠；滑退推水脊 | 波纹外扩、鞋印、破碎倒影，水滴回落 |
| 木屋/木台 | 空气少量尘，梁柱形成前景遮挡 | 被撞木板沿木纹裂开，木屑顺力向飞出，细木粉后涌 | 裂板、弯曲钉子、落地木片；不凭空生金属火花 |
| 雪地 | 风雪和贴地雪粉 | 踏压松雪、受击落雪、滑退犁出雪槽 | 压实脚印；冰裂只来自实际冰面 |
| 石殿/废墟 | 碎柱遮挡、斜光浮尘 | 接触石材后崩角、石屑、粉尘与回声 | 坍落碎块、裂纹延续；不让空气出拳震碎所有石柱 |

**需要三层时分工**：前景提供视差和临场遮挡，中景提供受力和接触，后景提供深度与规模。强效果可以占据大面积背景/边缘，不必把所有粒子压得微弱；命中前后留出能读到手、刃和身体轮廓的瞬间。

前景不是覆盖屏幕的固定贴图。写清沙粒来自哪次蹬地/刮沙，从人物前还是后穿过，离镜头近时变大失焦，随后落出画面。风向与服装一致；迎风飞出的粗颗粒先按初速度运动，再下落，细尘更快随风。

**碎片由材料决定**：纯沙地不长出石板裂缝；衣料拉紧后撕出少量纤维/布条；金属相擦或撞硬石才可能产生短火星；骨饰只有被击碎才掉骨屑，不能装饰性连续掉落。无热源、燃烧或明确角色能力时不用余烬。逆光沙粒可亮，但不因此成为发光火星。

## 打击事件和声音

每次关键重击写成一条有顺序的链：

`蹬地/转髋/武器起势 → 路径和破风 → 确切接触与局部压陷 → 短顿挫与同步重音 → 身体沿力向位移 → 衣料/环境响应 → 碎屑滞后回落与新状态`

声画允许近乎同时发生，但因果必须明确：先看到接触，才给闪光/震镜/扬尘，不能先爆炸再补拳。

| 强度 | 可见证据 | 声音 |
|---|---|---|
| 连续轻快击 | 清楚落点、格挡偏转、衣料冲振、少量附着尘/汗滴、脚步局部扬尘 | 短破风和干脆接触音，声色随身体/护具/柄材改变 |
| 次重击 | 胸肩偏转带动重心、补步或屈膝抵抗；角色材质按需响应 | 接触瞬态＋短低频重量＋材料声，避免每拳都同样巨大 |
| 主峰 | 蓄势对比、清楚碰撞、身体折转/失衡/击飞或状态破坏、短停后释放；环境受扰才响应 | 碰撞前瞬时压低环境音；接触重音、低频冲击；随后沙粒落地/布条抽动/金属余振 |

重音不等于只把音量调大。为拳、肘、刃、身体落地分别写不同的音头、低频重量和尾音；保持关键接触声高于环境风声，环境在重击后重新浮现。沙漠采用开放空间的短尾，不无故添加大厅长混响。未试听原片时，只能说这些是新设计，不能说原片已经具有或缺失某种混音。

每击有反馈，不等于每击出现发光冲击环。写实CG先用姿态、重心、拖曳和收势，再按需用衣料与尘等材质；纯2D可用手绘烟尘块、速度线、轮廓压缩和冲击帧；不要仅因技能名而更改参考图媒介。

## 节奏、媒介与状态连续性

密集模式以 action-density-and-editing.md 的时间预算优先；一个主峰不等于全片只留少数攻击。灰粒、布条和环境余波在下一次攻防中延续，不要求角色停下等它们消散。

- 15秒短片可选择一条主效果链、一个最大峰值、最多两个次峰；普通接触和常驻环境可以连续存在。一种主效果不等于只允许一个特效瞬间。
- 30秒可有两条相连的效果链，例如“实体遭击逐步灰化→残余灰烬重新聚合”；后一段继承前段残留，不能另开无关特效系统。用户只借鉴特效写法时不照搬整套30秒剧情。
- 连打保留材质反馈和空气携带物，密集时缩小爆散范围，收尾重击才放大。不要写“连打零特效”，也不要要求主峰全程铺满到结束。
- 命中短停、慢动作和受击硬直分别设计，见 hit-reaction-and-impact.md。用短暂速度差突出选定重击，注明恢复常速的位置；不为每拳加慢动作，不以帧数承诺模型精确执行。
- 镜头随位移跟进，接触时短促沿受力方向震动，随后迅速稳定。前景沙粒及背景视差增强速度；甩镜放在动作转向/追击上，不把所有过程摇糊。
- 运动模糊集中于高速拳脚边缘、刃尾和经过镜头的粒子；面具、握柄、受击接触至少在关键帧可读。不要把“完美模糊”“最高密度雾”当作可靠参数。
- 记录最少状态：披风破口、散落物、沙沟、武器位置、身体虚实。下一镜继承损伤和尘的运动，不重置。
- 用户允许幽灵/灰烬能力时，选择一个一致的黑灰材料系统：受击处边缘破散→灰粒沿力向剥离→主体仍有可辨认轮廓→灰尘停留或回聚。不能用“消失/重现”替代过程，也不要让每次未命中的攻击都假装打中实体。
- 用户要求写实时，以物理环境和材料响应为主；“写实渲染”本身并不禁止已授权的超自然设定。

## 参考提示词拆解

用户提供的30秒沙漠战斗英文示例，其结构可迁移，但具体人物编号、动作与魔法不能机械照搬。

| 写作层 | 示例包含什么 | 可迁移的方法 |
|---|---|---|
| 总体力度 | 高速CG战斗、强动作 | 声明体验后用具体接触和位移兑现，不只堆形容词 |
| 环境介质 | 体积雾、金色沙暴、热扰动 | 让空气有前后层次、可被人物/武器推动；热扰动仅在适合环境时使用 |
| 摄影 | 35mm变形镜头、低位跟拍、甩镜、倾斜构图、慢动作 | 每个镜头承担速度、尺度或接触的任务；不是逐项强制全用 |
| 身份锁定 | 双方参考图、面具、红披风、长镰 | 先按当前素材重新绑定，保留服装和武器的可识别轮廓 |
| 动作携带特效 | 碰撞炸开沙浪，布料/灰粒爆散，刃击地表，布袍撕条 | 动词＋接触＋材质变化＋位移；不是“打斗很激烈＋高级粒子” |
| 状态递进 | 袍子逐步破损、半消解、最后灰化 | 前一段的损伤成为后一段基础，让力量升级可见 |
| 结尾反转 | 残余灰重新汇聚成敌人 | 灰烬既是上一击结果也是下一事件原料，建立可继承的效果链 |
| 渲染收束 | 布料物理、粒子、体积光、材质一致性 | 用受力、遮挡、逆光和不同粒径运动说明质感 |

示例没有明确编排音头、低频重音和碎片回落尾音，也没有充分规定前景粒子层；这些是结合当前诉求补入的设计，不能误称它原文已经写清。其血液、火星、开裂、重组属于创作设定，按当前材质和用户意图取舍。仅凭词不能证明这些指令必然带来好成片。

## 编译示例与交付检查

弱句：战士重拳击中对手，产生冲击波，电影级特效。

可拍版本（沙漠CG）：战士后脚蹬沙、转髋出拳，拳面压进对手胸前布袍；命中短停，干脆撞击声下叠一次低频闷爆。对手胸肩后折，布上积尘沿拳势向后喷散，绷紧的旧破口撕出几缕黑纤维。脚步被推退，在沙地犁出双沟；粗沙向镜头两侧抛起，近处失焦沙粒掠过画面下缘，细尘在逆光中后涌。镜头沿受力方向短震后稳定，粗沙先回落，布纤维和细尘继续随风飘走。

把效果嵌入风格总控、镜头总控、每个事件节拍、声音与稳定约束中。不要在时间线之外再附一份泛泛“VFX特效大全”。最终文案先保留动作落点、受击、材质、声音、余波，再压缩重复形容词。

交付前逐项检查：
1. 当前参考图编号正确，时长与开场动作保留。
2. 身体反应先成立；选用的地表与碎屑材料匹配，空间层次服务动作。
3. 重要效果有来源、轨迹、接触、结果、衰减或可继承终态。
4. 轻快击、次峰、主峰的画面和声重不同。
5. 环境强度随实际扰动变化，不用扩大沙尘替代怪物受击；没有用“清晰”删除必要环境。
6. 破损、位移和残留跨镜连续；武器未被粒子替代。
7. 声音包含接触重音和材料尾音，和动作逐拍同步。
8. 已注明分析依据的边界，没有把未生成的改写说成实测成功。
