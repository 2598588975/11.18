## 1. 读取与迁移边界

创作或改写时读取本文件。按需读取 reference-casebook.md 查例句。两例均为用户2026-11-03提供的文本，分析的是文本写法；没有对应成片时，不宣称这些词已验证生成质量。

将主入口的单次最长30秒、整数秒时间轴、一次完整交付与当前素材绑定置于案例之上。参考案例内的沙漠、21:9、35mm、血液、幽灵重组、赛博战刀、毁城、人物姓名和图号均为案例设定，不是新任务默认值。用户的16:9血月古城和巨兽战不得变成午后都市刀战。

## 2. 英文案例：紧凑动词链

学习顺序是“镜头任务 → 攻击路径 → 对方应对 → 反击 → 材质结果 → 进入下一招”。一句可以含两三次相连攻防；受击反馈与下一动作重叠，不把每个部位拆成逐条慢演。

例：`ducks under scythe → spinning elbow to ribs → upward knee → reaper reforms and counters`。其密度来自下潜、肘、膝、防反之间的连续关系，而非只写 `hyper-kinetic`。

| 原词/短语 | 工作 | 可迁移中文表达 |
|---|---|---|
| explodes forward / vaults off | 发起与借力点 | 后脚蹬地暴冲；踩住明确物体借力跃起 |
| ducks under / rolls, rises into | 避让与下一招衔接 | 下潜从刃下穿过；翻滚起身顺势接踢 |
| drives / seizes / rips free / twists | 施力与控制关系 | 顶入明确部位；抓住何处；挣脱握持；扭转武器或重心 |
| spinning elbow / upward knee / dual-fist hammer | 动作与轨迹 | 转髋横肘；膝盖向上顶入；双手由上往下砸击 |
| phases partially / reforms mid-strike | 特殊身体规则 | 已授权虚化时写凝实部位、错过的攻击和恢复时点 |
| shreds into black ribbons | 角色材质变化 | 布料从受力处撕开，布条顺运动方向滞后飞出 |
| sends the figure airborne / crashes down | 受击终态 | 由明确命中造成失衡、离地，再承接撞落位置 |
| reconstitutes from residual ash | 残留成为后续原因 | 由已有灰质聚回核心，按轮廓与武器顺序重组 |

不要孤立复制“高速、猛烈、电影级”。用动词的施力对象、路径和结果兑现力度。英文并不天然比中文有效，交付语言服从用户。

## 3. 中文案例：镜头状态与战损

每镜内部记录三件事，交付时用简洁中文句子体现即可：

- 开场状态：谁在哪里、朝向、武器状态、已有伤损。
- 动作：从该状态出发的攻防，谁造成谁的姿态或位置改变。
- 结束状态：停在哪里、谁占优、何处暴露、下一招从哪里接。

终态必须成为下一镜起点。动作跨镜时，后镜从上镜尚未完成的阶段继续，不重放攻击。画面左右在新机位下可能改变，必须给切镜、移动路径或背景锚点作为解释；单写“换位完成”不能证明位置成立。

将战损视为持续账目：接触先损伤→损伤削弱防御或结构→下一击利用弱点→终结留下不可逆状态。战损写具体：头盔镜头闪烁、胸甲凹陷、腰带断裂、墙洞、弯曲支架、断剑、倒地熄火，不是每镜泛称“遍体鳞伤”。普通肉身、岩甲巨兽与幽灵分别采用对应规则。

设计重音时借鉴“近景接触→大全景位移→材质破坏→继续战斗”。例如踢中胸口先展示胸肩受力和支撑离地，再切全景展示飞退；不能只给发力和远处爆炸。

碰撞分三级：

| 层级 | 动作结果 | 声画处理 |
|---|---|---|
| 轻 | 拨偏、局部震颤、短退步，仍能反击 | 短接触音、少量对应材质；保持常速 |
| 重 | 架势被打散、支撑破坏、身体显著位移 | 接触先清楚；一次极短顿挫或局部冲击强调；低频更深 |
| 终结 | 明确破防后改变胜负或能力状态 | 一个主要视觉峰值，接续倒地/断裂/熄灭与余波；不凭空毁城 |

冲击帧、负片、闪白、镜头短震是选择性重音。参考案例中的所有碰撞都配抽帧，不代表新片要每招闪屏。用户要求写实，用姿态和材质优先；用户要求强作画张力，可在关键接触加入简短手绘冲击图形并恢复主体。

## 4. 词语如何变成画面

### 摄影词：一个镜头解决一个主要任务

| 参考写法 | 实际任务 | 编译要求 |
|---|---|---|
| Extreme Wide Crash-In | 大尺度、速度与碰撞同时进入 | 从哪里冲近、跟谁、到哪个接触点；别以无动作空景拖开头 |
| Dynamic Low Tracking | 贴地速度与支撑关系 | 固定低机位参照，跟随明确人物或脚步方向 |
| Orbiting Medium + Dutch Angle | 绕行、力量失衡 | 必须有动作理由，限制绕行幅度，保持方向线索 |
| Handheld Close Combat Frenzy | 贴身密集攻防 | 可有轻手持，连续招式与接触仍可辨；不全程摇糊 |
| Wide to Tight Push-In | 从位置关系转到关键破绽 | 写起止景别和推进目标；镜内推进不是一次新剪切 |
| Reverse Extreme Close-Up | 前后景揭示或反转 | 交代机位改变、对焦位置和被揭示信息 |

35mm变形镜头、热扰动、重运动模糊只有适合当前媒介和场景时选用。速度模糊放在高速边缘、背景和经过镜头的粒子；脸、握柄、攻击落点在关键时刻可读。景深由信息决定：需要背景反转时保留背景，不一律浅景深。

### 特效词：材料与动词成对使用

采用“来源→路径→碰撞/作用→身体与材料响应→衰减或残留”。

- 布料：拉紧、撕开、绷断、滞后抽动；来自衣物已有破口，保留破口。
- 沙尘：蹬地抛起、滑行刮出、粗粒回落、细尘随风；不凭空喷出混凝土。
- 岩甲：刃口切入、裂口延伸、边缘崩离；先露接触和关节反应，再出碎屑。
- 金属：刃口咬合、弹开、凹陷、支架弯折、断片旋转落下；接触与材质允许时才有火花。
- 火焰：喉内聚亮、从嘴喷出、沿路径卷动、照亮与灼烧碰到的对象；中断后残焰衰减。
- 能量：从人物/武器明确部位形成，沿身体或刃口传播，达到限定几何形状，作用后收束；不随意换色换来源。

爆气与觉醒也要有过程，顺序服从用户剧情；可写空手起身→身体能量激活→远处武器响应并召回→握住立即反击，也可在用户指定时写剑柄入手→能量沿手臂推进→压力波扩张→收束到刃口→立即反击。衣袍、细尘与碎石按实际气流和距离响应；不把握剑设成觉醒的固定前提。改变能力可以不改变面貌、身高或服装；用户未要求时不换装、加角、变巨人。

声画绑定：破风起音→清楚接触音头→有选择的低频重量→对应材料尾声。重音前可短暂让环境声退下；不是全程最大音量或每击爆炸。

## 5. 30秒设计与两种输出骨架

时长由剧情决定，30秒为本用户工作流上限，不是所有平台的技术承诺。只输出一份完整提示词。短片不必用满30秒，完整多转折剧情可用30秒。不要在第15秒截断再要求用户继续。

先预算剧情事件与镜头，再填规格：开场进入攻防，持续的压制/抵抗造成转折，转折后的新能力必须解决先前障碍，终结让观众看清结果。可以借用“轻→密→重→短暂蓄势→再爆发”的曲线；不能把每一阶段都做成大招，也不能让慢动作覆盖整段快打。

### 紧凑型（默认）

适用于人物关系简单、动作连贯的片段。学习英文案例的简洁动词链。

```text
[资产、媒介、片长、画幅、场地尺度、能力归属]
0—[整数秒]：切/开场于[景别、机位、跟随目标]。[具体进攻→对方应对→反击；接触、受击结果与材质同时交代]。
[后一镜]：承接[必要终态]，利用[已有位置/破绽]继续……
[结尾]：胜负或新威胁清楚，动作与残留进入稳定结果。
[简洁声音与身份、握持、尺度、损伤连续约束]
```

### 状态明确型

适用于巨兽尺度、多次缴械、召回、变身、跨地形追逐。借用中文案例的状态链，保留关键状态而非每镜重复资产描述。

```text
[全局资产与空间锚点；角色能力色、实体武器数量]
[整数秒]｜[镜头规格]
开场：[仅本镜必要的位置/朝向/握持/战损]。
动作：[明确动作链及接触受力，选定的声音和材质重音]。
结束：[让下一镜接得上的位置、状态或新破绽]。
……整个时间轴完成后附简洁连续性约束。
```

除用户明确要求外，不同时输出两套骨架，不附词库、内部评分与重复分镜表。中文版不必使用英文 Start State / Action / End State 标签。

## 6. 迁移、自检与修复

1. 有明确攻击对象、路径、落点与防守结果，还是只剩“高燃猛烈”？
2. 镜头有没有任务；全景看距离和体型，近景看接触，切镜有没有理由？
3. 下一动作是否利用上一动作留下的状态；位移和损伤是否被重置？
4. 轻、重与终结是否有区别；环境破坏是否来自接触或已设定力量？
5. 尺度是否持续成立；指甲盖等高的人物不能在下一镜与巨兽同高对拳？
6. 时长与镜数是否可执行；必要叙事转折是否被机械密度指标挤掉？
7. 正文整数时间线是否加总正确；旧案例的小数时间和阶段名有无误用？
8. 用户的面部、服装、图号、武器、场景是否正确；参考案例仅迁移结构？

参考案例需要修正的边界：
- 英文案例的纯沙环境却出现开裂地面、火星或余烬，须补硬土/岩层与热源或删去不匹配反馈。
- 英文“幽灵部分虚化”和实体受击必须分清，不能未命中却受伤；兜帽与面具等称呼不一致时以当前资产为准。
- 英文18—23秒的慢动作段不能直接照搬到用户追求密集常速的短片。
- 中文18镜标称时长相加约29.8秒，部分阶段区间与各镜加总不一致。新片重新排整数秒总表，不沿用错误累计。
- 中文前段已经使用重碰撞，与尾部“全屏冲击严格只在13—18镜”的约束需要区分局部强调与全屏主峰，避免互相打架。
- 机械/超能力设定可以让悬浮发生，但要给来源与作用对象；电磁力不默认吸起所有非金属碎砖。
- “perfect motion blur”“最大雾密度”“全程强震”是风格诉求，不能当作可执行保证，更不能覆盖接触可读性。
