# 受击身体与重击设计

## 先完成一次命中，再添加特效

打击感来自攻防结果可读。优先级：身体姿态/重心变化 → 角色材质变化 → 环境反馈。它们是编排优先级，不是要求声画机械分开。移除粒子、闪白与震镜后，如果只剩拳头碰着直立木桩，先重写受击。

逐个关键事件内部检查以下字段，交付时合并成自然句，不机械堆满每一拳：

| 字段 | 写什么 |
|---|---|
| 前态与意图 | 双方位置、支撑、谁露出什么破绽；这一击破防、压制还是击退 |
| 发力与接触 | 支撑脚、转髋/肩带、拳脚或刃的路径、明确受击部位 |
| 攻防结果 | 实中、擦中、格挡、卸力、闪避、主动虚化，只选与画面一致的结果 |
| 力向 | 相对对手的后方/侧方/上方；需要时补画面方向，换镜保持空间一致 |
| 局部到整体 | 受击部位先偏转/压缩，躯干与重心随后变化，支撑失效或补步抵抗；四肢、头发、衣料滞后 |
| 轻重 | 轻击局部偏移，次重击破坏架势，主重击明显改变位置/姿态/能力状态；不是每拳都飞走 |
| 终态 | 退到哪里、单膝撑地还是侧翻、武器是否握住、何时恢复反击；下一招承接此状态 |

身体链不是固定“头→胸→脚”：胸中拳可胸先后挫、头与手滞后、脚补步；扫腿可支撑先失效、骨盆倾倒、上身追随。局部压缩须符合材质，金属胸甲不能像肉腹凹陷。体型、质量、主动抵抗影响幅度；大怪可局部关节折退而未飞走。若硬抗，明确架势压低、支撑承压和攻击者收拳震退等证据，不能只有完全静止。

连续拳击组织密集而有因果的变化：试探被拨开→下一击击中躯干使肘下沉→利用破绽打出主重击。不能同时写“全部格挡”和“每拳打中”；不能每次接触后自动恢复站姿。防守方有主动抵抗、破招或短暂失能，避免全程配合挨打。

## 怪物受击由身体规则决定

| 身体规则 | 受击表现 | 持续结果 |
|---|---|---|
| 血肉/筋肉 | 局部受压、躯干折转、呼吸被截断、失衡或防护反射 | 疼痛动作、保护受伤部位、移动受限；血液不是必需 |
| 重甲/机械 | 接触甲板震动，连接件与关节承压，整体质量迟滞 | 凹痕/松扣须有力度依据；不能轻拳必碎甲或必生火花 |
| 石质/脆壳 | 本体先承力，接触处崩角或裂口扩展 | 碎块来自明确缺口并保留缺损，不能全身每次无差别爆碎 |
| 幽灵/灰化实体 | 先确定可被击中的凝实阶段；局部轮廓受压或剪切，躯干卷曲偏转 | 黑纤维/灰质从受击处沿受力路径撕离，主体保留可辨识轮廓；严重一击才部分解体 |

黑色外观不自动证明幽灵设定。用户参考允许虚化与重组时，可把它作为本次明确的创作设定。主动虚化是一次防御，受击灰化是伤害结果，两者时机不同。怪物自己的黑色攻击轨迹也不能误判为受伤碎屑。

幽灵重组需要写灰质在哪里残留、向哪个核心汇聚、先形成什么轮廓、何时恢复武器与行动。普通连击不能每拳全身消失又满血重置。角色图是长耳兽首就保留其识别轮廓，不随参考片换成无脸兜帽。

粒子可顺初始冲量飞出，身体旋转和纤维拉伸让轨迹弯曲，之后受重力、风或已设定能力影响；不是所有碎片永远平行于拳向，也不是全都朝镜头爆射。优先写一条清楚的主力向和必要的次级运动。

## 三种时间变化要分清

密集模式按 action-density-and-editing.md 先限定慢段预算。以下受力链是同一动作内部的关系，不能逐条拉成独立耗时演示；轻快击只保留落点和主要反应，重点命中再展开。

- **命中短停（hit stop）**：在接触与受击姿态成立的瞬间短暂压住双方动作，表现碰撞阻力，随后迅速释放。不是出拳前悬停，也不是长时间全画面冻结。
- **动作慢放（slow motion）**：动作仍继续，放大关键姿态、受力变形或击飞展开；明确从何处进入、展示什么、在哪个动作恢复常速。只写“慢动作”不足以定位。
- **受击硬直（hit stun）**：对手一段时间不能正常防守或反击；攻击者可继续移动。它与整场时间减慢不同。

选定重击可采用：短蓄势形成压缩姿态→常速爆发接触→极短命中顿挫→局部慢放看清身体折转与衣料滞后→恢复常速完成摔落。按时长取舍，不要求每一击凑齐全部环节。不通篇慢，也不把每一拳都做主峰；参考片中的长滞空若占比过高，缩短而非照搬。时间轴用整数秒段，精确帧数只作可选创作目标，不宣称 Seedance 保证执行。

## 声音与镜头同命中对齐

声音写三层即可：动作起音/破风 → 接触音头＋有选择的低频重量 → 目标材质与动作尾音。连拳接触短促，重拳的低频更深或延续更久，主峰前让风声或配乐短暂退下，重击后恢复空间声。重音指动态对比与声色组织，不等于全程最大音量；低频不能吃掉清楚的接触音头。

区分对象：肉身闷撞与短促呼气；重甲硬撞加短金属共振；石壳脆裂加落块；授权幽灵可设计低沉空腔撞击、纤维撕裂和灰质散开的沙沙尾声。超自然声音是创作选择，不是假称真实物理录音。只有着地/碰地时才加入地表冲击和颗粒落地声。开放沙漠不自动添加大厅长回响。

镜头先让观众看见接触与姿态改变，再追随位移；可在主重击沿冲量做一次短促震动并立即稳定。展示击退距离时保留地面或背景参照，不用镜头同步贴随把位移抵消。画面切换、慢放、音头服务同一个事件，不能各自随机爆发。

没有试听就不评价原片的低频、混音或音效同步；波形峰值也不能证明听觉重量。可以独立提供声音设计方案，并注明是建议。

## 自检与修复

1. 不看粒子能否读出攻击与受击？若不能，修姿态和支撑。
2. 每次接触是否有明确结果，防守与命中是否矛盾？
3. 受击方向、身体旋转、镜头主轴与下一招位置是否一致？
4. 重击是否比轻击改变更多身体状态，而不只是尘更大？
5. 慢放有具体展示内容和退出点吗？接触、受击、落地是否都有时间？
6. 角色材质是否有来源，损伤是否累积，碎片是否留下缺口？
7. 声音的起音、重音、尾音是否对应动作，而不只是形容词？

修受击缺失时可保留原动作链；修动作少或拖慢时按 action-density-and-editing.md 增加事件和切镜，压缩准备、复位与空耗。不得把“有重量”默认解释成少招慢打。将试写与实际生成验证分开。

## 编译例：同一沙地，身体反馈优先

弱句：重拳击中怪物，爆出巨大沙尘和冲击波。

可拍句：战士后脚撑稳、转髋送出右直拳，击中怪物胸侧。拳面接触处的黑袍绷紧，怪物胸肩先向后挫，头与握镰的手稍后被带走，支撑脚补步失败；命中瞬间短顿，硬质音头下叠一次低沉撞击。短暂慢放中，它的躯干向后侧折转，受击处几束黑纤维被拉长、撕离；随即恢复常速，怪物侧跌并以镰柄撑地。滑动的脚跟只带起一道贴地沙痕，残余黑纤维继续飘落，胸侧缺口保留到下一招。

这是针对已授权幽灵能力的创作示例，不是每个沙漠怪物的默认模板。

## 研究依据与迁移边界

以下是动画与游戏开发的一手实践资料；转换为视频提示词是本技能的创作推导，不是 Seedance 参数文档或效果保证。

- [Wayne Gilbert：How to Create Believable Weight in Animation](https://www.animationmentor.com/blog/how-to-create-believable-weight-in-animation/)：重量通过姿态、路径、平衡与时序表现；由此先写身体承力，再选择特效。
- [Drew Adams：Follow-through and Overlapping Action](https://www.animationmentor.com/blog/follow-through-and-overlapping-action-the-12-basic-principles-of-animation/)：身体部位和附属物不同步运动，材质与连接方式影响拖曳与跟随；由此写局部、躯干、衣物的先后。
- [PlayStation Blog：开发者分析 God of War 战斗](https://blog.playstation.com/2022/10/04/game-developers-explain-what-makes-god-of-war-2018s-combat-tick/)：Christian Wohlwend 讨论大幅受击姿态、动作跟随、低频撞击结合高频尾声及命中短停；由此采用接触、受击、音头与停顿共同强调主重击。不同游戏的镜头方案也说明震镜不是唯一答案。
