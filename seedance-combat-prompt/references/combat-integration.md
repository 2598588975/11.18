# 打斗skill：组合执行规则

## 统一入口

把用户对「打斗skill」「Seedance 二次元打戏」或 `seedance-combat-prompt` 的调用视为同一个技能。按一次导演决策完成交付，不把几个技能的提示词依次粘贴。单次最长30秒；未指定时长按剧情在30秒以内选择，30秒以内一次性交付完整提示词。用户给定媒介、时长、人物和开场动作时直接沿用。不得因旧15秒模板自动拆段。

采用四层分工：

| 层 | 取用规则 | 产出 |
|---|---|---|
| 招式与运镜 | 原版 section-01—30，按拳法、兵器或镜头问题选读 | 角色动作签名、进攻与防守、镜头目的 |
| 动作密度与受击 | action-density-and-editing.md、hit-reaction-and-impact.md | 有效攻防事件、切点、受力方向、支撑和终态 |
| 特效构建 | environment-impact-vfx.md；可用时读取 vfx-effect-construction-engine | 来源、介质、路径、碰撞、角色和环境余波 |
| Seedance 编译 | section-36.md；可用时读取 seedance-vfx | 一份按整数秒组织、可直接复制的完整提示词 |

依赖技能不可用时用包内规则继续，不要求用户安装额外工具，不宣称已调用。用户只要求分析时只做分析；只要求提示词时不附内部规划、评分和多份版本。

## 组合步骤

1. 从用户素材锁定双方身份、武器、画风和环境；确定战斗目的与结局，有合理默认就继续。不使用示例人物替换用户资产。
2. 用原版角色/技法库给双方选不同打法。为每次进攻安排格挡、落空、反击或受击；下一招利用上一招留下的破绽和位置，不能全程配合挨打。
3. 用户要求密集时先排攻防事件与实际切镜，再填特效。15秒约10—14个事件、8—10镜是起排预算，不是固定模板或生成保证；单镜要求优先。
4. 逐个重音先写身体接触、力向、支撑变化与结果，再写材质和声音。轻击不逐项慢演，重击不只增加尘量；慢放后写明立即恢复常速。
5. 以真实场景材料构建特效：有来源、有路径、有碰撞、有余波。保留连续局部反馈，最大环境峰值只给有依据的重击；不用尘墙遮住受击。
6. 合成一份时间轴，保持主轴、人物位置、武器持握和累计损伤。检查总时长、攻防密度、三种景别、接触可见性与余波承接。

## 冲突时的取舍

用户本次要求优先；其次是 SKILL.md 当前执行入口和三个专项文件；最后才是原版章节中的固定配方。

- 原版「快慢交替」「胜利定格」「景别阶梯」是可选手段；高速需求采用短促重音和动作接切，不为模板增加停顿。
- 「必须肘击」「必须某种开局或固定角色」不覆盖人物武器和用户动作。武器战用合适的柄、刃、拨挡或夺械，不强塞拳肘。
- 「每拳音爆」「中段零特效」「后段铺满炸」不作为统一标准。轻重分层，接触点可读，环境响应符合材质。
- 原版完播率公式、跳出率数字和渲染引擎词只作为来源中的创作说法，不当作已验证数据、实际生成参数或效果保证。
- 技法专项文件缺失时用已有内容完成编排，不捏造读过资料。仅因人物黑色外观不能默认幽灵化。
