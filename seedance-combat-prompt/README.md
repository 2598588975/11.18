# 打斗skill

个人定制的打斗动作导演与提示词工具。根据人物、场景和剧情，一次性交付最长30秒、可直接复制使用的完整提示词。

## 能做什么

- 编排密集攻防、攻守转换、缴械、召剑、爆气与反杀。
- 设计全景、中景、接触特写及动作接切，保持方向、尺度和战损连续。
- 写清接触、身体受力、支撑变化、材质破坏和声音重音。
- 支持真人、写实三维CG、二维动画、兵器战与巨兽战，沿用当前资产质感。
- 根据成片与原提示词诊断动作少、拖慢、打击感弱或特效遮戏。

## 怎么用

提供对战双方、环境、画面风格、战况变化与必留动作。有资产就说明图片编号，没有具体招式可以交给技能设计。

> 用我的人物和场景，做一段不超过30秒的完整打斗。前半段被压制、宝剑脱手，随后起身召剑、爆气反击。动作密集，轻重有区别，保持人物与怪物尺度。直接给完整提示词，时间用整数秒。

30秒以内一次完整交付；只有剧情超过30秒或主动要求拆分时才拆段。实际时长依剧情决定，不强制每条都用满30秒。
